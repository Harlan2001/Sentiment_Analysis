# 05. 设置模块 PRD

状态：P0 范围已确认

## 1. 模块目标

设置模块首版只实现基础账号功能，帮助用户完成登录、查看和修改简单账号信息，以及安全退出当前账号。

首版不建设复杂的账号安全中心。

## 2. 页面入口

左侧栏底部显示当前用户信息：

```text
[头像] 用户名
       账号信息
```

点击后弹出账号菜单：

```text
账号设置
退出登录
```

## 3. 登录

### 3.1 登录页面

登录页包含：

- 用户名或邮箱输入框。
- 密码输入框。
- 显示或隐藏密码。
- 登录按钮。
- 登录失败提示。

### 3.2 登录交互

1. 未登录用户访问产品时进入登录页。
2. 用户输入用户名或邮箱、密码后点击“登录”。
3. 登录成功后进入产品首页。
4. 登录失败时保留用户输入的账号，并显示简单、明确的错误提示。
5. 登录状态过期后返回登录页。
6. 用户重新登录成功后，只加载当前账号有权限访问的数据。

## 4. 账号设置

账号设置使用简单弹窗，不单独建设复杂设置页面。

用户可以：

- 查看和修改用户名。
- 查看当前账号或邮箱。
- 修改头像。
- 修改密码。

修改成功后，左下角账号区域同步更新。

## 5. 退出登录

### 5.1 交互逻辑

1. 用户点击左下角账号区域。
2. 用户选择“退出登录”。
3. 页面显示简单确认提示。
4. 用户确认后清除当前登录状态和本地账号缓存。
5. 页面跳转到登录页。

退出后不能继续访问当前账号的项目、会话、任务和记忆数据。

## 6. 页面流程

```text
未登录 → 登录页 → 产品首页
                    ↓
              左下角账号菜单
               ├─ 账号设置
               └─ 退出登录 → 登录页
```

## 7. P0 实现顺序

1. 完成登录页面和账号密码校验。
2. 完成登录状态保存和过期处理。
3. 完成左下角用户信息和账号菜单。
4. 完成基础账号设置弹窗。
5. 完成退出确认、登录状态清理和页面跳转。
6. 验证不同账号之间的数据和缓存隔离。

## 8. P0 验收标准

- 未登录用户不能进入产品主页面。
- 用户可以使用用户名或邮箱和密码登录。
- 登录失败时能够看到明确提示。
- 登录成功后左下角显示当前用户信息。
- 用户可以修改用户名、头像和密码。
- 用户可以退出登录并返回登录页。
- 退出登录后不能继续访问原账号的数据。
- 切换账号登录后，不会显示上一个账号的项目、会话和记忆缓存。

## 9. P0 暂不实现

- 用户自由注册。
- 第三方登录。
- 企业单点登录。
- 多因素认证。
- 登录设备管理。
- 多账号快速切换。
- 退出所有设备。
- 复杂的安全日志和登录记录。
