# PRD：文件库（第一期）

## 1. 目标

在左侧功能区新增“文件库”，集中查看当前用户在产品中上传或生成的文件。用户可以按文件来源、格式和日期筛选，不必返回原业务页面逐处查找。

## 2. 用户与数据范围

### 纳入范围

- 当前登录用户自己上传的文件，包括产品各页面或流程中的附件。
- 当前登录用户在产品中生成的文件，包括报告、图表和导出文件。
- 文件来自产品不同页面或功能模块时，统一汇总到同一文件列表。

### 不纳入范围

- 其他用户上传或生成的文件。
- 无法关联到当前用户的公共系统资源。
- 在文件库中上传新文件、编辑文件内容、重命名、删除或批量管理文件。

## 3. 导航与页面

- 在左侧功能区新增“文件库”入口，位置在“自定义”下方。
- 点击后进入文件库页面；当前页面应明确标识文件库及当前筛选状态。
- 默认展示当前用户有权查看的全部符合范围的文件，按文件时间倒序排列。

## 4. 筛选

提供以下筛选条件，条件之间支持组合使用：

| 条件 | 要求 |
| --- | --- |
| 来源 | 按文件产生或上传所在的产品功能/业务入口筛选；选项只显示当前用户有文件的来源 |
| 格式 | 按文件实际格式或扩展名筛选，例如 PDF、Word、Excel、CSV、图片等；选项随当前结果变化 |
| 日期 | 按上传时间或生成时间筛选，支持选择起止日期 |

- 用户可以清除筛选条件，恢复全部文件列表。
- 同一文件的来源和时间应使用一致、可理解的名称展示；上传文件显示上传时间，生成文件显示生成时间。
- 筛选结果为空时，提示当前条件下没有文件，并提供清除筛选的入口。

## 5. 文件列表

每条记录至少展示：

- 文件名
- 文件格式
- 来源
- 上传时间或生成时间
- 文件大小（来源模块能提供时展示）

文件预览、打开或下载沿用对应来源模块当前已有的能力。第一期不新增统一编辑、重命名、删除或批量操作。

## 6. 归属与数据一致性

- 列表只能返回当前用户自己上传或生成的文件；不能仅因用户知道文件标识就访问其他用户的文件。
- 文件库汇总文件元数据和来源引用，不重复保存文件内容。
- 文件在来源模块中失效或被移除后，文件库不得继续提供失效的文件入口；列表应反映来源的实际状态。
- 来源暂时不可用时，应保留可确认的文件信息，并明确提示该文件当前无法打开或下载。

## 7. 空状态与异常状态

- 用户尚无符合范围的文件时，显示空状态，说明文件上传或生成后会在此汇总。
- 文件列表加载失败时，显示可重试的错误提示，不显示为“没有文件”。
- 文件已不存在或用户权限已变化时，提示文件不可用，并阻止访问。

## 8. 验收标准

- 左侧“文件库”入口显示在“自定义”下方，并能进入文件库页面。
- 当前用户自己上传的文件和生成的报告、图表、导出文件可以跨产品页面汇总展示。
- 其他用户的文件不会出现在当前用户的列表中，也不能通过文件库访问。
- 文件列表展示名称、格式、来源和对应的上传/生成时间。
- 来源、格式、日期筛选可单独使用及组合使用，清除后恢复全部结果。
- 空列表、筛选无结果、加载失败及文件不可用均有明确状态提示。
- 文件的预览、打开或下载不超出来源模块已有能力；第一期不提供重命名、删除或批量操作。

## 9. 实施前需盘点

- 逐一确认产品中现有的上传与生成入口，以及每个入口提供的文件元数据、用户归属和访问方式。
- 对暂不提供用户归属或稳定文件引用的来源，先补齐关联能力后再纳入聚合，不能退化为展示其他用户的文件。
- 为不同来源统一映射文件名、格式、来源、用户标识、文件时间和原文件访问入口。
