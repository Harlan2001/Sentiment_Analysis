## 二、债券分布限定模块

标题：**债券分布限定（%）**
包含两个标签页：`按种类`（默认选中）、`按类型`

按种类包含如下内容：

所有字段均为**区间输入框（min/max）**，默认值均为 `0.00 - 0.00`，单位为 `%`：

| 债券种类名称 | 字段说明 | 默认值（min-max） |
| :--- | :--- | :--- |
| 国债 | 国债在组合中的权重占比范围 | 0.00 - 0.00 |
| 地方政府债 | 地方政府债在组合中的权重占比范围 | 0.00 - 0.00 |
| 公司信用债 | 公司信用类债券在组合中的权重占比范围 | 0.00 - 0.00 |
| 金融债(不含政策性) | 非政策性金融债在组合中的权重占比范围 | 0.00 - 0.00 |
| 其它债券 | 其他类型债券在组合中的权重占比范围 | 0.00 - 0.00 |
| 政策性金融债 | 政策性金融债在组合中的权重占比范围 | 0.00 - 0.00 |
| 政府支持机构债 | 政府支持机构债在组合中的权重占比范围 | 0.00 - 0.00 |
| 同业存单 | 同业存单在组合中的权重占比范围 | 0.00 - 0.00 |
| 资产支持证券 | 资产支持证券（ABS）在组合中的权重占比范围 | 0.00 - 0.00 |

按类型包含如下内容：
| 债券类型名称 | 字段说明 | 默认值（min-max） |
| :--- | :--- | :--- |
| 利率债 | 利率债的权重占比范围 | 0.00 - 0.00 |
| 信用债 | 信用债的权重占比范围 | 0.00 - 0.00 |

## 三、交互与校验规则补充

1. 所有数值输入框均需支持保留两位小数，输入范围限制：
   - 久期：0~100 年
   - 权重/占比：0~100 %
   - 组合资金：≥ 0 万元
2. 区间输入框需满足 `min ≤ max` 的校验逻辑。
3. 单个债券的单个债券的 min ≤ max，且 0 ≤ min/max ≤ 100% 
    但是所有 min 之和 ≤ 100%，所有 max 之和 ≥ 100%
