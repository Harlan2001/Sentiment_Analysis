## 一、执行摘要

「视界」是一款 **AI 原生（AI-Native）的固定收益智能投研平台**。平台以多模态金融大模型为推理内核，以 **多智能体协同（Multi-Agent Orchestration）** 为执行框架，以 **时序知识图谱（Temporal Knowledge Graph）+ 混合检索增强生成（GraphRAG）** 为知识底座，将财经新闻、机构研报、宏观数据、收益率曲线、量化因子与投资策略等多源异构信息，转化为**可溯源、可解释、可验证**的投研判断。

平台不做"预测明日价格的黑箱"，而是扮演一位 **7×24 小时在线的 AI 资深研究员**：它在凌晨自动完成隔夜全球市场复盘，在盘中实时捕捉央行公开市场操作与突发事件并秒级推送影响推演，在盘后自动生成日 / 周 / 月研究报告；研究员则以自然语言与之对话、质询、布置研究任务，在人机协同中完成从信息到决策的跃迁。

**四大技术代际特征：**

| 代际 | 传统资讯终端 | 第一代金融 AI（Copilot） | **视界 · Agentic AI（本方案）** |
| ---- | ---- | ---- | ---- |
| 交互范式 | 人找数据（检索/翻页） | 单轮问答、内容摘要 | **目标驱动的任务自治：下达研究课题，智能体自主规划、调用工具、交付报告** |
| 知识组织 | 数据孤岛、人工关联 | 向量库相似检索 | **时序知识图谱 + GraphRAG：实体关系可推理、历史情境可重演** |
| 分析能力 | 静态图表 | 单模型情绪打分 | **智能体集群 + 时序基础模型 + 因果推断 + 置信度量化** |
| 系统形态 | 封闭软件 | 嵌入式对话框 | **开放智能体生态：MCP/A2A 协议接入，技能与智能体可生长** |

## 二、行业背景与客户挑战

### 2.1 行业趋势：Agentic AI 正在重塑金融投研

2025—2026 年，大模型技术完成了三次关键跃迁：

1. **从 Chatbot 到 Agent**：以工具调用（Function Calling）、推理模型（Reasoning Model）、计算机使用（Computer Use）为标志，AI 从"回答问题"进化为"完成任务"；
2. **从单模型到模型工厂**：主流机构普遍采用"旗舰推理模型 + 高频小模型 + 多供应商热切换"的混合模型路由（Model Router）架构，智能与成本兼得；
3. **从 RAG 到知识基础设施**：向量检索升级为融合稠密向量、稀疏检索、知识图谱与重排序（Reranker）的 GraphRAG，幻觉率显著下降，金融级归因成为可能。

海外 Bloomberg、Perplexity Finance 等已率先验证"AI 研究员"形态；国内头部券商与银行理财子公司亦在加速布局。固收市场因其**信息驱动强、逻辑链条清晰、结构化程度高**，被公认为大模型最先实现规模化商业价值的金融场景。

### 2.2 客户面临的三重鸿沟

| 挑战 | 具体表现 | 业务后果 |
| ---- | ---- | ---- |
| **信息鸿沟** | 单日数百条新闻、数十份研报、上百项宏观数据，多终端切换；关键信号被噪声淹没，漏看一条降准/MLF 操作即可能以 bp 计价 | 响应滞后、机会错失 |
| **认知鸿沟** | "新闻 → 因子 → 收益率"的传导依赖个人盘感，标准不统一；资深研究员培养以年计，核心人员离职即知识流失 | 判断不稳、经验断层 |
| **工程鸿沟** | 策略想法落地为可回测代码需兼具金融与编程双技能；数据、因子、回测、报告系统彼此割裂 | 验证缓慢、重复建设 |

### 2.3 建设目标

- **提效**：每日 2–4 小时的多源信息整合压缩至**分钟级**，研报解读从 30 分钟 / 份降至**分钟级**；
- **提质**：所有 AI 结论满足 **ATTACC 标准**——可归因（Attributable）、可溯源（Traceable）、可复核（Auditable）、带置信度（Confidence-scored）、可质询（Challengeable）；
- **传承**：将个人经验沉淀为机构级因子库、记忆库与智能体技能，形成**不随人员流动的数字资产**；
- **生长**：平台以开放协议接入客户内部系统，越用越聪明，避免"交付即巅峰"的传统软件宿命。

## 三、产品定位与设计理念

### 3.1 产品定位

> **一个会自己做研究的 AI 投研团队，而非一个会聊天的数据终端。**

「视界」以"AI 固收研究助理"身份嵌入投研全流程，覆盖**早间复盘 → 盘中监控 → 因子归因 → 策略研判 → 晚间报告 → 团队协作**完整链路。

### 3.2 五大设计理念

1. **Agentic First（智能体优先）**：一切功能皆智能体可调用的工具。用户不再学习菜单与按钮，而是以自然语言下达目标，由智能体完成规划、执行与交付。
2. **Human-in-the-Loop（人在回路）**：AI 负责广度与速度，人负责判断与拍板。关键结论提供多空双视角、反方观点与风险提示，**赋能而非替代研究员**。
3. **Evidence-bound（证据绑定）**：无证据，不结论。每一条判断必须挂载新闻原文、研报段落或数据序列，引用可点击、链路可审计，从机制上压制幻觉。
4. **Self-evolving（自进化）**：因子库、记忆库、技能库随使用自动增长；研究员的每次采纳、修正、否决都通过反馈闭环回流为模型偏好与知识。
5. **Open by Design（原生开放）**：基于 MCP / A2A 开放协议，客户内部数据、自研模型、第三方系统均可低成本接入，平台成为机构专属的"投研操作底座"。

## 五、核心 AI 能力设计

### 5.1 多模态金融感知引擎

平台内置统一的数据感知层，将异构信息转化为大模型可理解的标准化"金融事件"：

- **流式资讯感知**：对接财联社、Wind、彭博、公众号、交易所公告等多源通道，基于 SimHash + 语义双指纹进行跨源去重与事件聚合，同一事件的多家报道自动归并为**事件簇（Event Cluster）**；
- **多模态文档智能**：研报 PDF 经版式分析、OCR、表格结构还原、图表语义理解（K 线图 / 柱状图转数据描述）后入库，支持"这张图说明了什么"的直接提问；
- **语音与视频（规划）**：支持央行发布会、经纪会议语音的实时转写与要点提取；
- **事件标准化**：每条资讯经大模型结构化输出为标准事件卡——`事件主体 / 事件类型 / 影响方向 / 时间跨度 / 关联因子 / 逻辑传导链 / 证据原文`。

### 5.2 情绪分析引擎：从"打分"到"逻辑推演"

传统情绪分析输出一个正负面分值；「视界」的情绪引擎输出的是**一份微型投研结论**：

- **结构化约束生成**：以强约束 Prompt 要求模型输出"利多 / 利空 / 中性 + 时间跨度（短期/中期/长期）+ 因子列表 + **触发事件 → 中间变量 → 利率方向**的完整传导链"，并强制优先复用预定义因子，杜绝同义因子泛滥；
- **多模型陪审团（Model Jury）**：重大事件自动触发多个模型独立研判，一致时输出高置信结论，分歧时呈现分歧点并触发深度研究，避免单一模型偏差；
- **情绪指数体系**：逐篇情绪经强度加权、信源加权、时间衰减（半衰期核函数）聚合为市场情绪温度指数、分板块情绪指数，与收益率走势叠加可视化；
- **市场反应回看**：任一历史事件一键关联发布前后收益率曲线变动，用真实市场结果校验 AI 判断，形成**判断准确率的持续计分卡**。

### 5.3 GraphRAG 金融知识引擎

平台知识层并非简单向量库，而是"**一图三索引**"的混合架构：

```text
                    ┌──────────────────────┐
                    │   时序金融知识图谱     │
                    │ 机构/人物/政策/债券/   │
                    │ 行业/因子/事件 实体关系 │
                    │ 关系带时间戳与置信度    │
                    └──────────┬───────────┘
          ┌────────────────────┼────────────────────┐
          ▼                    ▼                    ▼
   稠密向量索引(语义)    稀疏/BM25 索引(词项)   图谱邻域索引(关系)
          └────────────────────┼────────────────────┘
                               ▼
                    Cross-Encoder 重排序
                               ▼
                    上下文压缩 & 证据组装
```

- **时序知识图谱**：实体关系带时间戳与置信度，支持"降准 → 流动性宽松 → 短端利率下行"这类**多跳关系推理**，并能回答"2024 年那次类似降准后市场如何演绎"；
- **图谱自动补全**：大模型从新闻与研报中自动抽取实体与关系（NER + RE），经相似度判重与置信度校验后入图，当前已沉淀 **400+ 因子、200+ 宏观指标**的知识网络并持续自增长；
- **混合检索 + 重排序**：稠密向量负责语义召回，BM25 负责精确术语（"MLF""OMO""10Y 国债"），图谱负责关系扩展，经 Cross-Encoder 精排后送入大模型——相比纯向量 RAG，金融术语场景召回率与归因准确率显著提升；
- **Agentic 检索**：检索过程本身由智能体动态规划（改写查询 → 多路召回 → 评估证据充分性 → 不足则自主补充检索），即 RAG 2.0 的"深度检索"范式。

### 5.4 AI 因子工厂

因子是固收研究的核心语言。平台构建从因子**发现、评估、入库到观测**的全生命周期智能化：

1. **因子自动发现**：大模型从事件流中提炼可复用的经济传导机制，按政策 / 宏观 / 流动性 / 风险 / 情绪 / 行业六大类自动归类；新因子经语义相似度判定（防止重复造因子）与人工/规则双重闸门后入池；
2. **因子信号计算**：
   - *存在性信号*：某因子是否在当日信息流中被激活；
   - *方向性信号*：因子方向强度经时间衰减聚合，输出可跟踪的因子强弱时间序列；
3. **因子—市场归因**：因子信号自动与收益率变动做归因分析，输出"今日债市走强主要由流动性与风险偏好因子驱动"式的结构化归因；
4. **因子健康度监控**：覆盖率、活跃度、与市场的历史相关性（IC 思路）自动计分，失效因子预警，保证因子库"常用常新"。

### 5.5 时序预测与不确定性量化

平台坚持**"辅助判断而非替人下注"**的预测观，在方法上以严谨性赢得专业用户信任：

- **时序基础模型（Time-series Foundation Model）**：引入预训练时序大模型对收益率曲线、宏观指标进行表征与预测，并以大模型对预测结果做经济学语义解释，实现"**统计模型算数值 + 语言模型讲逻辑**"的双引擎；
- **多期限 / 多情景预测**：支持隔夜、周度、月度等期限，并产出基准 / 乐观 / 谨慎多情景路径；
- **不确定性量化**：引入**保形预测（Conformal Prediction）**区间，所有预测以概率区间而非单点数值呈现，杜绝虚假精确；
- **预测—现实复盘**：每期预测自动留痕，到期后与实际走势对照，生成预测命中率报告，让 AI 能力本身可被考核。

### 5.6 深度研究引擎（Deep Research）

面向"这次降准对超长端利率影响几何？"这类复杂课题，平台提供自主深度研究能力：

智能体接到课题后自主执行：**课题分解 → 检索规划 → 多轮检索（新闻/研报/数据/历史案例）→ 交叉验证 → 反方论证 → 数值测算 → 撰写万字级带引用研究备忘**，全程以流式进度可见、中途可插话纠偏，最终交付一篇每个论断均可点击溯源的研究报告。

### 5.7 NL2Code 策略工坊

将策略验证门槛从"会写代码"降至"会描述思路"：

- 研究员以自然语言描述策略思想（如"当流动性因子转正且 10Y-1Y 期限利差处于历史 30% 分位以下时拉久期"），智能体自动生成策略代码；
- 代码在**隔离沙箱**中执行回测，自动输出净值曲线、年化、最大回撤、胜率等指标；
- 生成代码可查看、可修改、可保存为团队策略资产，支持自然语言迭代调参，形成"**想法 → 代码 → 回测 → 修正**"的分钟级闭环。

### 5.8 个性化记忆系统

平台为每位研究员与每个团队构建分层记忆，实现"越用越懂你"：

| 记忆类型 | 内容 | 应用 |
| ---- | ---- | ---- |
| 语义记忆 | 关注的标的、板块、因子偏好 | 个性化推送与回答侧重 |
| 情景记忆 | 历史对话、研究过的课题与结论 | "上次我们讨论的那个逻辑"可被召回 |
| 程序记忆 | 团队固化的分析 SOP、报告模板 | 一键复用专家工作流 |
| 组织记忆 | 项目空间内共享的资料、结论与批注 | 新人继承团队认知，知识不再随人走 |

记忆的写入、检索、遗忘（TTL 与重要性加权）均受策略管理，并向用户提供**可见、可编辑、可删除**的记忆管理界面。

### 5.9 自动化报告与多端触达

- 日 / 周 / 月报告由智能体定时自动撰写、排版并导出为版式精美的 PDF（含图表、引用、风险提示）；
- 重大事件触发**事件快报**智能体：秒级生成"事件 + 初判 + 历史对照 + 关注要点"卡片；
- 通过飞书 / 企业微信 / 邮件多通道精准触达，支持订阅式推送与 @ 智能体追问。

## 六、智能体编排与协同体系

### 6.1 智能体编排内核

平台采用类"数字投研团队"的多智能体架构，编排内核实现标准 **Agentic Loop**：

```text
用户目标
   │
   ▼
┌──────────┐   ReAct/规划-执行    ┌──────────┐
│  规划者   │───────────────────▶│  执行者   │
│ Planner  │                    │ Executor │
│ (推理模型)│◀────观察结果────────│ (工具调用) │
└────┬─────┘                    └──────────┘
     │ 关键节点
     ▼
┌──────────┐  事实核查/挑错  ┌──────────┐
│  反思者   │──────────────▶│  记忆官   │
│ Critic   │               │  Memory  │
└────┬─────┘               └──────────┘
     │ 通过
     ▼
 结构化交付（结论 + 证据 + 置信度 + 风险提示）
```

- **规划者（Planner）**：由推理型模型驱动，将复杂目标拆解为任务 DAG，支持并行执行与动态重规划；
- **专业智能体集群**：宏观研究员、情报分析员、因子工程师、策略量化员、风控审查员、研报解读员、报告撰稿员各司其职；
- **反思者（Critic）**：对结论做事实一致性核查（结论是否被证据支持）、数字一致性核查与反方论证，是压制幻觉的内生闸门；
- **记忆官**：负责任务中相关记忆的召回与新记忆的提炼写回。

### 6.2 工具体系：OpenAPI 即工具，MCP 即生态

- **OpenAPI 驱动的工具自动注册**：后端任一标准接口经规范解析即自动生成为智能体可调用的工具定义（名称、参数、描述），**新增一个接口 = 智能体新增一项能力**，零重复开发；
- **MCP（Model Context Protocol）开放接入**：客户内部行情系统、Wind/恒生终端、OA、风控系统、数据仓库均可通过 MCP Server 标准协议接入，智能体在对话中直接操作客户既有系统；
- **A2A（Agent-to-Agent）协同（规划）**：支持跨团队、跨厂商的智能体相互发现与委派任务，例如固收智能体向宏观团队智能体请求专题结论；
- **Skills 技能市场**：研究员可将重复性分析流程（如"一二级市场套利分析""信用事件排查 SOP"）封装为自定义技能上传共享，专家经验由此规模化复制。

### 6.3 项目空间：团队级多智能体协作

面向 ToB 场景设计的"项目"模块，让一个部门共享同一个 AI 信息空间：统一的资料库、共享记忆、任务看板与智能体协作记录；领导可查看团队关注热点与 AI 使用情况，协作内容可一键转报告、可追溯，形成机构级知识资产管理。

## 七、大模型工程体系

### 7.1 多模型网关与智能路由

平台经统一模型网关接入国产主流大模型（GLM、DeepSeek、Qwen、豆包等），支持客户自有模型与本地化权重接入：

- **智能路由（Model Router）**：按任务复杂度自动选型——深度推理与策略研判走旗舰推理模型（测试时计算，Test-time Compute），情绪打分、实体抽取等高频任务走轻量模型或端侧小模型，摘要生成走高性价比通用模型；
- **灰度与热切换**：模型供应商故障时秒级熔断切换，新模型经影子运行（Shadow）与评测达标后灰度放量；
- **推理优化**：提示词缓存（Prompt Caching）、推测解码、批处理调度与量化推理，综合推理成本可降低 40%–70%。

### 7.2 模型评测与持续优化（LLMOps）

金融场景对模型可靠性的要求远高于通用场景，平台建立闭环模型质量体系：

- **金融垂域评测集**：覆盖情绪分类准确率、因子归因合理性、工具调用成功率、幻觉率、数值计算正确率等维度，每次模型或 Prompt 变更自动跑分；
- **LLM-as-Judge + 人工双评**：以强模型做初评、专家抽检校准，建立模型版本"升降级"客观依据；
- **反馈闭环**：研究员的采纳、点踩、修正构成偏好数据，驱动 Prompt 迭代与领域微调（SFT/DPO 可选）；
- **Prompt 即代码**：提示词模板纳入版本管理，支持 A/B 测试与一键回滚。

### 7.3 可观测性

面向大模型应用的全链路 LLMOps 监控：Token 消耗与成本、各模型时延与成功率、工具调用链路、检索命中率、任务完成率、用户活跃度画像，使 AI 投入产出对管理层**可度量、可归因、可优化**。

## 八、可信 AI 与合规安全

### 8.1 幻觉治理体系（平台生命线）

| 机制 | 设计 |
| ---- | ---- |
| 证据绑定 | 结论中的每个事实性论断必须挂载引用，无引用的论断在渲染层标记或拦截 |
| 结构化约束 | JSON Schema 强约束输出，正则容错 + 解析失败安全降级（回退中性结论），杜绝脏数据扩散 |
| 工具兜底 | 每个工具执行器统一异常捕获与错误回传，单点失败不中断多轮任务 |
| 批判复核 | Critic 智能体核查结论—证据一致性，重大结论触发多模型陪审团 |
| 边界声明 | 平台明确呈现"AI 辅助判断"属性与置信度区间，不输出具体头寸指令，不越位投顾合规边界 |

### 8.2 安全架构

- **全栈私有化部署**：模型权重、向量库、知识库全部驻留客户内网，数据不出域；支持国产信创环境（国产芯片 / 操作系统 / 数据库适配）；
- **权限与隔离**：RBAC + 数据行列级权限，项目空间逻辑隔离，满足"研究员只能看授权范围"的内控要求；
- **内容安全护栏**：输入输出双向敏感信息检测、提示词注入（Prompt Injection）防护、工具调用白名单与高危操作人工确认；
- **全链路审计**：数据访问、模型调用、工具执行、报告导出全程留痕，支持合规审计追溯；
- **高可用与容灾**：核心服务容器化多副本，关键数据定时备份，推理服务跨节点故障转移。

## 九、平台工程与部署架构

### 9.1 技术选型

| 层次 | 技术栈 | 选型理由 |
| ---- | ---- | ---- |

| 模型层 | 多模型网关 + 国产 GPU 推理池 | 成本可控、自主可控 |
| 交付 | Docker / Docker Compose（可平滑升级 K8s） | 一键部署，弹性伸缩 |

### 9.2 部署形态

| 形态 | 适用客户 | 说明 |
| ---- | ---- | ---- |
| 私有化一体机 | 银行 / 理财子 / 头部券商 | GPU 一体机或驻场部署，数据完全内网闭环 |

### 9.3 实施方法论

采用"**2 周可见、6 周可用、持续进化**"的敏捷交付路径：

1. **第 1–2 周｜环境就绪 & 数据接入**：私有化环境部署、1–2 个核心数据源联通、平台基础功能上线；
2. **第 3–4 周｜知识灌注**：研报与历史新闻批量入库、知识图谱初始化、因子体系与客户词表校准；
3. **第 5–6 周｜场景联调 & 试点运行**：晨会复盘、盘中快报、晚间报告三大场景联调，种子用户试用；
4. **持续运营**：模型评测、技能共创、MCP 内部系统接入、效果数据月度复盘。
