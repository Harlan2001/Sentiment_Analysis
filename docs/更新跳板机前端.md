# 更新跳板机前端

## 1. 构建前端

```bash
cd frontend
npx vite build --base=/ui/sentiment/
```

> `--base=/ui/sentiment/` 确保打包后的静态资源路径和前端路由都带上 `/ui/sentiment/` 前缀，与服务器 Nginx 的 `location /ui/sentiment/` 配置匹配。不加此参数则默认为 `/`，适用于 Docker 部署。
>
> **Windows 注意**：PowerShell 下 `npm run build -- --base=...` 的 `--` 传参方式不生效，改用 `npx vite build --base=...` 即可。

## 2. 上传构建产物

使用 WinSCP 将 `frontend/dist/` 下的所有内容传输到服务器路径：

```
/data/ksfc/app/nginx/html/ui/sentiment
```

## 3. 重启 Nginx（服务器端）

```bash
pkill -9 nginx
cd /data/ksfc/midware/nginx
./usr/sbin/nginx -c /data/ksfc/midware/nginx/nginx.conf
```

> 启动时会有日志相关的警告，不影响使用，可忽略。
