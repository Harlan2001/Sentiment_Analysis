# 更新跳板机前端

## 1. 构建前端

```bash
cd frontend
npm run build
```

## 2. 上传构建产物

使用 WinSCP 将 `frontend/dist/` 下的所有内容传输到服务器路径：

```
/data/ksfc/app/nginx/html/ui/sentiment
```

## 3. 重启 Nginx（服务器端）

```bash
pkill -9 nginx
cd /data/ksfc/midware/nginx
./usr/sbin/nginx -c /data/ksfc/midware/nginx/nginx.conf
```

> 启动时会有日志相关的警告，不影响使用，可忽略。
