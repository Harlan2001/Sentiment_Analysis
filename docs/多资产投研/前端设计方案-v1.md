# 多资产投研平台前端设计方案 V1

> 范围：仅覆盖“债券市场智能分析”工作区。保留现有中国国债能力，整合信用债、国债期货和美债；不包含工作流、研究案例、正式报告、项目、文件库和左侧平台导航改造。
>
> 需求依据：`01-多资产固收投研平台需求文档-PRD.md`、`02-多资产投研引擎技术设计-TDD.md`、`03-信用债资产规格.md`、`04-国债期货资产规格.md`、`05-美债资产规格.md`。

## 1. 设计目标

1. 不按资产复制四套一级页面，以客户研究任务组织导航。
2. 保留现有页面、URL、接口和中国国债默认行为，采用旁路扩展。
3. 公共内容只保存和展示一次；资产方向、目标指标和统计结果保持独立语义。
4. 未具备数据能力时展示真实的缺失、覆盖不足或拒绝状态，不生成模拟业务结果。
5. 延续现有深色、高信息密度、克制的金融工作台风格。

## 2. 导航架构

现有九个页面和URL保留，导航改为两级任务分组：

```text
债券市场智能分析
├─ 市场洞察
│  ├─ 市场                 /market
│  ├─ 市场数据             /info
│  └─ 市场表现             /returns
├─ 研究分析
│  ├─ 因子                 /factors
│  └─ 预测                 /forecast
├─ 组合管理
│  ├─ 关注列表             /watchlist
│  └─ 投资组合             /portfolio
└─ 策略验证
   ├─ 事件研究             /backtest
   └─ 策略生成             /strategy
```

- `/` 继续默认进入 `/market`。
- 不改造静态 `/home`。
- “信息”视觉名称调整为“市场数据”，URL仍为 `/info`。
- “收益”视觉名称调整为“市场表现”，URL仍为 `/returns`。
- “回测仿真”视觉名称调整为“事件研究”，URL仍为 `/backtest`。

## 3. 资产上下文

采用混合资产上下文：

- 市场页默认“全部资产”，不记忆上次选择。
- 因子、市场表现、预测等资产敏感页面继承显式资产和标的。
- 组合页天然为多资产，不受单资产筛选强制限制。
- 资产、标的、期限、时间范围和返回位置写入URL；不使用浏览器隐式记忆改变默认行为。
- 直接进入现有因子和预测页面时，默认保留中国国债语义。

## 4. 市场页

### 4.1 新闻信息流

- 默认展示全部资产相关事件。
- 同一事件只出现一次，不为四类资产复制四张新闻卡。
- 全部资产视图展示精简的资产影响标签。
- 选择单一资产后，突出该资产的方向、解释和关联因子。
- 无充分证据时显示“未分析”或“证据不足”，不得默认中性。
- 保留现有来源、时间、搜索、推荐排序和方向筛选。

新闻详情在标题和来源信息后固定展示“四资产影响”紧凑条：

- 中国国债、信用债、国债期货、美债各占一个位置，只展示方向或分析状态，不展开原因，避免压缩正文阅读空间。
- 已有中国国债分析继续映射为中国国债结论；其余资产只有在后端返回独立影响记录时才展示方向。
- 缺少影响记录时明确显示“未分析”；后端返回证据不足、分析失败或无显著影响时分别展示对应状态，不用“中性”替代。
- 新闻标题、原文、来源、发布时间、关注操作、关联因子和相似新闻继续保留。

方向文案必须匹配目标指标：

| 资产 | 方向表达 |
|---|---|
| 中国国债、美债 | 收益率上行 / 下行 |
| 信用债 | 信用利差走阔 / 收窄 |
| 国债期货 | 价格偏强 / 偏弱 |

### 4.2 右侧市场栏

采用“跨资产快照 + 当前资产详情”：

```text
跨资产快照
中国10Y｜整体信用利差｜T会员多空结构｜美债10Y｜10Y中美利差

当前资产详情
期限曲线 / 持仓趋势 / 活跃因子 / 数据说明
```

只展示已有、口径可靠的指标，不为视觉对称制造综合评分。

## 5. 市场数据页

### 5.1 四资产总览

`/info` 默认进入2×2四宫格：

```text
┌ 中国国债 ──────────┐ ┌ 信用债 ────────────┐
│ 收益率历史走势       │ │ 整体信用利差走势     │
└─────────────────────┘ └─────────────────────┘

┌ 国债期货 ──────────┐ ┌ 美债 ──────────────┐
│ 会员多空结构走势     │ │ 美债收益率历史走势   │
└─────────────────────┘ └─────────────────────┘
```

每块只包含：

- 资产名称和一个当前选择项。
- 一个最新值及一个较前值变化。
- 一张历史走势图。
- 数据日期和质量状态。
- 进入详情的明确入口。

总览只保留一个核心切换维度：

| 资产 | 主图 | 切换维度 |
|---|---|---|
| 中国国债 | 收益率历史走势 | 期限 |
| 信用债 | 整体信用利差历史走势 | 期限 |
| 国债期货 | 会员多空结构趋势 | TS / TF / T / TL |
| 美债 | 美债收益率历史走势 | 实际可用期限 |

### 5.2 资产详情公共结构

- 面包屑和“返回四资产总览”。
- 紧凑的资产切换下拉框，主体一次只展示一个资产。
- 主图全宽，次级图双列，数据表全宽。
- 窄屏下双列自动转为单列。
- 图表支持精确提示、放大和底层数据表展开；总览图不展示这些复杂操作。
- 资产级和图表级分别展示数据日期、来源、覆盖范围和质量状态。

建议URL：

```text
/info                         四资产总览
/info?asset=cgb               中国国债详情
/info?asset=credit            信用债详情
/info?asset=futures           国债期货详情
/info?asset=ust               美债详情
```

旧 `/futures`、`/credit-spread`、`/treasury-spread` 继续可用。

### 5.3 中国国债详情

轻量整合现有数据，不复制市场新闻、因子和预测：

- 选定期限收益率及较前值变化。
- 10Y-2Y利差。
- 选定期限历史走势。
- 当前收益率曲线。
- 各期限数据表。

### 5.4 信用债详情

以信用利差为主：

1. 信用利差历史走势。
2. 信用收益率与同期限国债收益率对比。
3. 当前整体信用曲线。
4. 不同期限利差和历史分位。

持续标注当前仅为整体曲线，不支持评级、行业、主体和单券结论。

### 5.5 国债期货详情

以持仓趋势为主：

1. 品种和合约选择。
2. 会员多空结构趋势。
3. 多头、空头、净持仓和多空比。
4. 四品种结构比较。
5. 会员持仓排名表。

合约切换统一放在会员多空结构走势图右上角，使用下拉框避免横向合约标签挤占图表空间。下拉项和图表标题采用“`TL2612 · 30年期国债期货（TL）`”格式：期限全称为主要信息，品种代码仅作辅助识别。四品种比较与市场表现页面同样显示“2年期 / 5年期 / 10年期 / 30年期”，不单独使用 TS、TF、T、TL 作为客户可见名称。

持续标注数据为中金所会员排名，不等于客户持仓、资金流向、价格收益或交易信号。

### 5.6 美债详情

美债自身分析优先，中美相对价值为第二层：

1. 选定期限美债收益率历史走势。
2. 当前美债收益率曲线。
3. 同期限中国国债与美债比较。
4. 中美利差历史走势和分位。

明确美国市场日期、时区、同日对齐规则；收益率变化不等于价格收益或总回报。

### 5.7 时间范围

- 中国国债、信用债、美债默认近一年。
- 国债期货默认近三个月。
- 公共范围为1月、3月、1年、3年、全部。
- 不记忆上次选择，显式状态写入URL。
- 数据不足时显示实际起止日期，不补零、不向前填充。

### 5.8 页面滚动

四资产总览和各资产详情统一由工作区主滚动容器承担纵向滚动。信用债、国债期货和美债详情复用的旧页面不得保留固定高度或独立纵向滚动容器，鼠标位于图表、指标卡或表格区域时仍应推动整页滚动；图表内部仅处理悬浮提示等图表交互，不截断页面滚轮。

## 6. 因子

- 使用统一因子库，不复制四套因子。
- 支持资产、公共/专属属性、分类和关键词筛选。
- 因子定义和公共证据共享；资产影响、历史有效性和事件研究独立。
- 因子详情采用“共享主体 + 资产影响标签”。
- 活跃度、历史有效性和资产影响分别呈现，不生成单一综合分。
- 直接进入因子页默认中国国债，从其他页面进入时继承显式资产上下文。

## 7. 市场表现

- 原“收益”改名为“市场表现”，保留 `/returns`。
- `/returns` 默认进入四资产近期变化总览，不复用“市场数据”页的完整历史水平图。
- 点击总览卡片或资产选择器后，在同一URL中进入相应资产区域；带有旧 `date` 参数的中国国债收益日历深链继续兼容。
- 中国国债继续使用收益率日历和每日新闻证据。
- 信用债子页面以信用利差日变动为核心，并拆分信用收益率与同期限国债收益率变化；完整利差历史水平和分位仍在“市场数据”。
- 美债子页面以美债收益率日变动为核心，并并列同期限中债和中美利差变化；完整收益率曲线与中美历史比较仍在“市场数据”。
- 国债期货当前只展示会员多空比和多空持仓的日变化，并明确标注为持仓结构观察；只有取得合格价格序列后才能展示价格表现，会员持仓不能代替收益。
- 四资产指标单位不同，不生成统一涨跌排名；总览强调“发生了什么变化”，市场数据页负责回答“历史水平和曲线是什么”。
- 各资产表现子页面使用工作区主滚动容器，不设置互相争夺鼠标滚轮的固定高度内层滚动区。
- 页面公共骨架统一，主体布局允许按资产变化。

## 8. 预测

- 使用统一预测工作台，一次只选择一个资产和目标，不提供默认四资产预测汇总。
- 直接进入时继续默认中国10Y国债收益率。
- 每个资产只显示实际支持的目标、周期和模型结果。
- 数据门槛不满足时显示拒绝或降级原因，不生成模拟预测。
- 保留“结论—概率或区间—证据—假设—失效条件—历史评估”的信息层级。

## 9. 事件研究

- 原“回测仿真”视觉名称改为“事件研究”，保留 `/backtest`。
- 明确结果类型、目标资产、目标指标、事件时间、有效样本、基准、平均效应和不确定性。
- 持续展示“不代表可交易收益或盈利概率”。
- 未来只有满足交易级行情、持仓和成本门槛后，才增加真正的策略回测。

## 10. 数据状态

页面需要区分：

1. 数据缺失。
2. 部分覆盖。
3. 数据质量不足。
4. 降级使用最近有效数据。
5. 业务门槛拒绝。
6. 系统错误。

最近有效数据必须展示原始日期，不能伪装成当日数据。颜色只作为辅助，必须同时提供文字状态。

## 11. V1实现与后续依赖

本版前端优先落地：

- 两级任务导航。
- “市场数据”“市场表现”“事件研究”视觉命名。
- 四资产市场数据2×2总览。
- 市场页顶部四资产范围条与跨资产指标快照。
- 市场表现默认四资产总览及分资产下钻。
- 新闻详情四资产影响紧凑条；当前未取得独立影响记录的资产显示“未分析”。
- 基于现有真实接口的期限/品种切换和趋势图。
- 四资产详情入口、返回总览和资产切换。
- 中国国债轻量整合页。
- 信用债、国债期货、美债现有详情复用及主次调整。

以下设计需要后端形成分资产事实和结果后继续落地，前端不得使用假数据代替：

- 新闻事件的分资产方向筛选，以及信用债、国债期货和美债独立影响结论。
- 公共因子的分资产影响、有效性和事件研究。
- 信用债、美债和国债期货的市场表现结果。
- 非中国国债预测及历史评估。
- 交易级国债期货价格表现和策略回测。
