# 信用债资产规格——简洁明了讲解

> 本文面向不熟悉金融和计算机的管理者，用通俗语言解释《03-信用债资产规格》每个模块准备建设什么、为什么需要这样设计，以及当前数据能做到什么、暂时不能做到什么。

## 一、先用一句话说明这个模块

信用债模块要帮助研究人员回答：

```text
信用债市场最近发生了什么变化
→ 是整体利率变化，还是企业信用风险发生变化
→ 哪些评级、行业、企业或债券受到影响
→ 证据是什么
→ 能否形成研究案例和正式报告
```

第一阶段不要求一定给出精确预测或交易策略。只要有可靠的整体市场数据和事件证据，就应该能够完成定性研究、保存案例并生成报告。

## 二、什么是信用债

国债主要由国家发行。信用债通常由企业、金融机构或其他组织发行。

购买信用债的人不仅要关心市场利率，还要关心发行人能不能按时支付利息和归还本金。因此，信用债研究通常同时关注：

- 整体市场利率；
- 发行人的信用状况；
- 债券是否容易买卖；
- 行业、地区和政策变化；
- 到期、回售、违约和再融资压力。

这也是信用债模块不能简单照搬中国国债模块的原因。

## 三、老板最需要先理解的五件事

### 1. 当前只有整体市场数据，没有完整的企业和单只债券数据

现有系统已经可以取得一条代表整体信用债市场的收益率曲线，并与相近期限的国债进行比较。

但当前数据还不能完整支持：

- 不同评级的信用债；
- 不同行业；
- 不同企业；
- 每一只具体债券；
- 历史评级和真实成交情况。

因此第一阶段可以研究整体市场，但不能把整体市场结论复制成某家企业或某只债券的结论。

### 2. 信用债收益率下降，不一定代表企业信用变好了

信用债收益率大致受到三部分影响：

```text
信用债收益率变化
= 整体市场利率变化
+ 企业信用风险变化
+ 交易和估值等其他影响
```

例如，央行政策使整个债券市场利率下降，信用债收益率也可能下降，但这并不代表企业经营状况改善。

### 3. 新闻中的企业事实可以保留，但不等于能够计算企业价格

系统可以从可靠新闻或公告中识别“某企业评级下调”或“某债券发生展期”。

如果没有该企业或债券的历史价格和完整资料，系统只能保留这个事实并进行文字分析，不能生成精确价格预测、历史统计或交易收益。

### 4. 估值价格不一定是真正能成交的价格

信用债有些交易不活跃。市场提供的估值可以用于研究，但实际买卖时可能没有对手方，或者成交价格与估值有明显差异。

因此正式策略回测不能直接假设所有债券都能按估值价格成交。

### 5. 信用债的精细能力严重依赖专业数据和授权

评级、行业、企业、单券、成交和流动性数据通常需要专业供应商。能否取得这些数据，以及是否允许保存、展示和导出，会直接决定模块能开放到哪一层。

## 四、用一个例子理解信用债研究流程

假设某地产企业出现融资困难，并且评级机构把它列入负面观察名单。

系统希望完成以下工作：

1. 保存评级公告、企业公告和可靠新闻；
2. 区分已经发生的事实和分析师的观点；
3. 判断事件可能增加企业未来还款压力；
4. 分析影响可能先出现在该企业、地产行业或相近评级债券中；
5. 同时检查整体市场利率是否也发生变化；
6. 说明信用风险和整体利率影响不能混在一起；
7. 如果只有事件证据，就形成文字研究；
8. 如果以后取得企业和债券历史数据，再做统计验证或价格预测；
9. 将本次研究加入案例并生成正式报告。

这就是信用债研究闭环。

## 五、第1部分：目标是什么意思

信用债模块的目标是把下面几个环节连接起来：

- 查看整体信用债曲线和信用利差；
- 识别评级、违约、融资等信用事件；
- 分析事件背后的主要影响因素；
- 根据数据能力形成文字判断或定量结果；
- 保存成研究案例；
- 生成正式报告。

统计验证、精确预测和可交易策略属于后续能力，不是完成基础研究闭环的必要条件。

信用债目前排在美债和国债期货之后，但如果客户需求明确、数据授权提前具备，也可以并行推进。

## 六、第2部分：范围是什么意思

### 2.1 当前已经具备什么

系统现在有中短期票据整体收益率曲线，也能计算它与相近期限国债之间的差距。

但目前没有完整的评级、行业、企业和单只债券研究链路，也没有信用债专属预测和正式交易回测。

### 2.2 第一阶段必须完成什么

第一阶段重点完成：

- 展示整体信用债收益率、相近期限国债收益率及两者差距；
- 建立信用债专属事件分析；
- 区分整体利率、信用风险和交易流动性影响；
- 展示异常变化、证据、影响路径、风险和后续关注；
- 把研究内容加入案例并生成报告；
- 建立基础研究组合和集中度展示；
- 数据不足时明确告诉用户能力边界。

### 2.3 哪些能力等数据满足后再开放

取得更细的数据后，系统再逐步开放：

- AAA、AA+、AA等评级分组；
- 城投、地产、金融、产业等行业分组；
- 企业和单只债券研究；
- 分层历史统计；
- 更正式的信用风险计算；
- 有真实成交约束的策略回测。

### 2.4 后续可以继续扩展什么

未来可以进一步研究发行企业、单只债券、评级历史、提前还款、违约概率和评级变化等。

### 2.5 明确不做什么

信用债模块不是：

- 实时做市系统；
- 高频逐笔交易系统；
- 企业授信审批系统；
- 评级机构的替代品；
- 公司内部信用审批结论的替代品。

它提供研究辅助，不替代正式授信和风险审批。

## 七、第3部分：标的模型是什么意思

“标的”就是系统正在研究的具体对象。

信用债可以按照三个主要维度分组：

- 评级，例如AAA、AA+、AA；
- 行业，例如城投、地产、金融、产业；
- 期限，例如1年、3年、5年。

例如“AAA级金融行业5年期信用债”就是一个研究分组。

系统给每个分组设置统一名称，是为了让数据、事件、预测和报告都明确知道自己针对哪一类债券。

每个分组还需要说明：

- 使用哪条国债曲线作为比较基准；
- 使用人民币还是其他币种；
- 按哪个市场交易日历计算时间。

这不是要求第一阶段立刻支持所有分组，而是在数据具备后使用统一方法逐步扩展。

## 八、第4部分：数据需求是什么意思

### 4.1 市场行情数据

理想情况下，需要：

- 不同评级、行业和期限的收益率曲线；
- 相近期限国债收益率；
- 信用债与国债之间的收益率差距；
- 新发行和即将到期的债券数量；
- 成交量或能够反映是否容易买卖的数据；
- 市场估值和真实成交价格之间的差异。

第一阶段主要使用整体曲线，细分数据按供应商能力开放。

### 4.2 企业和债券基本资料

系统未来需要知道：

- 发行人是谁；
- 债券代码、名称和是否仍在存续；
- 企业所属行业和地区；
- 企业评级和债券评级在什么时候生效；
- 票面利率、到期日和特殊条款；
- 企业是否属于城投平台；
- 企业改名、合并等历史关系。

这些资料决定系统能否把新闻、评级和行情准确关联到同一个企业或债券。

### 4.3 需要关注哪些事件

信用债事件包括：

- 评级上调、下调或展望变化；
- 违约、展期或技术性违约；
- 回售、赎回或提前还款；
- 新债发行、取消发行或认购不足；
- 财务和现金流变化；
- 行业、地区和监管政策；
- 再融资、担保和资产处置；
- 重大诉讼、处罚和公司治理问题。

### 4.4 数据需要检查什么

系统必须检查：

- 是否用今天的评级错误替代了过去的评级；
- 已经到期的债券是否仍被放进研究样本；
- 同一企业是否因为改名被重复计算；
- 曲线是否突然出现不合理跳动；
- 同一天不同来源是否互相冲突；
- 非交易日数据是否被错误使用；
- 回测是否使用了当时尚未发布的数据。

### 4.5 数据来源和开放关卡

当前公开数据只能支持整体曲线。更细能力要优先盘点公司已有专业数据，仍然不足时再考虑采购。

每个层级单独检查。整体曲线能够展示，并不代表评级、企业或单只债券已经能够进行正式预测或回测。

用户上传数据也必须检查对象、单位、时间和权限，只能在所属用户或项目范围使用，不能自动覆盖公共数据。

## 九、第5部分：方向和研究指标是什么意思

信用债研究要分清四类变化：

### 信用利差变化

信用利差可以简单理解为信用债比相近国债多出来的收益率。

利差扩大通常说明投资者要求更多风险补偿，往往偏负面；利差缩小通常偏正面。

### 超额收益变化

表示信用债相对比较基准的表现。正值通常代表表现较好，负值通常代表表现较差。

### 信用风险变化

表示企业按时偿还本息的风险是在上升还是下降。

### 信用债收益率变化

收益率上升或下降可能同时包含整体市场利率和企业信用变化。如果没有完成拆分，不能直接说成企业信用变好或变坏。

### 市场表现和基准为什么要严格匹配

计算信用利差时，信用债和国债必须期限相近、估值时间一致、数据口径一致。

整体曲线的收益率变化只能叫市场指标变化，不能称为投资收益。正式总回报还需要价格、利息、到期和特殊条款等信息。

## 十、第6部分：信用债因子体系

“因子”可以理解为可能影响信用债市场的原因。

### 6.1 公共因素怎样用于信用债

货币政策、经济增长、市场资金、风险偏好和行业变化等公共因素继续复用，不重复建立。

但它们在信用债中要说明具体影响的是：

- 整体收益率；
- 信用利差；
- 企业信用风险；
- 相对基准的表现。

例如，整体市场利率下降和企业信用风险上升可以同时发生，两者不能强行合成一个“利好”或“利空”。

### 6.2 信用债专属因素

信用债重点关注：

- 评级和评级展望；
- 还款、违约、展期和回售压力；
- 企业能否继续融资；
- 企业经营、现金流和负债；
- 股东支持、担保和公司治理；
- 债券是否容易成交、估值是否偏离；
- 市场新发行、机构配置和赎回压力。

### 6.3 冲突、状态和影响路径

某类风险长时间没有发生，不代表它已经没有意义。例如违约事件很少见，但不能因此删除违约因素。

“整体利率下降”和“企业信用风险上升”也不是直接冲突，因为两者研究的对象不同。

系统还会记录影响路径，例如：

```text
企业融资受限
→ 市场担心未来还款能力
→ 投资者要求更高风险补偿
→ 信用利差可能扩大
```

整体市场证据不能替代某家企业或某只债券的历史证据。

## 十一、第7部分：事件分析输出是什么意思

每次信用事件分析至少要说明：

- 针对哪类信用债；
- 研究的是收益率、信用利差还是信用风险；
- 指标可能上升还是下降；
- 对市场偏正面、偏负面还是无法判断；
- 影响可能持续多久；
- 影响路径和理由是什么；
- 哪些情况发生后，原判断不再成立。

例如，“再融资受限可能使风险补偿上升，信用利差扩大”。如果后来出现明确的政府支持、担保或融资安排，这个判断可能失效。

如果系统无法把事件可靠地对应到具体企业，就只能在评级、行业或期限层面进行定量分析。企业事实仍然可以保存，但要标明只是事实识别。

## 十二、第8部分：信用债页面准备展示什么

信用债内容会加入现有网站板块，不新增一套一级导航，也不删除原有信用利差页面。

### 页面共同原则

- 页面始终说明正在看整体曲线、评级、行业、企业还是单只债券；
- 历史研究固定当时使用的评级、企业资料和结果版本；
- 评级公告、市场曲线、成交信息、新闻和研报使用不同展示方式；
- 支持证据、反对证据和补充证据分别显示；
- 日频数据不能宣传为实时预警；
- 整体曲线提醒不能自动变成某个企业的风险提醒；
- 报告导出时重新检查数据许可。

### 8.1 市场页面

未来展示不同评级、期限和行业的收益率与信用利差，并告诉用户数据更新到什么时候。

当前第一步以整体曲线为主。

### 8.2 信息页面

集中展示信用事件、评级变化、新债发行、债券到期、流动性和市场供需信息。

### 8.3 因子页面

分别展示：

- 某个信用事件有多重要；
- 某类事件最近是否明显增多；
- 过去类似因素是否在特定评级、行业或周期中有效；
- 当前是否存在相反证据或混合影响。

### 8.4 收益页面

首先展示整体收益率曲线变化。数据满足后，再逐步展示信用利差、利率对冲后的相对表现和完整投资回报。

历史相关和事件发生后的市场反应会清楚区别于正式交易收益。

### 8.5 预测页面

整体信用曲线是第一个预测候选。信用利差、评级、行业、企业和单券预测要分别等待对应数据。

页面可以显示正常预测、降级分析或拒绝预测，并解释依据、反向风险和失效条件。

### 8.6 组合页面

用户可以研究理想信用债配置，也可以建立具体模拟持仓。

系统逐步展示评级、企业、行业、期限和违约事件是否过度集中，并把整体利率风险和信用风险分开。

如果部分债券没有评级或企业资料，要单独显示未覆盖比例，不能自动归到“低风险”。

## 十三、第9部分：什么时候可以做正式统计验证

正式统计验证需要同时具备：

- 足够长的历史市场数据；
- 事件真正发生和公开的时间；
- 当时有效的历史评级；
- 固定的研究指标和比较基准；
- 对重复新闻、后续事件和其他干扰事件的处理规则。

如果条件不足，只能做案例研究或探索性统计，不能宣传成稳定规律或交易收益。

### 统计可以研究哪些结果

从简单到复杂包括：

- 整体曲线收益率变化；
- 基准匹配后的信用利差变化；
- 利率影响被剔除后的相对表现；
- 包括价格和利息的完整总回报。

### 可以怎样分组

按评级、行业、期限、市场状态、事件类型和是否涉及具体企业分组。

### 最终输出什么

输出样本数量、平均变化、命中情况、不确定性、极端损失和不同年份是否稳定，而不是只给一个简单“有效”或“无效”。

## 十四、第10部分：什么时候可以预测

整体信用曲线是首个候选目标。只有历史数据、时间对齐和事后评估通过后，才能进入正式预测清单。

更细的预测需要更细的数据：

- 信用利差预测需要匹配国债基准；
- 评级预测需要历史评级；
- 行业、企业和单券预测需要相应历史行情；
- 不能用整体曲线外推某家企业的精确概率。

预测能力分层开放：

- 先做文字研究；
- 再做方向判断；
- 历史校准通过后才给正式概率；
- 有可靠模型后才给精确变化幅度和范围。

新闻热度高、AI说自己很有信心或用户上传一份文件，都不能绕过数据检查。

## 十五、第11部分：什么时候可以做正式策略回测

整体信用债曲线和评级指数只是研究指标，不是可以直接买卖的一只债券。

正式回测必须落实到具体可交易债券，并确认：

- 历史评级和企业状态；
- 当时真实可用的市场价格；
- 是否可能成交；
- 买卖价差和其他成本；
- 票息和应计利息；
- 到期、提前还款、违约和回收；
- 外部策略服务是否真正支持该债券。

### 为什么估值不能直接当成交价

估值只是市场参考。某只信用债可能长期没有成交，或者只能以明显不同的价格成交。

缺少成交和成本验证时，结果只能叫估值研究、诊断或实验，不能叫正式策略收益。

### 国债期货可以完全对冲信用债风险吗

不能。国债期货主要用于降低与整体利率相关的风险，无法消除企业信用恶化、违约和流动性风险。

## 十六、第12部分：策略生成需要哪些信用债信息

公共策略模块负责通用流程，信用债模块只额外提供本资产特有的信息，例如：

- 当前评级、行业和期限的信用利差；
- 最近利差变化；
- 评级、违约和融资事件；
- 信用债主要影响因素；
- 过去类似事件的研究结果；
- 当前整体利率环境；
- 组合的评级、企业和行业集中度；
- 流动性限制和不可交易警告。

每个信用债策略版本还要明确：

- 研究或交易哪些具体债券；
- 与什么基准比较；
- 是否使用国债期货降低利率风险；
- 多久调整一次；
- 怎样过滤难以成交的债券；
- 对评级、行业和企业设置什么上限；
- 使用什么成本假设；
- 什么情况下停止策略。

整体曲线、评级指数和具体债券不能互相替代。历史策略只能使用当时真实可见的评级、事件和预测。

## 十七、第13部分：信用债怎样接入公共平台

公共平台已经统一定义页面接口、组合模式、风险状态、覆盖率和情景分析方式。

信用债接入时，需要额外告诉公共平台：

- 评级；
- 发行企业；
- 行业；
- 期限；
- 比较基准；
- 信用债收益率、国债收益率和信用利差；
- 数据对应什么时间；
- 当前成交和估值质量；
- 数据实际覆盖了多少对象。

整体利率风险和信用风险必须分开保存。

页面最终用普通用户能够理解的状态表达：数据缺失、只覆盖一部分、质量不足、只能降级分析、业务不允许或系统出错。

## 十八、第14部分：怎样验收信用债模块

原规格列出了30项详细验收要求，可以归纳为以下八组。

### 1. 整体市场能力真实可用

能够展示整体信用债收益率、相近国债收益率、信用利差、数据日期和质量状态。

### 2. 信用事件分析正确

能够识别评级、偿付、融资、企业和行业事件，并区分整体利率、信用风险和流动性影响。

### 3. 不越过数据能力

缺少评级、行业、企业或单券数据时，不生成伪造的细分结论、概率和收益。

### 4. 时间和证据可追查

评级何时生效、事件何时可用、研究使用哪个数据版本都能查清。

### 5. 不混淆不同结果

收益率变化、信用利差、相对表现、总回报和策略收益分别展示。

### 6. 组合和风险计算诚实

整体利率风险和信用风险分开，缺失值不当成零，部分结果显示覆盖范围。

### 7. 策略和套保有真实门槛

正式回测考虑成交、成本、利息、违约和现金流；国债期货套保不会被描述为消除全部信用风险。

### 8. 案例和报告能够独立完成

即使预测和统计验证尚未开放，也可以使用整体曲线和可靠事件证据形成案例及正式报告，并保留历史版本和权限边界。

## 十九、第15部分：还有哪些内容等开发阶段确认

当前剩余问题主要是实施条件，不是顶层产品方向。

### 数据和授权

- 公司供应商能否提供评级、行业、企业、单券和成交数据；
- 是否允许对外展示企业和单券结果；
- 数据多久更新、保存多久。

### 具体计算规则

- 使用哪条国债曲线作为比较基准；
- 信用利差、相对表现和总回报怎样计算；
- 风险参数和覆盖率怎样确定；
- 历史观察窗口和样本规则怎样设置。

### 预测和监测参数

- 哪些目标先进入预测清单；
- 概率和幅度达到什么标准后开放；
- 监测阈值、检查频率和提醒渠道。

### 策略和成交能力

- 哪些具体债券可以进入策略；
- 买卖价差、流动性和无成交怎样处理；
- 违约、提前还款、融资和结算数据从哪里来；
- 信用债和国债期货联合套保何时具备完整条件。

这些参数应在真实数据盘点和开发验证时确定，不提前编造固定数字。

## 二十、管理层可以怎样理解信用债模块的交付

### 第一阶段能够看到什么

- 整体信用债市场收益率和信用利差；
- 真实数据日期和质量状态；
- 信用债专属新闻和事件分析；
- 整体利率、信用风险和流动性影响的区分；
- 主要信用因素及其证据；
- 有边界的定性研究；
- 研究案例和正式报告；
- 对细分数据缺口的明确说明。

### 数据逐步具备后增加什么

- 评级、行业和期限分组；
- 企业和单只债券研究；
- 历史评级和事件统计；
- 信用利差预测；
- 更完整的组合集中度和风险；
- 有真实成交与成本约束的策略回测；
- 信用债与国债期货的套保研究。

### 最终业务价值

信用债模块不是简单增加一张曲线，而是把市场利率、企业信用、行业事件、历史表现和研究报告连起来。

它帮助研究人员避免把整体市场变化误判成企业信用变化，也帮助管理层清楚知道：当前结论研究到哪一层、使用了什么证据、哪些数字可靠、哪些能力仍然依赖数据采购和验证。

## 二十一、常用词语的简单解释

| 词语 | 简单解释 |
|---|---|
| 信用债 | 企业、金融机构等发行的债券，投资者要承担发行人不能按时还钱的风险。 |
| 发行人/主体 | 借钱并发行债券的企业或机构。 |
| 单券 | 某一只具体债券。 |
| 评级 | 对发行人或债券还款能力的等级判断，例如AAA、AA+、AA。 |
| 评级展望 | 评级机构对未来评级可能变化方向的判断。 |
| 收益率 | 债券市场常用的利率指标，不等于投资者实际赚取的收益。 |
| 信用利差 | 信用债收益率高于相近国债收益率的部分，可理解为市场要求的额外风险补偿。 |
| bp | 利率变化的小单位，1bp等于0.01个百分点。 |
| 基准 | 用来比较的参考对象，信用债常与相近期限国债比较。 |
| 流动性 | 一只债券是否容易买到或卖出，以及买卖价格差距是否过大。 |
| 估值 | 市场机构给出的参考价格或收益率，不一定等于真实成交价格。 |
| 票息 | 债券按约定支付的利息。 |
| 应计利息 | 从上次付息到当前日期已经累计但尚未支付的利息。 |
| 展期 | 原定还款时间被延后。 |
| 回售 | 债券持有人按约定条件要求发行人提前买回债券。 |
| 再融资 | 企业通过新借款或发行新债偿还旧债、补充资金。 |
| 集中度 | 组合是否过多集中在某个评级、行业、企业或期限。 |
| DV01 | 整体利率小幅变化时，债券或组合价值大约变化多少。 |
| CS01 | 信用利差小幅变化时，信用债或组合价值大约变化多少。 |
| 套保 | 使用另一项资产降低某一类风险，但通常不能消除全部风险。 |
| 总回报 | 综合考虑价格变化、利息和其他现金流后的投资表现。 |
| 策略回测 | 用过去的数据模拟一套具体买卖规则，检查其历史表现。 |
