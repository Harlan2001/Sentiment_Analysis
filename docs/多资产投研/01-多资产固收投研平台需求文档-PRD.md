# 多资产固收投研平台需求文档（PRD）

> 状态：Draft  
> 版本：v0.1  
> 日期：2026-11-25  
> 范围：中国国债、信用债、中国国债期货、美债  
> 关联文档：本目录下《多资产投研引擎技术设计》及三份资产规格

## 1. 背景

当前系统已经形成以中国国债为中心的多条相关能力，但不是一条全自动流水线：

1. 新闻分析串联 `analysis`、`news_factor` 和新闻重要性评分，方向口径固定为中国国债；
2. 因子事件研究由离线批处理读取 `news_factor` 和 10Y 中国国债收益率，结果供因子详情和“回测仿真”页展示；
3. 日/周/月预测独立读取新闻分析和收益率数据生成，不以事件研究或研究组合作为正式上游；
4. 账号级研究组合、组合配置约束建议、政策解读、研报分析和新闻总结是相对独立的工作流；
5. DreamStrategy 链路由用户确认提示词后触发外部代码生成和正式回测，本系统负责标的、代码、成交和指标验收以及版本保存。

本项目保留上述中国国债能力和现有 DreamStrategy 链路，通过渐进式扩展支持新增资产，不改变既有中国国债业务逻辑。

信用债、国债期货和美债目前仅具备局部能力：

| 资产 | 当前能力 | 主要缺口 |
|---|---|---|
| 信用债 | 整体信用曲线、信用利差展示与同步 | 无评级/行业/主体分层，无资产专属事件分析、预测、回测和策略链路 |
| 国债期货 | 持仓排名、趋势和同步 | 无完整行情、连续合约、换月、基差/CTD、事件验证和交易成本回测 |
| 美债 | 2Y/10Y/30Y 曲线、中美利差 | 无美债专属新闻因子、宏观事件、预测、回测和策略链路 |

当前代码未发现商业金融数据供应商适配器或通用联网搜索工具。已接入的新增资产数据来自中债、中金所和美国财政部公开接口；新闻已存在库内来源和分析链路，但采购、入库及授权边界不能仅由本仓库确认。Agent可查询库内新闻和已授权飞书内容，不等同于互联网搜索。

当前上传能力包括：文本型政策PDF（单文件20MB）、研报PDF解析与AI分析、固定格式研究组合CSV，以及个人Skill附件解析；尚无面向三类新增资产的通用结构化行情或主数据导入能力。目标上传范围不得写成当前已实现能力。

当前中国国债因子库使用POLICY、MACRO、LIQUIDITY、RISK、SENTIMENT、INDUSTRY六类，已有新因子相似度发现、新闻活跃度、事件研究和新闻重要性评分。现有新因子可按相似度直接入库或丢弃，尚不具备独立AI审核和完整生命周期；现有新闻重要性是既有综合评分，不能解释为新增资产的因子历史有效性。

本项目拟建设统一但不生硬的多资产研究工作台。统一的是客户任务、证据链、时间与状态表达；资产专业逻辑、目标指标、行情结构和可交易边界由各资产规格定义。

## 2. 产品目标

### 2.1 核心目标

1. 帮助固收研究员快速发现四类资产的重要变化，理解原因、影响方向和跨资产传导，并下钻到原始证据与历史验证。
2. 首个可交付版本优先形成“多资产市场研究→事件与证据→因子与预测→研究案例→正式报告”的完整研究闭环；AI预测及统计验证不是闭环完成的强制条件，证据不足时仍可形成有边界的定性研究与报告。
3. 可交易策略是进阶能力，仅对行情、可交易标的和 DreamStrategy 支持范围均已确认的资产开放；现有已验证链路保持可用。
4. 所有研究结论必须标注资产、标的、目标指标、方向语义、数据截止时间、证据、置信度和失效条件。
5. 相同数据快照、模型版本和参数应能够复现相同研究结果。
6. 支持中国国债与信用债、国债期货、美债之间的跨资产联动研究。

### 2.2 成功标准

- 三类新增资产均可完成“异常发现—事件解释—因子提取—风险与后续关注”的研究闭环。
- 具备开放条件的统计验证能够说明样本、目标指标、时间对齐、基准和稳定性；不满足条件时明确降级。
- 页面不因数据缺失而无限加载，必须显示数据状态和补救动作。
- 事件研究和正式策略回测均通过各自适用的时间与未来函数检查，二者不混用。
- 已开放的策略版本可追溯能力证据、确认内容、情报快照、代码、执行尝试、金融模型版本、指标、日志和验收结论；“可调用”与“正式研究可用”分开标识。
- 新增资产不复制三套平行代码，核心流程复用多资产投研引擎。
- 首个可交付版本可以从真实证据完成研究案例和正式报告；组合风险、持续监测提醒和新增资产策略回测按数据、技术依赖和业务优先级分期接入，但目标入口、页面结构和扩展契约保留完整设计。

## 3. 非目标

第一阶段不包含：

- 真实券商、交易所或资管系统下单；
- MVP不接入真实交易账户，不建设成交管理、实时账户监控、会计核算、真实持仓估值或真实 PnL；真实持仓仅预留权限、组织隔离和数据来源扩展边界；
- 信用债全市场逐券高频做市；
- 国债期货分钟级或更高频量化交易；
- MVP不建设复杂知识图谱、图数据库、自动因果推断引擎或依赖人工常态审批的因子平台；
- MVP不强制合成因子综合分，也不强制把冲突信号压缩为唯一方向；
- 自动根据单条新闻直接开仓；
- 无授权数据的抓取或绕过数据许可；
- 将研究组合解释为真实投资账户。

## 4. 用户与场景

### 4.1 目标用户与优先级

| 优先级 | 用户 | 核心任务 |
|---|---|---|
| 首要 | 固收研究员 | 发现市场变化，解释原因与传导，核查证据和历史样本 |
| 次要 1 | 投资经理 | 判断组合暴露、关注重点和研究结论的投资含义 |
| 次要 2 | 量化及数据研究员 | 检查数据、样本、时间口径、统计稳定性和复现条件 |
| 次要 3 | 债券交易员 | 在已开放范围内确认交易标的、执行约束和策略风险 |

平台管理员是运维与治理角色，不作为产品决策场景的首要用户。上述排序是当前设计基线，可根据真实业务反馈调整。

### 4.2 核心场景

1. 从总首页发现跨资产异常、重要事件和需要立即关注的变化。
2. 在行情、信息、因子、收益反应等任务板块内比较资产，并按需下钻到资产或标的。
3. 查看主要因子、方向、强度、置信度、证据、风险和历史表现。
4. 检查事件发生后的价格、收益率、信用利差、期限利差或合约收益反应。
5. 在具备数据条件的资产上查看预测、成立条件、失效条件和事后评估。
6. 将新闻、因子、事件、资产或标的加入关注列表，并管理研究组合。
7. 对满足开放条件的因子执行统计验证；对满足外部依赖的标的生成并回测可交易策略。
8. 生成新闻总结、政策解读或综合研究报告，并回溯原始证据。

## 5. 产品原则

1. **操作一致、语义分离**：页面和流程统一，资产方向口径不得混用。
2. **信号可追溯**：任何结论都应能够回到原始新闻、行情和模型快照。
3. **禁止未来函数**：回测只允许使用当时已经可获得的数据。
4. **新闻不直接触发交易**：新闻和因子仅用于方向确认、风险过滤和参数约束。
5. **无数据不造数**：缺少行情或样本时必须降级并显式提示。
6. **研究与交易隔离**：本平台输出研究建议，不执行真实交易。
7. **现有前端增量兼容**：保留现有一级板块、页面、路由及全部当前数据内容；新增资产与研究能力以子板块或新增内容嵌入，不以重构替换现有能力。
8. **来源分层、授权优先**：专业信息供应商为主要金融数据来源，官方数据用于核查与补充；联网搜索、用户上传和内部数据按授权与用途受控使用。
9. **模型不是实时数据源**：大模型负责提取、理解和推理，不得自行生成实时行情、评级、宏观公布值或交易价格。
10. **风险值与覆盖率并列**：风险指标、数据质量和计算状态分别展示；缺失风险不得按零处理，部分结果不得冒充全组合结果。
11. **本币优先、换算可追溯**：多币种组合保留原始币种和市场风险因子；跨币种换算必须记录汇率来源、时点和版本，不因统一基准币种而抹平市场差异。
12. **目标产品与实施阶段分离**：从完整客户研究需求设计有业务价值的页面、入口和扩展契约，MVP只决定开发优先级和验收顺序，不缩减最终产品设计；暂缺数据或技术条件时不得用虚假数据、模拟结果或客户可见的“尚未开发”状态代替真实业务结果，依赖、实现状态和验收门槛在内部设计与台账中持续记录。

## 6. 网站信息架构与用户链路

采用“保留现有一级板块、板块内按需增加资产子板块”的增量方案：

1. 保留当前“市场、信息、因子、收益、预测、关注列表、投资组合、回测仿真、策略生成”一级板块及现有首页、路由和全部当前数据内容，包括已有期货持仓、信用利差和中美利差子板块，不重新组织或替换。
2. 在每个现有板块内部，根据该板块的功能和数据能力增加信用债、国债期货、美债子板块；存在专业差异时再下钻期限、评级、行业、主体、品种或合约。
3. 新增内容不得改变现有中国国债及已有数据子板块的默认展示和业务行为；可通过子标签、分区、卡片或下钻入口增量呈现。
4. 对真正共享的新闻原文、公共事件、证据和跨资产传导，不按资产复制页面；同一事件详情分别展示已分析资产的独立影响，不强制生成四类资产结论。
5. 专业行情、预测、组合、回测和策略按资产差异化呈现。未来计划支持的功能可完成目标交互设计并预留入口；实际页面只呈现真实数据、分析结果及其覆盖和限制，不用占位数值或模拟金融结果伪装能力。
6. 因子板块承载活跃度、历史有效性、事件研究和统计验证；收益板块承载市场表现、历史相关性和事件市场反应；回测仿真板块只对满足交易级门控的新能力展示可交易策略回测。现有中国国债“回测仿真”实际展示事件研究，保留旧页面并标注结果类型，本阶段不删除或迁移。

典型链路：

```text
现有首页或一级板块
  → 板块内资产子板块（按功能与数据能力出现）
  → 现有内容或新增资产内容
  → 公共事件详情与多资产影响对比
  → 因子及历史统计验证
  → 预测或关注列表
  → 投资组合/风险/情景或策略研究
  → 轻量研究案例与版本化报告复盘
```

路由以现有结构为兼容边界；新增资产不另建一套重复一级导航，也不预设每类资产在九个板块中都具备相同数据能力。跨页面上下文通过显式URL传递资产、标的、数据时点、快照/版本及可选研究案例；页面按业务需要继承，不使用不可见全局状态强制同步。历史研究以版本ID或快照ID复现，日期只作为查询条件，不能替代版本引用。

## 7. 功能需求

### 7.1 资产与标的

| 编号 | 需求 |
|---|---|
| FR-ASSET-001 | 需要资产语义的板块必须提供统一资产选择器，并记住用户最近选择；共享事件页不得强制复制为四份。 |
| FR-ASSET-002 | 每类资产必须声明标的、基准、方向轴、时区、交易日历和支持期限。 |
| FR-ASSET-003 | 页面必须显示数据截止时间、更新时间和数据质量状态。 |
| FR-ASSET-004 | 研究结果必须标注资产范围和标的，不允许无资产归属的方向结论。 |
| FR-ASSET-005 | 每项功能必须声明实际支持的分析粒度、数据覆盖和下钻限制；事实提取粒度不得被误解为定量分析、预测或回测粒度。 |

### 7.2 数据与行情

| 编号 | 需求 |
|---|---|
| FR-DATA-001 | 优先盘点和复用公司已有专业信息供应商、接口、数据库及授权；供应商不能覆盖时再评估官方补充、其他授权数据或新增采购。 |
| FR-DATA-002 | 数据源适配必须统一标的、字段、单位、时间、来源和质量状态，不同口径不得无条件混合。 |
| FR-DATA-003 | 每个来源必须记录使用、缓存、存储、展示、再分发及向外部AI服务传输的授权范围；授权不足必须阻断。 |
| FR-DATA-004 | 更新频率按来源发布频率、市场日历、现有采集能力和研究需求配置，不要求统一实时；分钟级或实时行情不作为MVP强制条件。 |
| FR-DATA-005 | 同步必须幂等并支持失败重试、人工补跑和过期提示，记录数据周期、发布时间、可用时间、获取时间和分析生成时间。 |
| FR-DATA-006 | 质量门控按资产、标的、指标、功能和时间范围执行，区分展示级、分析级、验证级和交易级，不因局部异常关闭整个资产。 |
| FR-DATA-007 | 页面区分缺失、过期、重复、异常值、来源冲突、证据不足、权限不足和外部服务故障，并说明恢复条件。 |
| FR-DATA-008 | 在授权范围内保存原始批次或响应、内容哈希、标准化历史、修订关系和研究快照；修订不得覆盖历史决策使用版本。 |
| FR-DATA-009 | 用户上传的非结构化材料用于证据与观点分析；结构化数据经字段、单位、标的、时间和质量校验后才可进入定量功能。 |
| FR-DATA-010 | 用户上传数据默认限定于用户或授权组织，不覆盖供应商数据、不自动公开；当前仅已实现的格式和用途可标为可用。 |

### 7.3 新闻、政策与事件

| 编号 | 需求 |
|---|---|
| FR-EVENT-001 | 事件事实、证据来源和资产影响分离；一个公共事件可关联多个来源及零至多条资产或标的影响记录。 |
| FR-EVENT-002 | 新闻和正式政策文件可形成候选事件，但须经过事实识别、来源核查和去重；研报默认作为观点、预测或研究证据。 |
| FR-EVENT-003 | 证据必须区分已发生事实、分析观点、预测、市场预期和已确认的未来安排；预期和预测不得直接混入已发生事件的统计样本。 |
| FR-EVENT-004 | 影响分析状态必须区分未分析、无显著影响、证据不足、存在影响和分析失败；缺少影响记录不得解释为无影响。 |
| FR-EVENT-005 | 每条影响独立保留资产、标的、目标指标、方向、周期、传导路径、依据、强度、置信度和失效条件，不强制覆盖全部资产。 |
| FR-EVENT-006 | 分析结果必须保留模型、提示词版本、数据快照和生成时间，并可按事件、来源、资产、标的、因子、方向、时间和模型筛选。 |
| FR-EVENT-007 | 事件和证据必须区分事件发生时间、信息发布时间、现实可用时间、系统入库时间及决策时间。 |
| FR-EVENT-008 | 联网搜索仅按研究需要触发，结果须保存来源链接、发布时间、获取时间和证据；未经核查不得作为权威行情或正式统计样本。 |
| FR-EVENT-009 | 联网搜索不可用时可基于已有可靠信息继续分析，但必须标注数据截止时间、证据范围和限制。 |
| FR-EVENT-010 | 建立统一证据引用与详情契约，复用现有新闻、因子、事件等详情路由；引用保留证据类型、稳定ID、版本、来源、可用时间、支持/反驳/补充关系及返回上下文。 |
| FR-EVENT-011 | 统一下钻不抹平专业结构：新闻显示原文与来源，政策显示条款，研报显示观点和假设，行情显示指标/单位/时点，统计结果显示样本与方法；正反证据并列，缺少反证不等于结论已证实。 |

### 7.4 因子

| 编号 | 需求 |
|---|---|
| FR-FACTOR-001 | 因子体系采用公共核心因子、资产专属命名空间和版本化别名；因子具有稳定ID、标准名称、分类、适用资产、版本和状态。 |
| FR-FACTOR-002 | 同义词归并须保留AI原始标签、标准化结果和映射依据；名称相似但经济含义、事实与预期不同的概念不得错误合并。 |
| FR-FACTOR-003 | 因子定义不绑定固定利好或利空；因子事件按资产、标的、目标指标、周期和证据独立保存方向与市场效果。 |
| FR-FACTOR-004 | 新因子优先匹配正式因子及别名；未可靠匹配时进入候选，经独立AI审核和程序规则校验后自动发布或保留候选，不依赖人工常态审批。 |
| FR-FACTOR-005 | 因子生命周期支持候选、审核中、正式使用、休眠、观察、暂停、合并、拒绝和退休；所有变更保留原因、证据、生效时间、版本和影响范围。 |
| FR-FACTOR-006 | 因子字典状态与资产×标的×指标×周期的应用资格分开；单一应用失效不得导致公共因子全局退休。 |
| FR-FACTOR-007 | 事件重要性、因子活跃度和历史有效性分别计算和展示；MVP不强制综合分，现有中国国债新闻重要性算法保持不变。 |
| FR-FACTOR-008 | 活跃度基于去重事件、明确窗口和必要频率标准化；历史有效性显示有效样本、命中率、基准、统计不确定性和适用市场阶段。 |
| FR-FACTOR-009 | 页面允许按三个评价维度分别筛选和排序；数据不足时显示证据不足，不得以重要性或活跃度替代历史有效性。 |
| FR-FACTOR-010 | 仅在标的、目标指标、方向口径和周期可比时判定直接冲突；中性、混合、冲突和无法判断必须分开。 |
| FR-FACTOR-011 | 缺乏可靠汇总依据时保留冲突；研究摘要须保留主导因素、反向证据、适用条件和失效风险，冲突继续传递到预测、组合、报告和策略情报包。 |
| FR-FACTOR-012 | 多模型或定量汇总必须标注模型、计算规则、权重来源和验证依据；不得在缺少持仓与行情时推断客户实际损益。 |

### 7.5 收益与事件研究

| 编号 | 需求 |
|---|---|
| FR-RETURN-001 | 市场表现采用统一结果契约，表达资产、标的、指标、初始/结束值、变化值、单位、起止时间、周期、方法、基准、来源、数据版本和质量状态；计算由资产专属计算器完成。 |
| FR-RETURN-002 | 中国国债保留现有收益率变化；信用债MVP以整体曲线收益率变化为基础；国债期货MVP保留会员持仓变化；美债复用2Y/10Y/30Y收益率变化。价格、总回报、信用利差验证、合约收益和策略PnL按条件开放。 |
| FR-RETURN-003 | 收益率、信用利差使用bp等明确单位，不等于投资收益；期货持仓、价格变化与交易PnL分开；债券总回报不得由收益率bp替代。 |
| FR-RETURN-004 | 统一结构不代表指标可直接数值比较，不得用不同指标原始变化值生成统一资产或投资收益排名。 |
| FR-RETURN-005 | 时间对齐保存原始时间、时区、精度、可用时间、映射规则和结果；只有日期时默认映射至信息可用后的下一有效交易时点，周末和节假日不丢弃。 |
| FR-RETURN-006 | 精确时间按市场交易时段和行情观测频率映射；可用时间不可靠时阻断严格验证和策略回测，只有日频行情时不得宣称盘中反应。 |
| FR-RETURN-007 | T、T+1、T+5、T+20必须说明基准时点、市场日历、起点、计数方式和用途；事件观察结果不得解释为可成交收益。 |
| FR-RETURN-008 | 中美跨市场事件分别计算源市场与目标市场窗口，保留各自时区、交易日、先后顺序和映射规则，不要求相同T+N对应同一自然日。 |
| FR-RETURN-009 | 同一客观事件的重复报道只作为证据；主事件、子事件、事件族和独立新增信息分别标识。 |
| FR-RETURN-010 | 保存观察窗口重叠、干扰事件、样本资格和排除原因；处理规则预先定义，可采用剔除、缩窗、分组或稳健性分析，不得按事后结果选择样本。 |
| FR-RETURN-011 | 历史相关性、事件研究和策略回测使用独立契约、标签、能力状态和验收标准；三者均不得直接证明因果。 |
| FR-RETURN-012 | 正式事件研究按资产、事件类型、标的、指标和周期设置门槛，输出有效样本、效应、命中率、基准、不确定性、适用市场阶段和局限。 |

### 7.6 预测

| 编号 | 需求 |
|---|---|
| FR-FORECAST-001 | 预测能力按资产、标的、目标指标、预测周期和预测类型建立白名单；定性研究、方向、概率、幅度和区间预测分别门控，不因字段存在而默认开放。 |
| FR-FORECAST-002 | 中国国债保留现有10Y日/周/月预测；美债优先评估2Y/10Y/30Y收益率方向；国债期货取得可靠价格历史后开放价格方向/幅度/波动状态；信用债先评估整体曲线，基准匹配后再开放信用利差，细分目标等待对应数据。 |
| FR-FORECAST-003 | 新增资产以未来1/5/20个有效观察日作为日/周/月展示基线，保存实际起止时点、市场日历和观察日数；展示标签不等于固定自然日。预测周期、生成频率和更新频率分别定义。 |
| FR-FORECAST-004 | 每次预测保存独立版本、生成时间、数据截止时间、输入证据、模型和提示词版本；定期、重大事件或上游数据变化可触发更新，但不得覆盖历史预测或尚未到期的预测。 |
| FR-FORECAST-005 | 能力不足时依次允许降级为方向判断或定性研究，并可因证据不足、信号冲突或目标不满足生成门控返回业务拒绝；拒绝预测是正常业务结果，不等于市场中性、研发进度或执行失败。 |
| FR-FORECAST-006 | 正常或降级预测须保留目标、周期、核心依据、假设、反向风险、失效条件；拒绝或降级须说明原因、证据范围和恢复条件，不强制输出概率、BP、点值或区间。 |
| FR-FORECAST-007 | 模型判断置信度、证据质量、历史概率校准和统计不确定性分别展示；AI自报置信度不等于真实准确概率，未校准概率不得作为正式概率。 |
| FR-FORECAST-008 | 联网搜索按数据新鲜度、重大事件、来源缺口、事实冲突或用户要求触发，优先核查官方/原始来源；搜索失败后根据现有证据继续、降级或拒绝，不得补造事实。 |
| FR-FORECAST-009 | 多模型结果独立保存和评估；仅在目标、周期、输入和口径可比且聚合规则、权重与历史校准明确时生成正式共识，否则保留冲突或拒绝综合预测。 |
| FR-FORECAST-010 | 预测按资产、标的、指标、周期、模型版本和市场阶段事后评估：方向比较命中率与基准，概率使用Brier Score和校准，幅度使用MAE/RMSE，区间评价覆盖率与宽度，并同时披露覆盖率、拒绝率和降级原因。 |
| FR-FORECAST-011 | 历史评估区分真实历史时点预测与事后历史模拟；后者若使用当前模型可能含事后知识，不得宣称严格无未来信息。历史预测不得按事后行情修改。 |

### 7.7 关注列表与研究组合

| 编号 | 需求 |
|---|---|
| FR-WATCH-001 | 关注列表保留普通收藏，并扩展为多资产研究监测中心；可监测资产、标的、指标、事件和因子，监测对象使用稳定ID、版本及资产语义，不只保存标题和跳转链接。 |

| FR-WATCH-003 | 监测频率不得高于可靠数据更新能力，页面和提醒标注数据所属时间、获取时间及规则评估时间；基于日频或发布频率的数据不得描述为实时预警。 |
| FR-WATCH-004 | 同一数据批次或同一事件族对同一规则只形成一次主提醒，后续修订、持续越界或状态恢复按版本化策略处理，避免重复轰炸并保留审计。 |

| FR-PORT-002 | 研究组合分为目标配置组合和模拟持仓组合：前者表达资产配置权重与假设资金，后者表达具体标的、数量/面值、方向及假设风险参数；两者均不代表真实投资账户。 |

| FR-PORT-004 | 公共契约包含组合模式、资产类型、标的、方向、币种、数据时点和输入来源，并按模式与资产设置必填字段；目标权重、假设资金、数量、面值、市值、成本、名义敞口和保证金使用独立语义。 |

| FR-PORT-007 | 组合级新闻、因子、预测和策略结果按能力状态引用；研究组合不得自动进入真实交易或绕过策略白名单。 |

### 7.8 组合风险与情景分析

| 编号 | 需求 |
|---|---|
| FR-RISK-001 | 统一风险结果至少表达风险类型、风险因子、方向、数值与单位、币种、市场、数据时点、参数来源、计算方法、适用范围、结果状态、数据质量、覆盖率和缺失原因；具体金融计算由资产专属计算器完成。 |
| FR-RISK-002 | 利率风险支持市值、久期类型、修正久期和DV01。现有`duration_years`仅为未分类的用户录入久期，未确认类型前不得作为正式修正久期或用于正式DV01。 |
| FR-RISK-003 | 明确DV01符号约定，并分别展示净风险暴露和总绝对风险暴露；不同币种、市场和风险因子分别管理，未经可靠汇率不得直接相加。 |
| FR-RISK-004 | 覆盖率必须说明分母：债券可按有效风险市值，期货可按同类合约持仓或名义敞口；不同口径不直接合并，无法建立全组合分母时按资产展示覆盖率和有效标的数。 |
| FR-RISK-005 | 公共风险分类与资产专属指标并存，不建立缺少金融及统计依据的全站综合风险分；风险等级与数据质量等级分别展示，缺失不等于低风险、零风险或高风险。 |
| FR-RISK-006 | 信用债在数据满足后开放评级、主体、行业、期限和事件集中度、基准利率风险、信用利差风险及CS01；国债期货按具体合约展示名义敞口、保证金、杠杆、DV01、基差、到期和换月风险；美债MVP以美元本币利率及期限风险为基线。 |
| FR-RISK-007 | 流动性定量结果必须基于可靠成交量、成交额、买卖价差、成交频率或明确代理指标；中金所会员排名不得替代用户持仓、完整市场成交、保证金或流动性数据。 |
| FR-RISK-008 | 美债当前收益率曲线只支持收益率研究，不自动支持单券市值、DV01、价格回报、总回报或持仓损益；美元本币为MVP正式口径，人民币即期折算、未对冲回报和对冲后回报分别门控。 |
| FR-RISK-009 | 国债期货套保按定性方案、静态套保比率/合约数、完整历史套保回测三级开放。前两级进入现有组合/风险板块；只有组合与期货DV01可靠或明确标注为假设时，确定性程序才可给出理论合约数、整数候选、目标套保率和剩余DV01。 |
| FR-RISK-010 | 套保必须显示方向、风险因子、币种、数据时点、曲线/基差不匹配、CTD切换、换月、保证金和过度套保风险；期货只能对冲已匹配的基准利率风险，不得声称消除信用利差、违约或流动性风险。参数不足时只输出定性方案，AI不得猜测正式合约数、保证金或损益。 |
| FR-SCENARIO-001 | MVP以版本化规则情景为主，支持预设情景、用户自定义冲击、定性分析及数据满足后的基础敏感度损益；历史情景仅在历史数据、时间对齐和风险因子口径通过后开放。 |
| FR-SCENARIO-002 | 情景区分基准利率、信用利差、期货价格、期货基差和汇率风险因子，禁止重复计入信用债总收益率及其组成冲击，也不得无依据叠加期货直接价格与隐含利率价格冲击。 |
| FR-SCENARIO-003 | DV01、CS01等结果标记为一阶敏感度近似，不称为精确重估、完整实际PnL、未来预测或最大可能亏损；部分覆盖可以展示，但必须同时展示覆盖率、缺失原因和不适用范围。 |
| FR-SCENARIO-004 | AI只能提出候选情景、解释机制或建议假设参数；候选参数经用户确认或预设规则校验后，正式金融数值由确定性、可复核程序计算。 |
| FR-SCENARIO-005 | VaR、ES、蒙特卡洛、完整现金流重估和关键期限风险模型不是MVP强制要求。 |

### 7.9 回测

| 编号 | 需求 |
|---|---|
| FR-BT-001 | 页面和术语必须区分历史相关性、因子事件研究、收益代理验证与可交易策略回测。 |
| FR-BT-002 | 必须执行未来函数、空交易、异常指标和样本不足检查。 |
| FR-BT-003 | 策略回测必须具备可交易标的、当时可用行情、交易规则、仓位、成交模拟、成本和风险指标；代理变化或事件命中率不得称为策略PnL或盈利概率。 |
| FR-BT-004 | 不同资产的换月、久期、利率对冲和汇率规则由资产规格定义；数据不满足时不得开放对应回测。 |
| FR-BT-005 | 策略标的能力登记为`not_enabled/configured/basic_validated/formal_research_backtest`，状态必须附证据、验证时间和限制。白名单、接口接受、单次运行或代码注释均不能单独证明正式支持。 |
| FR-BT-006 | 正式研究回测必须版本化保存成本、成交、资金/持仓结算和收益/现金流核算模型；零成本、成本不完整或外部服务无法验证应用的结果只能标记为诊断、实验或理论结果。 |
| FR-BT-007 | 业务策略版本与执行尝试分离。标的、模式、逻辑、区间、参数、仓位、成本、资本或关键数据变化创建新业务版本；同一请求的幂等重试和不改变语义的有限技术修复可以形成同版本新尝试。 |
| FR-BT-008 | 零成交必须区分无信号、数据不足、订单被拒、资金不足、代码失败和标的能力问题。普通策略零成交不必然是技术失败，但不能形成盈利能力证据；受控预期成交测试用于验证基础成交能力。 |
| FR-BT-009 | 独立展示生命周期、研究质量和表现评价。正式研究可用只表示方法、数据、成本、执行和复现通过，不代表盈利、未来适用或可交易；亏损策略仍可形成有效研究结论。 |
| FR-BT-010 | 评价按资产和策略类型选择指标并明确资金分母；套保策略重点评价风险降低、剩余风险、资金占用和成本。时间顺序划分、样本外结果及生成/调参/选择历史必须可追溯，不因反复测试宣称独立样本。 |

### 7.10 策略生成

| 编号 | 需求 |
|---|---|
| FR-STRAT-001 | 系统按需生成版本化结构化情报包，分层保存标的/能力、市场与历史数据引用、需求/成本/成交/执行约束，以及可选事件因子、历史证据、预测和组合风险；同时保存来源、时点、版本、质量与缺失。情报包按令牌预算筛选、去重和处理冲突，不倾倒全部原始内容。 |
| FR-STRAT-002 | 设计时上下文与历史运行特征集分离。历史决策只能使用当时可用信息；当前新闻、当前预测、当前组合风险、事后统计和仅按当前模型回放的“历史预测”不得注入过去决策。 |
| FR-STRAT-003 | 每个发生实质变化的业务策略版本必须由用户确认后才能执行；仅展示名称变化可复用确认。同版本重试若改变金融或执行语义必须升版并重新确认。确认页展示标的及能力、资本、区间、规则、方向/仓位、成本、成交假设和主要风险。 |
| FR-STRAT-004 | 确认后冻结结构化需求并校验生成代码与需求一致性。当前集成链路无法在外部执行前取得代码时，不虚构本地预执行审核；正式能力须额外满足外部隔离、资源/超时、网络权限、幂等和可复核执行契约，否则仅标记实验性。 |
| FR-STRAT-005 | AI生成代码和外部输入均按不可信内容处理，不得读取本地文件、环境变量、密钥、其他用户数据或未经授权联网。系统记录请求去重、状态、执行尝试和失败；外部服务无幂等保证时不得承诺恰好执行一次。 |
| FR-STRAT-006 | 新闻、因子、预测和组合风险只能按已验证能力进入情报包。未经统计验证的AI预测不得作为自动触发器，组合风险只用于预算、限制及不新增/加仓/减仓/平仓/套保约束；不得通过简单平均或无确认流程自动生成并回测策略。 |
| FR-STRAT-007 | 用户明确选择不符合策略能力门控的标的时返回业务拒绝，不静默替换。现有入口和白名单通过兼容适配保留；资产类别、研究指标、可交易标的、主力/连续序列分别建模。 |

## 9. 跨资产联动

MVP优先支持以下关系：

1. 美债收益率、中美利差 → 中国国债方向与期限结构。
2. 中国国债现券曲线 → 国债期货价格、基差和 CTD。
3. 无风险利率、流动性和风险偏好 → 信用债收益率与信用利差。
4. 同一政策或宏观事件在四类资产中的方向差异对比。

跨资产研究同时保留自然语言解释和轻量结构化传导关系。每条关系表达来源事件或指标、目标资产及指标、方向、直接/间接/共同因素类型、传导机制、周期、适用条件、证据、不确定性和验证状态；同一事件可有多条相反或不确定路径。

传导模板只提供候选机制，不固定方向，也不证明因果。具体事件必须独立判断是否适用；验证状态区分研究假设、案例支持、统计支持、证据不足和验证不支持。无数据时允许定性研究，但不得宣称完成定量验证；统计支持不等于因果证明。跨资产结论必须分别给出每个资产的目标指标，不得只输出笼统的“利多/利空”。

前端采用传导链卡片与可筛选关系表，至少展示来源事件/指标、目标资产与指标、方向、周期、机制、证据和验证状态，并区分理论机制、AI推断、案例支持和历史统计关联。不同资产、标的、目标指标、方向口径或研究周期的差异不是直接冲突；只有比较口径一致且判断相反时才标记冲突，其他情况标记为期限差异、指标差异、跨资产差异或并列机制。

## 10. 权限与合规

- 匿名用户仅允许只读公开研究页面。
- 组合、策略、上传、任务和报告需要登录。
- 研究组合默认按当前账号隔离；真实持仓、内部导入或组织共享未开放前不得通过研究组合接口暴露，开放时需独立权限、审计和数据安全评估。
- 内部流水线必须使用内部服务令牌和幂等键。
- 数据源必须记录授权范围，不得将无再分发许可的数据暴露给外部接口。
- 策略生成和模型调用必须记录审计日志与 token 使用量。
- 研究案例默认归属创建者；关联项目后复用现有项目经理/编辑者权限语义，不新建平行RBAC。案例操作与底层引用读取分别授权，成员权限变化即时生效。
- 所有权转移、报告导出、再分发、永久删除和恢复属于高审计操作；查看权限不自动包含研究使用、导出或再分发权限。

## 12. 验收标准

每类新增资产的MVP必须满足：

1. 现有一级板块、路由和全部当前数据内容保持不变；新增资产能力可从对应板块的子板块进入并完成研究闭环。
2. 公共事件可追溯到全部证据来源；每条影响可追溯到资产、标的、目标指标、周期、传导路径、模型和数据截止时间。
3. 页面正确区分未分析、无显著影响、证据不足、存在影响、分析失败以及无数据、延迟、权限不足等状态。
4. 每项功能显示实际分析粒度、数据覆盖与下钻限制；事实提取不得越权生成定量结论。
5. 数据展示、分析、验证和交易四级门控可独立触发；授权不足始终阻断，数据质量状态与AI置信度分开显示。
6. 研究结果能追溯到来源授权、数据批次或版本、可用时间、模型、提示词和计算配置；受许可限制时说明复现边界。
7. 统计验证目标交互可以完整设计；只有条件满足后才产生正式统计结果，且结果可追溯事实状态、有效样本、时间规则、目标变量、基准、市场阶段和数据版本。
8. 可交易策略入口可以按目标产品预留；只有数据与DreamStrategy支持范围确认后才允许正式执行并生成结果，结果包含代码、指标、日志、引用和验收结论，条件不足时不返回占位PnL。
9. 不触发真实交易，不把研究组合或代理收益解释为真实持仓和策略PnL。
10. 新因子提取与审核任务相互独立，程序校验失败或审核冲突时不自动发布；状态变更和原始标签可追溯，且不改变中国国债旧因子链路。
11. 事件重要性、因子活跃度和历史有效性可分别查看；冲突信号不会被后续功能无条件改写为唯一方向。
12. 跨资产传导可按事件、源/目标指标、周期和验证状态查询；模板关系不被展示为必然因果。
13. 市场表现结果具备完整指标、时间、基准、来源、版本和质量语义；不同单位不会被直接合并排名。
14. 日期级、非交易日、盘后及跨中美市场事件均可追溯实际对齐规则；信息可用时间不明时不能进入正式验证或回测。
15. 重复报道不扩大样本；事件族、主子事件、窗口重叠、样本资格和排除原因可追溯，筛选规则不使用事后结果。
16. 历史相关性、事件研究和策略回测具有不同标签和验收；现有中国国债事件研究页面不被改写为可交易回测。
17. 每项预测均能追溯白名单、目标、有效观察日窗口、生成时间、数据截止时间、证据、模型和提示词版本；不满足生成门控的目标不会生成伪预测。
18. 正常、降级、证据不足、信号冲突、业务拒绝和系统失败可区分；拒绝预测不被展示为中性或研发进度，AI置信度不被展示为历史准确率。
19. 多模型结果保持独立且未经验证不平均；方向、概率、幅度、区间及拒绝分别使用匹配指标评估，并同时展示预测覆盖率。
20. 联网搜索仅按需补充证据，关键金融事实经可靠来源核查；搜索不可用、超时或受权限限制时按规则继续、降级或拒绝。
21. 目标配置组合与模拟持仓组合可区分；公共字段及模式必填规则可校验，期货名义敞口不会被展示为普通资产市值或配置权重。
22. 风险结果可追溯风险因子、方向、币种、市场、数据时点、参数来源、计算方法和状态；现有未分类用户久期不会生成正式DV01，缺失风险不会被补零。
23. 净DV01和总绝对DV01分别展示；债券与期货覆盖率说明各自分母，不可靠的跨资产、跨币种覆盖率不会被合并。
24. 信用、期货、美债专属风险按数据条件开放；风险等级和数据质量分离，中金所会员排名不会被解释为客户持仓、保证金或流动性。
25. 美债美元本币结果与人民币即期折算、未对冲回报、对冲后回报清楚区分；只有收益率数据时不会生成伪市值、DV01或投资回报。
26. 规则情景和自定义冲击保存版本、风险因子、单位、参数来源、近似假设、覆盖率和限制；部分结果不冒充全组合损益，AI候选参数未经确认或校验不进入正式计算。
27. 策略标的能力状态具有证据、验证时间和限制；白名单、接口接受或单次运行不会被展示为正式回测支持，`100040`没有独立证据时不会借别名关系升级。
28. 情报包按结构化分层、令牌预算和时点规则生成；历史运行不注入当前信息、事后统计或无法证明当时真实存在的模型预测。
29. 实质变化的业务策略版本逐版确认并冻结需求；技术重试单独记录为执行尝试，语义变化必须升版、重新确认。
30. 正式研究回测可追溯成本、成交、结算和收益/现金流核算版本；不完整或无法验证的外部模型明确标记为实验/诊断，不冒充正式结果。
31. 生命周期、研究质量和表现评价分别展示；零成交原因可诊断，亏损不等于方法失败，正式研究可用不等于盈利或未来适用。
32. AI代码及外部输入受隔离、资源、超时、网络、数据和密钥边界约束；外部服务无法证明幂等时不承诺恰好一次执行。
33. 国债期货套保按三级能力开放；静态合约数由确定性程序计算并展示整数候选、剩余DV01和风险限制，参数不足时只给定性方案。
34. 完整历史套保回测仅在现货/组合与期货历史、真实合约、成本、结算及多资产多腿能力通过后开放；期货套保不会被描述为消除信用利差、违约或流动性风险。
35. 资产、标的、数据时点和研究快照可通过显式URL跨页面传递；页面可按业务继承或忽略，历史结果以版本/快照复现，旧页面默认行为不变。
36. 证据详情可从事件、因子、市场表现、预测、策略或报告下钻并返回原版本上下文；正反证据并列，证据类型保留专业展示结构。
37. 传导链和关系表区分理论机制、AI推断、案例及统计关联；不同资产、指标或周期的方向差异不会被误标为直接冲突。
38. 页面统一区分数据缺失、部分覆盖、质量不足、分析降级、业务拒绝和系统错误；实现进度不作为客户金融状态，预留入口不显示伪数据或伪结果。
39. 研究案例可引用事件至报告的不可变版本，并正确处理引用失效、替代版本、保留期和访问权限；底层更新不改写历史案例。
40. 研究案例默认个人所有并可关联项目；项目成员角色变化后案例访问随之更新，但底层引用仍逐条校验。所有权转移产生权限版本并保留原作者、接收者和审计记录。
41. 关注列表可同时承担收藏和多资产监测；规则可版本化、启停、去重并按用户时区和数据频率运行，日频数据不会被标记为实时预警。
42. 监测提醒只形成研究提示、待办或案例候选引用，不会自动调用预测、策略、回测或交易。
43. 正式报告固定案例、数据、证据、模型和计算参数版本；再生成产生新版本并可比较，动态研究视图不会覆盖正式结论。
44. 删除、权限或授权变化可追溯到原始数据、快照、报告、派生文件和缓存；历史引用只保留许可允许的最小墓碑，并明确复现受损范围。
45. PDF、Word、Excel、CSV和Markdown导出均重新校验查看/使用/导出/再分发权限及来源许可；过滤后核心结论失去支撑时拒绝导出或要求重新生成。
46. 首个可交付版本能够从多资产市场研究进入事件/证据、因子或定性判断、研究案例和正式报告；预测或统计验证缺失不会阻断有证据支撑的定性闭环。
47. 分期接入新增资产组合风险、监测和策略能力时，现有中国国债组合、预测、策略生成及回测功能、入口和数据均保持可用。
48. 首个可交付版本只作为开发里程碑；未进入该里程碑的目标功能仍保留完整交互和扩展契约，不以占位金融结果冒充已实现能力。

## 13. 实施阶段

当前推荐路线为“公共基础能力→美债→国债期货→信用债”。该顺序用于里程碑规划，不是串行硬门槛：公共能力随实际资产用例渐进抽取，不提前过度抽象；各资产的数据接入、产品设计和独立模块可以并行。客户需求、接口可用性、授权、金融模型或开发依赖变化时可以调整顺序，但必须记录原因、影响范围和依赖，并同步更新五份设计文档。

### 阶段 0：最小公共能力与可交付研究闭环

- 明确资产、功能粒度、公共事件、证据、目标指标、双轴方向、时间和能力状态契约。
- 建立统一市场表现、版本化时间对齐、事件族/样本资格及三类研究结果契约，具体公式和阈值按后续决策补充。
- 建立预测白名单、结果/拒绝状态、证据准备、版本、独立置信度和分类评估契约；新增资产默认不开启未经评估的概率或幅度预测。
- 在不改动现有组合表和页面行为的前提下，建立目标配置/模拟持仓、多币种、风险结果、资产计算器、覆盖率和版本化情景的目标契约；MVP不接入真实持仓。
- 建立策略标的能力登记、分层情报包、业务版本/执行尝试、成本/成交/结算/核算版本以及生命周期/质量/表现分离契约；保留旧入口和白名单，但不把兼容状态自动升级为正式研究能力。
- 盘点现有供应商、官方接口、上传与内部数据的覆盖和授权，未确认项不进入能力承诺。
- 在现有一级板块内部建立可选资产上下文和共享事件下钻，不改变现有页面结构，不一次性迁移全部旧表。
- 建立显式URL研究上下文、统一证据引用/返回契约、传导链卡片/关系表、六类客户状态和轻量研究案例逻辑契约；目标交互可先完整设计，物理实现按MVP优先级分期。
- 建立个人/项目案例权限、监测规则、正式报告快照/动态视图、软删除/引用墓碑及授权导出目标契约；当前项目角色和报告任务通过适配器复用，新增所有权转移和多格式导出按需求分期。
- 优先打通市场研究、事件/证据、因子或定性判断、研究案例和正式报告；预测、统计验证、组合风险、持续监测及新增资产策略回测按条件接入，不作为首个闭环的统一阻断项。
- 使用中国国债只读适配验证兼容性，保持现有页面和 DreamStrategy 链路可用。

### 阶段 1：美债

- 扩展美债曲线和专属事件分析，验证跨市场时间与跨资产研究。
- 组合风险先以美元本币研究为正式基线；取得授权汇率后优先评估人民币即期金额折算，未对冲和对冲后回报继续独立门控。
- 作为首个新增资产验证公共多资产架构，先完成可进入研究案例和正式报告的研究闭环；预测、统计验证和策略分别按数据及外部支持条件开放。

### 阶段 2：国债期货

本阶段可在美债尚未全部完成时并行开展数据接入、页面设计和独立适配器开发。

- 建立合约主数据、行情、连续合约、换月和成本模型。
- 模拟持仓以具体合约、手数和方向为基础；保证金、DV01、基差和换月风险按参数能力分别开放。
- 在现有组合/风险板块先开放定性套保及有可靠/假设标识参数的静态套保比率与合约数；完整历史套保回测继续按数据和外部能力门控。
- 验证价格方向、期现联动和风险管理；策略只开放已确认标的。

### 阶段 3：信用债

本阶段可根据客户需求和分层数据授权提前并行，不要求等待国债期货全部完成。

- 先复用整体曲线并明确数据降级；取得数据后再扩展评级、行业、主体和单券。
- 先建设基础集中度和风险状态；基准利率、信用利差及CS01在市值、基准、历史属性和敏感度参数满足后开放。
- 研究闭环优先于可交易策略，后者需另行确认标的和成交约束。

### 阶段 4：跨资产深化

- 在首个版本已经具备案例和正式报告闭环的基础上，深化跨资产事件对比、传导验证、组合分析、持续监测和综合报告。

## 14. 风险与待决策

- 现有专业信息供应商的名称、接口、资产覆盖和授权范围，以及是否需要新增采购。
- 信用债逐券数据、评级历史，国债期货价格/期现数据及美国宏观预期数据能否由现有供应商覆盖。
- 联网搜索供应商、接口、触发阈值、来源筛选、缓存、预算及与当前AI链路的集成实现。
- 用户上传格式、结构化映射、组织隔离和权限模型。
- 研究组合Excel/内部持仓导入、真实持仓模式、组织权限、估值及敏感数据审计的开放条件。
- 各来源具体SLA、质量阈值、存储方式、保留周期及统计样本门槛。
- 因子具体清单、别名映射、审核提示词、监测周期、状态阈值和各评价公式。
- 跨资产传导模板、关系字段、统计方法及具体筛选/排序规则；展示形式已确认为传导链卡片与关系表。
- 研究案例、监测运行、提醒、报告版本、导出物和审计记录的物理存储与保留期限；具体期限按公司制度、数据类型和供应商许可确定。
- 各供应商对屏幕查看、内部研究使用、导出和再分发的许可矩阵，以及过滤/脱敏/替代后核心结论仍具证据支持的判定规则。
- 各资产市场指标公式、信用利差基准、交易日历组件、T及观察窗口细则。
- 事件聚类、窗口重叠处理和历史相关性算法及统计门槛。
- 预测白名单的具体目标与开放阈值、概率校准/聚合算法、评估窗口、模型复核及切换条件。
- USD/CNY授权数据能否支持人民币即期折算，以及未对冲/对冲后回报所需现金流、远期点、对冲比例、展期和成本数据。
- 各资产风险参数来源、DV01/CS01符号和公式、覆盖率分母、情景冲击参数、适用范围与数值精度阈值。
- 是否迁移现有 \`analysis/news_factor\`，或先由兼容适配器读取。
- 外部 DreamStrategy 对具体标的、行情、真实合约映射、代码生成/执行隔离、成本/成交/结算/核算、超时、资源、网络权限、幂等与多资产多腿回测的可验证支持范围。
- `FCT_T_MAIN`既有成交注释所对应的可复核运行记录，以及`100040`是否存在独立验证；在取得证据前分别保持基础验证和已配置状态。
