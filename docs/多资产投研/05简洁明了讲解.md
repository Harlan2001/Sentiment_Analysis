# 《05-美债资产规格》简洁明了讲解

> 阅读对象：公司管理层、产品负责人，以及不熟悉金融和计算机的同事  
> 说明目的：用通俗语言解释《05-美债资产规格》各模块想建设什么、能解决什么问题，以及哪些结果必须等真实数据具备后才能提供。  
> 本文是业务讲解，不替代原资产规格中的字段、计算规则和验收要求。

## 一、先用一句话说明这份需求

我们希望在现有中国国债研究能力之外，增加一套美债研究能力，让用户能够看到美国不同期限国债利率发生了什么变化、为什么变化、会影响什么，并把事件、证据、判断和结论整理成可复查的研究案例与正式报告。

第一阶段不是做美债交易系统，也不是承诺系统可以准确预测市场，而是先把“看市场、找原因、留证据、形成判断、输出报告”这条研究链路走通。

## 二、老板先了解六件事

### 1. 这里研究的“美债”是什么

美债就是美国政府发行的债券。可以简单理解为：美国政府向市场借钱，并按照约定支付利息、到期还钱。

不同期限的美债反映的问题不完全相同。例如：

- 2年期通常更容易受到美联储近期加息或降息预期影响；
- 10年期常被市场用来观察中长期经济、通胀和利率预期；
- 30年期还会受到长期通胀、财政发债和长期资金需求影响。

因此，同一个事件发生后，2年期和30年期出现不同反应是正常现象，不能简单认为系统前后矛盾。

### 2. “收益率上升”不等于“投资赚钱”

收益率可以理解为市场要求这类债券提供多高的回报。对已经持有的普通债券来说，市场收益率上升时，债券价格通常会下降；市场收益率下降时，债券价格通常会上升。

所以，页面上显示“10年期收益率上涨”，只是在描述市场利率的变化，并不等于投资者赚了多少钱。要计算真正的投资回报，还需要知道具体买了哪只债券、买入价格、持有数量、利息收入、交易成本和卖出价格等。

### 3. 现在有的是期限参考数据，不是具体持仓

目前已有2年期、10年期和30年期的官方收益率数据。这些数据可以帮助判断市场整体变化，但它们不是某一只可以买卖的债券，也不能直接代表用户的真实持仓。

因此，仅凭这些期限数据，可以做市场研究和事件分析，但不能直接生成单只债券的市值、盈亏或完整回测结果。

### 4. 美国和中国市场不能只按同一天简单比较

美国和中国有时差，还有各自的节假日和交易时间。美国晚上公布的数据，在中国可能已经是第二天。如果直接把两个自然日期相同的数据放在一起，可能会把“事情发生前”的中国市场表现误当成“事情发生后”的反应。

因此，系统必须记清楚事件在美国时间、世界统一时间和北京时间分别是什么时刻，并根据两边市场实际开市时间确定观察范围。

### 5. 美元结果和人民币结果是四个不同层次

系统会分阶段提供四种能力：

1. 用美元研究美债本身；
2. 按某个时点的汇率，把美元金额换算成人民币金额；
3. 计算中国投资者没有做汇率保护时的真实人民币投资回报；
4. 计算进行了汇率保护后的人民币投资回报。

这四种结果需要的数据不同。简单把100美元按当天汇率换成人民币，只是金额换算，不能说成中国投资者最终赚了多少，更不能说成做了汇率保护后的收益。

### 6. 没有可靠数据时，系统宁可说明缺什么，也不能编结果

例如，目前没有可靠的5年期历史数据时，页面可以保留5年期位置并说明依赖新数据，但不能用2年期和10年期之间的数字“估算”出一个5年期结果冒充真实数据。

同样，没有具体债券价格、现金收付和交易成本时，也不能生成看起来很完整的投资收益。

## 三、一个例子看懂整套研究过程

假设美国公布的通胀数据高于市场原来的预期。

系统希望完成下面这条链路：

1. 记录数据实际在什么时间公布，以及市场当时原本预期多少；
2. 判断这条信息可能让市场认为美联储不会很快降息；
3. 分别观察2年期、10年期和30年期收益率怎么变化；
4. 说明为什么短期债券和长期债券的反应可能不同；
5. 观察这件事是否影响美元、中美利差和中国债券市场；
6. 保存支持和反对这一判断的证据，并说明结论可能在哪些情况下失效；
7. 把这次研究保存成一个可复查的案例；
8. 生成正式报告，同时注明数据截止时间和能力限制。

即使暂时没有成熟的预测模型，也可以根据真实事件和真实市场数据完成这套定性研究。预测不是生成研究报告的强制条件。

## 四、原文各模块的白话讲解

## 模块1：目标——这套美债能力最终要解决什么问题

### 这一模块的意思

我们不是只增加一张美债行情表，而是要建立一条完整的研究过程：

**发现美债市场发生变化 → 查找美国经济和美联储方面的原因 → 形成有证据的判断 → 保存为研究案例 → 输出正式报告。**

美债被选作第一个新增资产，也承担一个验证任务：证明现有平台除了中国国债之外，还能用同一套公共框架接入其他国家、其他币种和其他市场时间的资产。

### 对老板的价值

- 能验证平台是否真正具备多资产扩展能力；
- 能让研究人员的分析过程有证据、有版本、可复盘；
- 不要求先把预测和自动交易全部做完，能够更早形成可交付的研究价值。

## 模块2：范围——第一阶段做什么，以后做什么，不做什么

这部分是为了防止项目边界失控，也防止把未来设计误说成当前已经具备的能力。

### 2.1 当前已经具备的基础

系统目前已经能够取得美国官方发布的2年期、10年期和30年期国债日度收益率，并在中美双方当天都有数据时计算中美利差。

当前中美利差采用比较谨慎的做法：某一天只要其中一边没有数据，就不强行补数，也不人为推算。

目前还欠缺的主要内容包括：

- 5年期美债数据；
- 针对美债的专门事件分析；
- 美国重要经济数据的“市场预期值”和“最终公布值”完整记录；
- 美债预测；
- 可以真正代表投资收益的交易策略回测。

### 2.2 第一阶段必须具备的能力

第一阶段至少要做到：

- 清楚展示2年期、10年期和30年期的变化；
- 看懂收益率曲线是变陡了、变平了，还是整体向上、向下移动；
- 分析美联储、通胀、就业、经济增长、美国财政发债和避险事件；
- 正确处理美国与中国的时差和交易日；
- 展示同一事件对不同期限美债、中国国债和中美利差的不同影响；
- 允许用户把市场数据、事件、证据和判断保存成案例并生成报告；
- 在只有收益率曲线、没有具体债券信息时，明确不计算单只债券的市值和盈亏。

### 2.3 数据和模型具备后再开放的能力

有些功能可以先设计入口和使用方式，但正式结果必须等条件具备后再提供。例如：

- 有可靠5年期数据后，再正式展示和分析5年期；
- 能准确取得经济数据的预期值、公布值和发布时间后，再研究“公布结果比预期好多少或差多少”；
- 预测方法经过历史检验后，再正式提供预测；
- 有具体可交易标的、价格、现金收付和成本数据后，再开放正式策略回测；
- 有可靠并获准使用的美元兑人民币汇率后，再做人民币金额换算；
- 有完整的资产回报、汇率和现金流数据后，再做人民币未对冲回报；
- 有远期汇率、保护比例、展期和成本后，再做完整的汇率保护后回报。

“条件开放”不是说产品不设计，而是说不能在关键数据缺失时给出貌似正式的金融结果。

### 2.4 后续可扩展的内容

未来可以增加更多短期和长期美债期限、抗通胀美债、通胀预期、拍卖分析、美元资金市场、美债期货，以及更完整的人民币投资回报分析。

这些内容有实际价值，但不要求第一阶段一次性全部完成。

### 2.5 第一阶段明确不做的事情

- 不提供真实美债买卖；
- 不承诺分钟级、秒级的市场预测；
- 没有明确汇率和回报计算方法时，不展示人民币总收益；
- 不把中国国债的判断方法原样套到美债上。

换句话说，第一阶段定位是专业研究平台，不是境外交易系统，也不是万能预测系统。

## 模块3：标的模型——系统怎样区分研究对象

### 这一模块的意思

系统必须给每个研究对象一个明确身份。例如：2年期美债、10年期美债、30年期美债、2年与10年的差值、中美10年期利差，都不是同一个东西，不能混在一起。

每个对象还要记录：

- 使用什么币种；
- 属于哪个市场；
- 按哪个市场的交易日计算；
- 展示的是哪个期限的收益率；
- 用户当前选择按北京时间还是美国时间查看。

### 为什么重要

如果研究对象没有明确编号和规则，后续事件分析、预测、报告和回测就可能引用错数据。这个模块相当于先给所有研究对象建立统一、不会混淆的“身份证”。

## 模块4：数据需求——系统需要哪些原料

这一模块列的是研究美债所需的主要数据。它不是要求一次性采购所有数据，而是说明要完成不同能力，分别需要哪些原料。

### 4.1 收益率曲线数据

系统需要不同期限的美债收益率，以及每天、每周的变化和当前水平在历史上处于高位还是低位。

“曲线”可以理解为把短期、中期和长期收益率连起来看。它可以帮助判断市场更担心近期政策，还是更担心长期通胀、财政发债等问题。

### 4.2 美国经济数据

主要包括物价、就业、工资、经济增长、消费、企业景气和金融环境等数据。

系统不能只保存最终公布数字，还要尽量保存：

- 市场事前预期是多少；
- 上一次是多少；
- 这一次实际公布多少；
- 后来有没有修订；
- 具体在什么时间公布；
- 系统在什么时间真正能够看到。

这样做是为了还原“当时的人究竟知道什么”，避免用后来修订过的数据假装当时就已经知道。

### 4.3 美联储信息

包括利率决定、会议材料、官员讲话、资产负债表变化等。

美联储会直接影响市场对未来利率的判断，因此这部分是美债研究的核心证据。系统不仅要收集结论，还要尽量保留原始材料，方便追溯。

### 4.4 美国政府发债和拍卖数据

美国政府发多少债、市场认购是否积极、成交结果是否弱于预期，都可能影响美债，尤其是长期美债。

简单理解：如果市场短时间需要消化大量新债，而买方需求不足，债券价格可能承压，市场要求的收益率可能上升。

### 4.5 其他市场数据

美债不会只受到美国经济数据影响，还可能与美元、股票市场、全球避险情绪、中国国债和人民币汇率发生联系。

如果要从人民币投资者角度计算结果，还要逐层增加：

- 美元兑人民币即期汇率；
- 美债本身的历史回报；
- 买卖期间的汇率变化；
- 利息和本金实际发生的时间；
- 如果做汇率保护，还需要远期汇率、保护比例、续作方式和成本。

### 4.6 数据来源和使用条件

数据必须说明从哪里来、多久更新一次、是否允许使用、何时真正可见、后来有没有被修订。

公司已购买的数据优先盘点；官方来源用于确认权威事实和补充；互联网搜索可以帮助找到最新线索和原始出处，但没有核实的搜索结果不能直接进入正式计算。

用户自己上传的数据也不能直接混入公共数据。系统需要检查指标名称、单位、时间、授权和质量，并只在对应用户或组织范围内使用。

这一小节还强调：拥有2年、10年和30年数据，不代表5年、预测、交易回测等功能自然就具备。每项能力都要分别检查条件。

## 模块5：方向与目标指标——“上涨”到底指什么上涨

### 这一模块的意思

金融研究里最容易产生误解的词就是“上涨”和“利好”。

例如：

- “美债收益率上涨”通常意味着已有债券价格下跌；
- “债券总回报上涨”则通常意味着持有者赚钱；
- “2年与10年的差值上涨”只说明曲线形状变化，不能脱离背景简单说利好或利空；
- “中美利差上涨”必须先说明到底用中国减美国，还是美国减中国。

因此，系统需要先写清楚讨论的指标，再说明变化方向，最后说明它对什么样的持仓意味着什么。

### 曲线形态如何通俗理解

曲线变化需要同时看整体方向和短长期变化速度：

- 整体收益率下降，同时长期下降得更快；
- 整体收益率下降，同时短期下降得更快；
- 整体收益率上升，同时长期上升得更快；
- 整体收益率上升，同时短期上升得更快。

原文用四个金融简称描述这些情况。老板只需知道：系统不能只写“美债利多”或“美债利空”，而要说明短期和长期分别发生了什么。

### 市场变化不等于投资回报

第一阶段可以计算各期限收益率变化了多少个基点。一个基点等于0.01个百分点，例如收益率从4.00%升到4.10%，就是上升10个基点。

但这个数字仍不是价格回报或投资收益。真正计算投资回报必须有具体标的、价格、利息和现金收付信息。

## 模块6：时区与事件对齐——保证因果顺序没有弄反

### 这一模块解决什么问题

美国重要数据可能在北京时间晚上公布，美联储会议结果甚至可能在北京时间凌晨发布。中国市场当时可能已经收盘。

如果系统把美国事件与中国当天收盘直接配对，就可能出现时间倒置：用事件发生前的中国行情解释事件发生后的影响。

### 系统要怎样处理

每个事件都需要记录：

- 原始来源标注的时间；
- 来源所在时区；
- 转换后的美国时间、世界统一时间和北京时间；
- 什么时候发布；
- 什么时候对市场真正可见；
- 系统什么时候取得；
- 美国和中国市场分别从哪个可交易时段开始观察。

还必须正确处理美国夏令时。美国每年有一段时间会调整时钟，如果忽略这一点，事件时间就可能整体错一小时。

### 对结果的约束

- 只有日度数据时，只能研究每日变化，不能声称看到了盘中即时反应；
- 不知道一条信息何时真正可见时，不能把它放进正式历史检验；
- 中美两地要按各自的开市日和开市时间观察，不能要求两边一定落在同一自然日期；
- 某天一边没有数据时，不能随意补数计算中美利差。

## 模块7：因子体系——把影响美债的原因分门别类

### 什么是“因子”

这里的因子可以简单理解为“可能影响美债的原因类别”。这样系统才能把大量新闻和数据归纳起来，而不是每天只堆一堆零散信息。

美债重点关注六类原因：

1. 美联储政策和市场对政策的预期；
2. 通胀和真实利率；
3. 经济增长与就业；
4. 美国政府发债和拍卖情况；
5. 全球避险情绪与美元资金情况；
6. 长短期收益率之间的结构变化。

### 这一模块特别强调什么

- 同一个经济指标的“预期值、公布值、后来修订值”不能混为一谈；
- 同一事件对短期和长期美债影响不同，不一定是冲突；
- 通胀压力和避险需求可能同时存在，系统应保留两套相反证据，而不是强行选一个；
- 美债和中国国债同时变化，只能说明存在联系，不能直接证明是美债导致了中国国债变化；
- 历史上经常同时出现，也不等于已经证明因果关系。

## 模块8：事件分析输出——每次分析应该告诉用户什么

### 这一模块的意思

系统不能只输出一句“看涨”或“看跌”，而要给出一张结构清楚的分析卡片。卡片至少要回答：

- 分析的是哪种资产、哪个期限；
- 讨论的是收益率、价格还是其他指标；
- 预计向上、向下还是不确定；
- 对持有债券的人可能意味着什么；
- 影响大概持续多久；
- 短期和长期收益率可能如何变化；
- 为什么这样判断；
- 有哪些反面风险；
- 什么情况出现后，原判断需要失效或重做。

### 为什么要区分市场判断和用户盈亏

一条分析可以判断10年期收益率可能上升，但如果不知道用户持有什么、持有多少、是买入还是做空，就不能直接说用户会亏损。系统应解释市场影响，不能冒充个人账户盈亏分析。

## 模块9：专业页面内容——用户在产品里会看到什么

美债能力会放进现有平台的一级栏目中，不重新搭建一个完全不同的网站，也会保留已有中美利差页面和原来的默认使用方式。

产品设计可以提前考虑最终完整形态，但页面上的正式数值必须与真实数据能力一致。

### 页面之间如何保持研究上下文

用户从美债市场页进入事件页、案例页或报告页时，系统应尽量带上当前研究背景，例如：

- 正在看哪个期限或哪只具体债券；
- 看的是收益率还是投资回报；
- 采用美元还是人民币视角；
- 使用哪个时区；
- 数据截止到什么时候；
- 引用的是哪个历史快照。

这样用户切换页面后不需要反复选择，也能重新打开过去的研究结果。但从美国市场跳到中国市场时，时间范围必须按中国市场重新解释，不能生搬硬套。

### 证据、监测、案例和报告

- 不同证据要用适合自己的方式展示，例如经济数据要展示预期与实际，美联储材料要展示原文来源，汇率要展示时点；
- 研究案例保存当时引用的数据和结果版本，后来的数据修订不能悄悄改写旧结论；
- 监测规则可以关注某个期限、曲线形态、中美利差或重要事件，但日度数据不能称为实时预警；
- 提醒只告诉研究人员“值得关注”，不会自动触发预测、回测或交易；
- 正式报告需要固定当时的数据、证据、模型和计算方法；重新生成时建立新版本，不覆盖旧报告；
- 导出报告时需要重新检查数据使用权限。关键证据不允许导出时，相关结论要删除后重新生成，或者拒绝导出。

### 9.1 市场页面

用于快速回答“美债市场现在怎么样”。主要展示：

- 2年、10年和30年收益率；
- 长短期差值；
- 每日、每周变化；
- 曲线变陡还是变平；
- 当前水平在历史上高不高；
- 数据最后更新时间。

5年期等没有真实数据的内容可以预留位置，但必须明确依赖数据，不能生成假值。

### 9.2 信息页面

用于回答“最近有什么事情可能影响美债”。内容包括美国经济数据日历、美联储事件、国债拍卖、美债新闻和中美利差变化。

重点不是信息越多越好，而是要帮助用户找到对研究真正重要的事件。

### 9.3 因子页面

用于回答“哪些原因最近最活跃、过去是否有参考价值”。

系统会展示某类事件的重要程度、近期出现频率，以及在特定期限和特定市场阶段下的历史表现。

历史统计只提供参考，不能被说成必然规律；同一因素对不同期限的作用也可能不同。

### 9.4 收益页面

第一阶段主要展示2年、10年和30年收益率变化，以及曲线和中美利差变化。

未来数据完整后，可以增加债券价格回报和包含利息的总回报。页面必须把市场变化、真实投资回报和策略盈亏分开，避免用户误解。

### 9.5 预测页面

未来可以分别预测2年、10年和30年收益率在未来一天、一周或一月的大致方向，但每个期限都要单独通过检验后才能正式开放。

预测页面还要展示：

- 判断依据；
- 反面风险；
- 结论成立的假设；
- 什么情况出现后需要作废；
- 当前是正常输出、能力降级还是因条件不足拒绝输出。

系统自己认为“很有信心”，不等于历史准确率真的很高。模型信心、证据质量和历史表现必须分开显示。

### 9.6 组合页面

组合研究分为两类：

- 目标配置：研究希望把多少比例资金放在不同期限美债上；
- 模拟持仓：研究假设具体持有什么、方向是什么、数量和成本是多少。

美债组合首先以美元为基本口径。只有2年、10年和30年收益率参考点时，不能把它们当成真实债券持仓，也不能计算正式市值和盈亏。

人民币视角按四层能力逐步开放：美元本币结果、人民币即期换算、人民币未对冲回报、人民币对冲后回报。每一层单独检查条件，不能因为第一层具备就默认后面三层也具备。

组合只计算出部分结果时，要清楚说明覆盖了多少资产、缺少哪些参数，不能把部分结果说成整个组合的完整结论。

## 模块10：统计验证——历史上类似事件通常怎样影响市场

### 这一模块想做什么

研究人员提出“通胀高于预期通常会推高2年期收益率”之后，系统未来可以用历史数据检验这个说法是否经常成立、影响通常持续多久。

### 为什么要条件开放

这种检验必须知道事件准确发布时间、数据何时对市场可见，并拥有完整的市场数据。如果时间记录不可靠，统计结果就可能把事情发生前后的数据放反。

同一事件被很多新闻重复报道时，不能算成很多个独立样本。美联储决议、新闻发布会和会议纪要既有关联，也可能包含新信息，需要标记它们之间的关系。

样本太少或同时有多个重要事件干扰时，只能展示案例或探索性结果，不能包装成可靠规律。

### 10.1 检验什么结果

第一阶段主要看2年、10年和30年收益率变化。未来数据满足条件后，再看5年期、债券价格、总回报、曲线变化和中美利差变化。

### 10.2 看多长时间

可以观察事件当天、之后一天、五个交易日、二十个交易日等不同范围，但具体起点必须按美国和中国各自市场的开市时间计算。

### 10.3 按什么情况分类

系统会区分：数据高于还是低于预期、美联储态度偏紧还是偏松、事件属于通胀还是就业、当时市场是否避险、曲线原来是什么形态、当时处于加息还是降息阶段。

这样可以避免把完全不同背景下的事件粗暴放在一起平均。

## 模块11：预测——未来可能往哪个方向走

### 预测能力如何开放

2年、10年和30年收益率会作为第一批候选预测对象，但不是设计完成后立刻对外输出。每个对象都需要具备稳定数据、正确市场日历、可靠信息时间和历史评估，才能进入正式名单。

预测方向、预测幅度和预测概率是三种不同难度的能力，可以分开开放。例如，可以先允许输出“更可能上升或下降”，但在概率没有经过验证前，不输出“上涨概率80%”这类看似精确的数字。

### 系统遇到不确定情况怎么办

- 不同期限判断相反时，先解释期限差异；
- 不同方法结论相反时，保留冲突并说明原因；
- 证据不足时，可以只提供定性研究；
- 关键数据缺失或矛盾无法解释时，可以拒绝给出正式预测；
- 每一版预测都保存数据截止时间、证据、方法、假设和失效条件，不能覆盖历史结果。

这保证系统不会为了“必须给答案”而制造虚假的确定性。

## 模块12：可交易策略回测——历史上按某种规则买卖是否有效

### 什么是回测

回测可以理解为：把一套买卖规则放到过去的数据中试运行，看看历史上可能赚多少、亏多少。

### 为什么当前收益率数据不能直接做正式回测

2年、10年和30年收益率只是市场参考指标，不是可以直接买卖的商品。要做正式回测，必须先确定具体交易对象，例如某一只美债、获准使用的基金或期货，并具备：

- 当时可以买卖的真实价格；
- 买卖价差和交易成本；
- 是否有成交、市场是否有足够流动性；
- 债券利息、应计利息和到期还款；
- 结算规则；
- 美元资金核算；
- 外部回测服务是否真正支持该标的和这些规则。

如果只用收益率变化做实验，可以称为研究代理或实验结果，不能升级为正式投资盈亏。

### 未来可能研究的策略

可以研究收益率趋势、曲线变陡或变平、经济数据超预期、美联储事件、国债拍卖、中美利差和新闻因素等策略。

系统还必须避免“提前知道未来”：收盘后才公布的信息不能假设按同一收盘价成交，后来修订的数据也不能放回过去假装当时已知。

## 模块13：策略生成——让系统辅助形成可研究的交易想法

### 这一模块要做什么

未来系统可以综合美债曲线、美国经济、美联储政策、拍卖、市场风险偏好、新闻和中美利差，帮助研究人员形成策略候选。

但一个策略不能只写“看多美债”，必须说清楚：

- 研究哪个期限或具体标的；
- 依据收益率还是价格；
- 用哪个时区和哪个决策时点；
- 最早什么时候允许成交；
- 对利率变化有多敏感；
- 交易成本怎么处理；
- 是否计算汇率影响；
- 与什么基准比较；
- 使用的数据在当时是否已经可见。

### AI的边界

AI可以帮助整理信息、解释逻辑和提出候选想法，但不能把今天的知识偷偷带回过去，也不能凭空生成正式盈亏。

用今天的模型重新分析过去数据，只能标为实验性回放。它和过去真实时点已经生成并保存的预测不是一回事。

## 模块14：跨资产联动——美债变化会怎样影响其他市场

这部分希望研究四类联系：

1. 美债变化怎样改变中美利差；
2. 中美利差变化可能给中国国债带来什么外部压力；
3. 全球避险时，中美债券有哪些相同和不同反应；
4. 海外利率变化可能怎样传到信用债和国债期货。

这类分析必须允许出现“影响不明显”“方向不同”或“由共同原因造成”等结论。不能预设美债上涨，中国国债就一定上涨；也不能因为两个市场同时变化，就认定一个直接导致另一个。

## 模块15：公共平台扩展——美债如何接入整个平台

### 这一模块的意思

平台已有一些公共能力，例如页面接口、组合类型、多币种处理、风险结果和情景分析。美债接入时要复用这些公共规则，只补充美债特有内容，避免为每类资产重新造一套系统。

美债需要额外记录：

- 期限；
- 原始币种和用户查看币种；
- 汇率来源、时点和版本；
- 美国时间、世界统一时间和北京时间；
- 中美两地交易日；
- 中美利差采用什么算法；
- 哪些期限和风险已有数据，哪些尚缺；
- 人民币即期换算、未对冲回报和对冲后回报分别具备到哪一层。

当5年期、价格、现金收付、汇率或经济预期数据缺失时，系统要返回具体缺失原因，而不是填入插值或未标明的模拟数字。

## 模块16：验收标准——怎样判断这套需求做对了

原文列出的验收条目很多，可以归纳为九组管理检查项。

### 1. 市场数据是否真实、可追溯

- 2年、10年和30年数据来源、更新时间和变化正确；
- 5年期没有数据时明确说明依赖，不生成假值；
- 经济数据保留公布、预期、修订和可用时间。

### 2. 时间处理是否正确

- 同时展示或保存美国时间、世界统一时间和北京时间；
- 正确处理美国夏令时和中美交易日差异；
- 日度数据不包装成盘中实时反应。

### 3. 指标含义是否没有混淆

- 收益率变化、债券价格、总回报和策略盈亏分别展示；
- 中美利差明确计算方向；
- 短期与长期方向不同不被误判为系统冲突。

### 4. 事件和证据是否能追溯

- 每条重要结论能找到数据、新闻、官方文件或其他证据；
- 正反证据都能保留；
- 未核实的网络信息不进入正式计算；
- 用户上传数据经过质量、权限和隔离检查。

### 5. 预测和统计是否诚实

- 每个期限和每种预测类型单独验收；
- 没校准的概率不输出为正式概率；
- 模型自信程度不冒充历史准确率；
- 条件不满足时允许降级为定性研究或拒绝输出。

### 6. 组合和风险是否有真实基础

- 收益率参考点不冒充具体可交易债券；
- 缺少价格、现金流、持仓和风险参数时不生成正式市值和盈亏；
- 只覆盖部分资产时，显示覆盖比例和缺失原因。

### 7. 多币种结果是否分层

- 美元结果、人民币即期换算、人民币未对冲回报、人民币对冲后回报分别检查；
- 简单换汇不冒充投资回报；
- 换算成人民币后，仍保留风险来自美国利率市场这一事实。

### 8. 回测和策略是否可复查

- 使用明确的具体标的；
- 价格、成交、成本、利息、结算和资金口径能够追溯；
- 只使用当时已经可见的信息；
- 当前模型对历史的回放明确标为实验。

### 9. 案例、报告、监测和导出是否有版本与权限

- 页面链接能恢复当时看的期限、币种、时区和数据快照；
- 案例和正式报告不被后来数据自动覆盖；
- 日度监测不宣称实时；
- 提醒不自动触发交易；
- 导出时再次检查数据授权，关键证据被过滤后不能保留失去支撑的结论。

总体而言，验收不只是“页面能打开”，而是要证明数据没有造假、时间没有错位、指标没有混淆、结论可以复查、能力边界说得清楚。

## 模块17：待确认事项——开发前还要核实哪些现实条件

这部分不是要老板现在逐项决定所有细节，而是项目进入具体开发阶段后，需要通过数据盘点、供应商确认和技术验证逐项落实。

主要待确认内容包括：

- 公司现有数据供应商能否提供5年期、经济预期、修订和拍卖数据，以及是否有使用授权；
- 各类数据多久更新、质量达到什么标准、历史版本保存多久；
- 监测提醒的触发值、观察时间、重复提醒控制和发送渠道；
- 第一阶段是否接入抗通胀美债和真实利率；
- 公司是否已有可合法使用、时间匹配且可追溯的美元兑人民币汇率；
- 外部策略服务究竟支持哪些具体美债工具，以及是否能正确处理价格、现金流、成交、成本和安全问题；
- 具体债券价格回报、总回报和中美利差应该采用什么统一计算口径；
- 美国交易时间、事件观察范围和重复事件如何处理；
- 预测功能达到什么历史表现后才允许正式开放；
- 正式回测所需的买卖价格、利息、到期还款、融资、结算和美元核算数据从哪里取得。

这些事项会影响具体实现方法和上线顺序，但不改变美债研究产品的总体方向。

## 五、这套美债需求最终要交付什么

从管理层视角，可以把最终产品理解为六项能力：

### 1. 看清市场

清楚展示美国不同期限国债收益率、曲线形态和中美利差的变化。

### 2. 解释原因

把美联储、通胀、就业、经济增长、财政发债和全球避险事件与市场变化联系起来。

### 3. 保留证据

每个判断都能回到当时的数据、文件、新闻、时间和版本，既保留支持证据，也保留反面风险。

### 4. 形成研究成果

即使暂时没有预测，也可以把真实数据、事件分析和定性判断保存为研究案例，并生成正式报告。

### 5. 分阶段增加高级能力

数据和模型成熟后，再逐步增加统计验证、方向预测、投资组合风险、人民币视角和可交易策略回测。

### 6. 坚守结果可信边界

没有真实数据时不插值冒充正式数据，没有具体标的时不计算假盈亏，没有完整汇率与现金流时不冒充人民币投资回报。

## 六、老板可以怎样判断这份需求是否合理

可以用四个问题快速检查：

1. **它是否解决真实研究问题？** 研究人员可以从市场变化一路走到证据、判断、案例和报告。
2. **它是否保护现有系统？** 美债以新增模块接入，复用现有页面和公共能力，不推翻中国国债业务。
3. **它是否允许逐步建设？** 产品形态可以完整设计，但数据、预测、回测和人民币回报按条件逐层开放。
4. **它是否避免假结果？** 每个数字都需要真实来源、明确时间和适用条件，缺失时说明原因，不用模拟值冒充正式结果。

## 七、常见词语的通俗解释

| 词语 | 通俗解释 |
|---|---|
| 美债 | 美国政府发行的债券 |
| 收益率 | 市场当前要求这类债券提供的大致回报水平 |
| 期限 | 距离债券到期还有多长时间，例如2年、10年、30年 |
| 收益率曲线 | 把不同期限的收益率放在一起观察形成的结构 |
| 基点（bp） | 利率变化的常用小单位，1个基点等于0.01个百分点 |
| 中美利差 | 中国国债收益率与美国国债收益率之间的差值，必须说明谁减谁 |
| 市场预期 | 数据公布前，市场普遍估计的数值 |
| 宏观意外 | 实际公布结果与市场原来预期之间的差异 |
| 美联储 | 美国中央银行体系，负责美国货币政策 |
| FOMC | 美联储讨论和决定利率政策的重要会议 |
| 总回报 | 同时考虑价格变化和持有期间利息后的完整回报 |
| 现金流 | 持有债券期间实际收到或支付的利息、本金等资金 |
| 久期 | 用来描述债券价格对利率变化有多敏感的一类指标 |
| DV01 | 市场利率变化一个基点时，债券价值大约变化多少钱 |
| 即期汇率 | 当前时点用一种货币兑换另一种货币的价格 |
| 未对冲回报 | 没有做汇率保护时，资产涨跌和汇率变化共同造成的回报 |
| 对冲后回报 | 做了汇率保护并计入相关成本后的回报 |
| 统计验证 | 用历史数据检查某种判断过去是否经常成立 |
| 预测白名单 | 只有数据和历史评估达标的预测对象，才允许正式输出 |
| 回测 | 用过去的数据模拟执行一套交易规则 |
| 前视风险 | 在模拟过去时，不小心使用了当时尚未公开的未来信息 |
| 研究案例 | 固定保存某次研究的数据、证据、判断和结论版本 |
| 数据快照 | 把某个时点看到的数据固定下来，便于以后还原 |

## 八、最后的管理层结论

《05-美债资产规格》不是单纯增加一个美债行情页面，而是在设计一套可扩展、可追溯的海外利率研究能力。

第一阶段最重要的成果，是利用已有真实收益率数据和可靠事件证据，完成从市场观察到正式报告的研究闭环。预测、人民币投资回报和策略回测都可以继续完整设计，但只有在对应数据、模型、授权和计算规则通过验证后，才能作为正式金融结果开放。

这套设计的核心原则可以概括为：**先把研究过程做完整，再把高级计算逐项做可靠；可以提前设计未来能力，但不能提前制造未来结果。**
