# 国债期货资产投研规格

> 状态：Draft  
> 版本：v0.1  
> asset_scope：\`cn_treasury_futures\`

本文件仅定义国债期货专业差异。公共客户任务、三类闭环、现有前端兼容、公共事件与证据、双轴方向、时间及能力状态继承《多资产固收投研平台需求文档》和《多资产投研引擎技术设计》。

## 1. 目标

建立国债期货“合约与持仓异常—事件与证据—因子或定性判断—研究案例—正式报告”的研究闭环。连续合约、期现指标、定量预测、统计验证和可交易策略按行情与外部能力条件开放，不作为基于现有可靠持仓证据完成定性闭环的强制前置。国债期货按推荐路线在美债之后推进，但合约数据、页面和独立适配器可并行建设。

## 2. 范围

### 2.1 当前基础

- 已通过中金所公开CSV实现TS、TF、T、TL的会员成交与持仓排名、合约筛选和多空比趋势；当前同步由接口或回填脚本触发；
- 当前没有OHLC、结算价、完整成交持仓总量、连续合约、换月、基差、CTD或隐含回购率；
- DreamStrategy仅对白名单内少量利率债标的有已验证或允许范围，不能推定四个品种全部支持。

### 2.2 MVP必须实现

- 保留现有会员持仓页、路由和数据展示，在板块内部增量加入异常增减仓、集中度、拥挤和持仓背离解释，并说明排名数据的覆盖边界；
- 建立国债期货专属事件分析，将中国国债“收益率方向”显式转换为“期货价格方向”；
- 以TS、TF、T、TL品种及当前可得具体合约为研究对象，展示数据日期、证据、风险、失效条件和后续关注；
- 支持把会员持仓、事件证据、定性传导和数据限制加入研究案例并生成正式报告；缺少价格预测、统计验证或策略回测时不阻断该基础闭环；
- 在公共模拟持仓契约中明确具体合约、手数和多空方向；价格、保证金、DV01或基差参数不足时仅保留持仓结构与缺失说明；
- 缺少价格和期现数据时，不展示连续合约收益、基差、CTD、IRR、价格预测或可交易回测。

### 2.3 满足条件后开放

- 取得合约主数据、OHLC、结算价、成交量和持仓量后，开放主力/连续合约、价格统计验证和预测；
- 取得可交割券、转换因子和现券数据后，开放基差、CTD和IRR研究；
- 具体合约、执行成本及DreamStrategy支持确认后，开放对应品种的可交易策略。

### 2.4 后续范围

- 分钟级行情；
- 日内事件研究；
- 跨期价差；
- 期现套利；
- 多腿组合和保证金优化；
- 真实交易接口。

## 3. 标的模型

标的分为：

1. **具体合约**：如 T2603；
2. **主力合约**：如 T_MAIN；
3. **连续合约**：如 T_CONTINUOUS；
4. **期限组合**：如 T_TF_SPREAD；
5. **期现关系**：如 T_BASIS。

字段：

| 字段 | 说明 |
|---|---|
| product | TS/TF/T/TL |
| contract | 具体合约代码 |
| expiry | 到期日 |
| last_trade_date | 最后交易日 |
| delivery_month | 交割月 |
| continuous_method | 连续合约拼接规则 |
| roll_rule | 换月规则 |
| multiplier | 合约乘数 |
| tick_size | 最小变动价位 |
| margin_rate | 保证金比例 |

## 4. 数据需求

### 4.1 合约行情

- 开、高、低、收、结算价；
- 成交量、持仓量；
- 涨跌停；
- 合约生命周期；
- 主力合约判定；
- 连续合约拼接因子。

### 4.2 持仓

- 会员多头、空头和净持仓；
- 前 N 名集中度；
- 持仓变化；
- 成交/持仓比；
- 不同合约间迁移。

### 4.3 期现

- 中债可交割券列表；
- 转换因子；
- CTD；
- 净基差；
- 隐含回购率；
- 久期、DV01；
- 现券收益率曲线。

### 4.4 事件

- 货币政策和公开市场操作；
- 资金面；
- 国债发行与供给；
- 财政政策；
- 通胀和增长；
- 监管和交易规则；
- 持仓异动；
- 海外利率和风险偏好。

### 4.5 来源、更新与门控差异

- 现有公开来源只确认会员排名；合约价格、结算价、主数据、全市场成交持仓、基差及期现数据优先盘点公司已购专业数据和授权，不足时再评估其他来源或采购；
- 会员排名按中金所或供应商披露频率同步；取得可靠授权行情后MVP优先日频，分钟级和实时行情不是强制验收项；
- 合约代码、生命周期、结算口径、主力判定和换月规则必须带版本；修订或回填不得改变历史决策时点所见数据；
- 用户上传历史行情需通过合约识别、交易日、价格/结算口径、单位、连续性和授权校验，仅在所属用户或组织范围使用；
- 会员排名可达到展示/分析级时，价格预测、期现验证和策略仍可分别处于阻断状态；授权不足直接阻断对应用途。

## 5. 方向模型

使用公共双轴方向模型：

| target_metric | target_direction示例 | market_effect规则 |
|---|---|---|
| futures_price | up/down/flat/unknown | 上涨通常为期货多头`bullish`，下跌为`bearish` |
| implied_yield | up/down/flat/unknown | 与期货价格确定关系优先使用规则映射 |
| basis | up/down/flat/unknown | 不设通用利好利空，除非明确期现策略和持仓视角 |
| carry | up/down/flat/unknown | 仅在持有方向和计算口径明确时解释市场效果 |

不得把基差方向、期货价格方向和收益率方向混为一个字段。

示例：

```json
{
  "asset_scope": "cn_treasury_futures",
  "instrument_id": "T_MAIN",
  "target_metric": "futures_price",
  "target_direction": "up",
  "market_effect": "bullish",
  "position_view": "long_futures",
  "analysis_state": "impact_identified",
  "strength": 0.7,
  "confidence": 0.72,
  "horizon": "1D-5D",
  "reason": "资金面宽松推动长端收益率下行，利多十年期国债期货"
}
```

### 5.1 市场表现差异

- 当前MVP只把会员多空、净持仓和持仓变化作为`position_structure`市场观察，不称为合约收益或策略PnL；
- 取得具体合约价格与结算价后，分别计算价格点数变化和明确口径的合约收益；结算价、收盘价和连续合约序列不得混用；
- 基差、净基差、IRR和CTD属于期现指标，不等同于期货单边收益；策略PnL还需仓位、合约乘数、保证金、成交、换月和成本；
- 所有结果保留具体合约、价格口径、起止时点、换月规则版本和数据质量，连续合约不得作为可成交标的。

## 6. 条件开放：连续合约与换月

本节规则在合约行情与主数据接入后生效，不属于仅凭当前持仓排名即可交付的能力。

连续合约是回测的高风险区域，必须明确：

1. 主力判定使用成交量、持仓量或固定提前换月。
2. 主力信息只能使用当时已经可获得的数据。
3. 拼接采用前复权、后复权或收益率拼接。
4. 换月日和价格跳空单独记录。
5. 策略真实成交使用具体合约，不直接交易连续合约。
6. 回测结果必须标注换月规则和拼接方法。

建议初始规则候选：

```text
主力判定：上一交易日持仓量最大
换月执行：下一交易日开盘
连续序列：收益率拼接
真实成交：具体合约
```

最终规则须由业务确认。

## 7. 因子体系

### 7.1 公共因子的期货映射

货币政策、宏观、流动性、风险和情绪因子继承公共字典，不复制定义。期货应用必须明确其作用于`futures_price`、`implied_yield`、`basis`、`position_structure`或其他具体指标；现券收益率方向与期货价格方向优先按确定金融关系转换。

### 7.2 期货专属

以下为分类建议，不锁定具体因子ID：

| 逻辑命名空间 | 专业含义 | 示例 |
|---|---|---|
| `futures.position` | 会员和全市场持仓结构 | 多空变化、集中度、拥挤、成交持仓比 |
| `futures.contract` | 合约生命周期 | 主力迁移、临近交割、换月压力 |
| `futures.basis` | 期现定价 | 基差、净基差、IRR、CTD切换 |
| `futures.delivery` | 交割与可交割券 | 转换因子、交割期权、现券可得性 |
| `futures.spread` | 期限与跨期关系 | 跨期价差、曲线相对价值 |
| `futures.liquidity` | 交易和成交约束 | 流动性、涨跌停、异常成交 |
| `futures.hedging` | 套保与风险暴露 | DV01、套保比率、保证金约束 |

### 7.3 风险事件

- 交易规则调整；
- 涨跌停；
- 异常成交；
- 合约临近交割；
- 数据断档；
- 现券不可得或 CTD 缺失。

### 7.4 冲突、生命周期与传导差异

- 会员持仓、价格、基差和交割因子的应用资格分别管理；缺少价格只暂停价格/策略应用，不使持仓因子全局失效；
- “现券收益率下行支持期货价格上涨”与“多头拥挤增加回撤风险”可作为不同机制并列；只有同一合约、指标和周期的相反方向才标记直接冲突；
- 传导关系优先表达“中国国债收益率/久期→期货价格”“资金成本与可交割券→基差、IRR和CTD”“持仓迁移→合约流动性与换月风险”；
- 基差、跨期和套保因子没有统一利好利空，必须保留策略视角、适用条件和失效风险；三维评价按品种/合约、指标和周期分别展示。

## 8. 专业页面内容

国债期货内容嵌入现有一级板块内部，现有会员持仓页面与数据保持不变。本节按最终研究形态设计行情、持仓、期现、风险和策略内容，MVP只决定实现顺序；缺少价格、合约或期现数据时不得用会员排名或连续序列模拟正式行情与PnL。

显式URL上下文至少区分品种、具体合约、主力/连续研究序列、数据时点、合约映射与换月规则版本。页面可从品种研究继承到具体合约，但模拟持仓、套保和回测必须重新确认具体合约，不能只继承主力/连续符号。

证据详情分别渲染会员排名、全市场行情/结算价、合约规则、可交割券/CTD、基差及事件新闻，并保留来源、交易日、公布/可用时间和版本。会员排名只能支持拥挤度或参与者行为研究，不能作为成交量、客户持仓或正式流动性证据；研究案例只引用这些不可变结果。

国债期货监测可针对具体合约价格/结算价、成交量、持仓量、会员排名、基差、CTD、到期和换月风险建立规则，并明确品种、具体合约、主力/连续研究序列及映射版本。行情、结算、会员排名和合约规则按各自来源频率评价；日频会员排名不得描述为实时持仓预警，连续序列触发不得直接生成具体合约订单。提醒只形成研究提示、待办或案例候选。

国债期货正式报告与导出必须冻结具体合约、乘数、最小变动、结算口径、合约规则、CTD/转换因子、基差及换月映射版本。导出时重新校验行情、会员排名、交易所规则和可交割券等来源许可；若过滤使合约价格、风险或套保结论失去核心依据，应拒绝导出或生成新报告版本，且不得以会员排名替代全市场行情、客户持仓或正式流动性数据。

### 8.1 市场

- TS/TF/T/TL 行情；
- 主力合约；
- 曲线和跨品种表现；
- 成交量、持仓量；
- 数据截止时间。

### 8.2 信息

- 会员持仓排名；
- 多空集中度；
- 持仓变化；
- 基差、CTD和隐含回购率。

### 8.3 因子

- 事件重要性：宏观、供给、交易规则或持仓事件的研究价值；
- 因子活跃度：去重后的品种/合约触发频率和变化；
- 历史有效性：指定合约、价格/基差指标和周期的样本、基准及不确定性；
- 原始标签、标准因子、应用状态、冲突/混合状态及期现反向证据。

### 8.4 收益

- 会员持仓及变化（当前MVP，不是收益）；
- 具体合约价格/结算价变化与收益（条件开放）；
- 连续合约研究收益及换月贡献（条件开放，不可直接成交）；
- 基差、净基差及期现分解（条件开放）；
- 可交易策略PnL（仅交易级门控通过后）；
- 历史相关性与事件市场反应，明确区别于策略PnL。

### 8.5 预测

- 取得可靠行情后的合约价格方向与波动状态；
- 幅度预测在价格口径和历史误差评估通过后开放；
- 基差预测在期现数据和基准定义通过后独立开放；
- 会员持仓只作为证据，不替代价格目标、实际结果或预测评估；
- 正常、降级、拒绝状态，以及依据、反向风险、假设和失效条件。

### 8.6 组合

- 期货只进入模拟持仓组合，必须选择可识别的具体合约并录入手数和多空方向；品种、主力或连续合约可作研究视图，但不得作为实际持仓标的；
- 名义敞口依据合约面值、价格及适用规则计算，与普通资产市值、净投资金额和目标配置权重分开；多空抵销同时保留净敞口和总绝对敞口；
- 保证金使用带来源、时点和版本的保证金率；用户假设参数可用于模拟但必须显式标识。保证金不是最大可能亏损，MVP不提供账户级追加保证金或强平预警；
- DV01必须由具体合约和可靠风险参数计算，算法所需时使用CTD、转换因子及合约面值；参数缺失返回不可计算，不从会员持仓排名推导；
- 基差、到期、交割与换月风险按具体合约、现券和规则版本分别显示；会员排名只作研究证据，不代表用户持仓、全市场成交、正式保证金或流动性；
- 期货价格、基差和隐含利率属于不同情景风险因子；未定义映射时不得同时叠加直接价格冲击与利率隐含价格冲击。部分敏感度结果显示覆盖的合约、手数/名义敞口分母和缺失原因。
- 套保研究分为定性方案、静态比率/合约数和完整历史套保回测。前两级在组合/风险页面开放，不依赖DreamStrategy；静态计算要求组合DV01与期货每合约DV01可靠或明确标注为假设，并输出理论值、满足方向和约束的整数候选、目标套保率及剩余DV01。
- 每合约DV01可使用经验证的供应商参数，或在数据满足时按CTD、转换因子和合约面值计算，CTD不是唯一允许来源。整数选择同时考虑目标风险、仓位、资本和保证金约束，不无条件四舍五入。
- 套保结果必须显示风险因子、方向、币种、数据时点、曲线/基差不匹配、CTD切换、换月、保证金和过度套保风险；不得仅因汇率折算后金额相同就认定跨市场风险可对冲。参数不足时只保留定性方案。

## 9. 条件开放：事件时间对齐

事件分为：

- 盘前；
- 盘中；
- 收盘后；
- 非交易日。

接入日频价格后，精确时间按中金所交易时段、行情观测点和信息可用时间映射；具体开盘、收盘或结算价规则后续确认。只有日期、盘后或非交易日事件采用信息已可用后的下一有效交易时点，并保存原始时间、精度、映射规则和结果。可用时间不明时只保留定性研究，不进入正式验证或回测；日频数据不得宣称盘中反应。

日频价格统计还须按事件类型、品种/合约、目标指标和窗口管理事件族、重复报道、主子事件、重叠与干扰事件。样本不足时仅展示案例或探索结果；正式验证必须给出样本资格、基准、统计不确定性和适用范围。

## 10. 条件开放：可交易策略回测

以下内容只有在具体合约能力登记、历史行情、真实合约映射、换月、成本、成交、逐日结算和资金约束可复现时开放。收益率、主力或连续序列代理只能进入研究/统计验证，不称为具体合约策略PnL。

### 10.1 策略类型

- 新闻/因子方向过滤；
- 持仓排名反转或趋势；
- 期限动量；
- 基差均值回归；
- 跨期价差；
- 宏观状态切换；
- 中国国债现券—期货联动。

### 10.2 成本模型

- 手续费；
- 买卖滑点；
- 冲击成本；
- 换月交易摩擦及跨合约价差；
- 保证金资金成本；
- 涨跌停和无法成交；
- 交割前强制换月。

### 10.3 输出

- 总收益和年化收益；
- 波动率；
- 最大回撤；
- Sharpe/Sortino；
- 胜率、盈亏比；
- 交易数和换手率；
- 保证金收益率；
- 多空拆分；
- 持有期PnL、基差变化、换月价差、交易摩擦和连续序列调整的分项贡献；
- 基准比较。

所有收益率必须声明资金分母；保证金收益率、名义敞口收益率和全组合收益率分别展示，禁止直接互相比较。结算模型还须处理合约乘数、最小变动价位、结算价、逐日盯市、可用资金不足、到期和交割/强制换月。

### 10.4 强制检查

- 受控预期成交测试零成交时基础成交能力不通过；普通策略零成交则区分无信号、数据缺失、订单拒绝、资金不足、代码错误和标的不支持，不自动判为技术失败，但不得形成表现证据；
- 事后主力合约不通过；
- 未声明换月规则不通过；
- 忽略成本不通过；
- 连续合约直接成交不通过；
- 异常比率只标记，不自动美化。

当前代码白名单只证明兼容入口：`FCT_T_MAIN`依据既有代码注释暂列`basic_validated`，待补独立可复核运行记录；`100040`仅为其别名且无独立证据，列`configured`；`FCT_TS_MAIN`与`FCT_TL_MAIN`列`configured`。所有`FCT_*_MAIN`还须确认外部定义、真实合约映射、连续构造、换月、成本和PnL，才能升级为`formal_research_backtest`。

## 11. 条件开放：预测

取得具体合约主数据、可靠价格/结算价历史、可用时间和目标判定规则后，按品种或合约分别注册预测能力。新增资产日/周/月默认对应未来1/5/20个中金所有效观察日，并保存合约、实际起止时点、日历、价格口径和数据截止时间。

开放顺序为价格方向、波动状态，再根据历史评估开放价格幅度；基差变化和TS/TF/T/TL相对强弱分别需要期现数据或可比合约口径。方向、概率、幅度和区间类型独立门控，不以会员排名字段存在推定预测可用，也不以持仓变化替代未来价格实际值。

输入包括：

- 近期行情和持仓；
- 资金面；
- 中债曲线；
- 宏观事件；
- 新闻因子；
- 交割和换月状态。

持仓拥挤与价格信号冲突时保留冲突；缺少行情、合约已临近交割且规则不足、目标不满足生成门控或信号无法解释时允许降级为定性研究或业务拒绝。未校准概率不得作为正式上涨概率，缺少幅度模型时不输出精确价格点数。预测更新不得覆盖旧版本；模型置信度、证据质量、历史校准及统计不确定性分别展示。

## 12. 条件开放：策略生成

本资产在公共分层情报包中只增加：

- 当前合约和主力判定；
- 行情、成交量和持仓量；
- 多空排名；
- 基差/CTD；
- 中债收益率曲线；
- 事件与因子；
- 历史回测先验及其样本内/样本外和选择历史；
- 换月和成本规则。

国债期货业务版本还必须声明：

- 交易合约；
- 信号频率；
- 决策和成交时点；
- 主力/换月规则；
- 仓位和保证金；
- 止损止盈；
- 成本；
- 涨跌停处理；
- 回测期间。

主力/连续序列只用于研究或信号时，必须同时保存当时可知的真实合约映射；历史运行不得使用事后主力判定。当前会员排名、新闻、预测或风险快照不得回填历史决策，连续序列信号也不得被当作可直接成交的订单标的。

## 13. 公共契约的国债期货扩展

公共API路径、模拟持仓、风险结果、覆盖率和情景协议由TDD统一定义。期货响应额外携带`product/contract/position_direction/contract_count/multiplier/expiry/last_trade_date`，并分别表达名义敞口、保证金参数及来源、DV01参数/算法、CTD、转换因子、基差、主力与换月规则版本，以及数据属于会员排名还是全市场行情。缺失能力返回状态和原因；假设参数带明确标记，不得伪装为市场实值。

## 14. 验收标准

1. TS/TF/T/TL会员排名可按真实交易日和合约查询，并显示来源、数据时间和覆盖边界。
2. 系统能识别并解释持仓集中度、异常增减仓和数据不足，不把会员排名等同全市场持仓。
3. 新闻结论明确区分期货价格、隐含收益率和基差方向；缺少价格时只输出有证据支撑的研究解释。
4. 方向使用双轴模型；基差未指定策略与持仓视角时不强制输出利好利空。
5. 主力、连续合约和换月仅在行情及主数据接入后验收，规则必须可解释、可复现且不使用事后信息。
6. 可交易回测仅在开放后验收手续费、滑点、换月、保证金、涨跌停和具体合约成交。
7. 策略按具体标的能力登记门控；白名单成员只证明已配置。目标入口可以预留，但未达到正式研究条件时不生成策略PnL，用户选择不符合门控的品种时返回业务拒绝而不替换。
8. 会员排名与价格/结算/期现数据分别显示来源、时间、版本和客户结果状态；内部能力状态不作为客户可见研发进度，局部数据缺失只影响相应结果。
9. 用户上传行情通过质量、授权和时间门控后，只在其权限范围用于验证或回测。
10. 期货专属因子使用资产命名空间，持仓、价格、基差和交割应用状态相互独立。
11. 期现传导保留现券与期货目标指标、机制、周期和验证状态；拥挤与价格方向不同不得被错误消除。
12. 会员持仓、价格/结算价变化、连续合约研究收益、基差和策略PnL分别定义，当前持仓数据不得展示为期货收益。
13. 事件时间按中金所时段和数据频率映射；事件族、重叠窗口和样本排除原因可追溯，只有交易级结果进入策略回测。
14. 合约价格方向、波动状态、幅度、基差和相对强弱分别注册；会员持仓不能单独使价格预测通过门控。
15. 预测周期映射到合约市场1/5/20个有效观察日；冲突、降级、拒绝及失败可区分，未校准概率和模型置信度不作为实际准确率。
16. 期货模拟持仓要求具体合约、手数和多空方向；名义敞口、普通资产市值、配置权重和保证金互不混用，连续合约不作为持仓标的。
17. 保证金参数可追溯来源与版本，假设参数有明确标记；保证金不显示为最大可能亏损，系统不提供真实账户追加保证金或强平监控。
18. DV01只在具体合约及所需CTD、转换因子/合约面值等参数满足时计算；覆盖率说明合约手数或名义敞口分母，会员排名不进入用户持仓风险计算。
19. 期货价格、基差和隐含利率情景不会无依据重复计入；部分敏感度结果明确覆盖合约、近似方法和缺失原因。
20. `FCT_T_MAIN`、`100040`及其他主力符号按独立证据登记能力；别名不会继承正式验证，主力/连续序列不会作为模拟持仓或实际成交标的。
21. 正式回测可追溯合约乘数、最小变动、手续费/滑点、成交、逐日结算、保证金/资金不足、到期/换月和PnL核算版本；换月价差不会全部记为费用或亏损。
22. 生命周期、研究质量和表现评价分别展示；零成交原因可诊断，收益率分母明确，保证金收益不与全组合收益直接比较。
23. 静态套保输出理论与整数候选、目标套保率和剩余DV01，并显示曲线/基差、CTD切换、换月、保证金和过度套保风险；参数不足时不生成正式合约数。
24. 完整历史套保回测仅在组合/现货与期货同步历史、可靠风险、真实合约、逐日结算、成本及多资产多腿能力满足后验收。
25. 国债期货URL上下文明确品种、具体合约、研究序列、真实合约映射和换月版本；旧会员持仓页面无上下文时保持原默认行为。
26. 会员排名、行情/结算、合约规则、CTD/可交割券和基差证据使用不同专业详情，不能因统一证据入口而混淆数据含义。
27. 现券收益率、期货价格、基差、拥挤度及不同到期合约的方向差异按指标/合约/周期差异展示；只有可比口径相反时标记直接冲突。
28. 研究案例可版本化引用合约行情、事件、因子、风险、套保、策略和回测；换月后保留原合约与映射版本，不自动改指新主力。
29. 国债期货监测规则区分行情、结算、会员排名、基差、到期与换月的对象和来源频率；日频排名不宣称实时，连续序列提醒不自动创建具体合约策略或订单。
30. 正式报告冻结具体合约、规则、CTD/转换因子、基差及换月版本，重新生成创建新版本；动态视图不会改写历史正式报告。
31. 导出保留合约乘数、结算与换月口径、来源许可和限制；核心行情/风险/套保证据被过滤时拒绝或重新生成，不用会员排名或连续序列补成正式结果。
32. 国债期货可基于现有可靠持仓及事件证据完成案例和正式报告；行情、预测或回测未开放时明确边界但不阻断定性闭环，且不会削弱现有中国国债期货相关入口。
