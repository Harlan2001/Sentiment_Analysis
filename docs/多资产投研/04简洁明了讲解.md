# 国债期货资产规格——简洁明了讲解

> 本文面向不熟悉金融和计算机的管理者，用通俗语言解释《04-国债期货资产规格》每个模块准备建设什么、当前数据能做到什么、暂时不能做到什么，以及为什么正式预测、套保和回测需要更严格的数据条件。

## 一、先用一句话说明这个模块

国债期货模块要帮助研究人员回答：

```text
国债期货市场最近有什么异常
→ 参与者的持仓怎样变化
→ 宏观政策和国债现货怎样影响期货
→ 可能存在哪些到期、换月、基差和资金风险
→ 能否形成研究案例和正式报告
```

第一阶段可以利用现有会员持仓排名和可靠事件证据完成定性研究。价格预测、正式套保计算和策略回测，必须等待具体合约价格、结算、成本和换月等数据具备后再开放。

## 二、什么是国债期货

国债期货是一种标准化合约。交易双方约定按照交易所规则，在未来围绕国债价值变化进行结算或交割。

它常见的用途包括：

- 判断未来利率和国债价格方向；
- 管理债券组合的利率风险；
- 研究国债现货与期货之间的价格关系；
- 在条件具备时设计交易或套保策略。

我国主要国债期货品种包括：

- TS：2年期国债期货；
- TF：5年期国债期货；
- T：10年期国债期货；
- TL：30年期国债期货。

这些只是品种名称。真正模拟持仓或回测时，还要落实到某个到期月份的具体合约。

## 三、老板最需要先理解的六件事

### 1. 当前已有的是会员排名，不是完整期货行情

系统目前能够取得中金所公布的部分会员成交和持仓排名，并观察多空排名怎样变化。

这类数据可以帮助研究市场参与者是否集中或拥挤，但它不等于：

- 全市场完整成交量；
- 所有投资者的持仓；
- 某个客户自己的持仓；
- 期货价格和结算价；
- 真实流动性；
- 正式保证金数据。

因此会员排名可以支持研究解释，不能直接计算策略收益。

### 2. 品种、具体合约、主力合约和连续合约不是一回事

- 品种是TS、TF、T、TL这样的大类；
- 具体合约是某个到期月份真实可以交易的合约；
- 主力合约是某段时间成交或持仓最活跃的具体合约；
- 连续合约是为了长期画图和研究，把不同时期合约连接起来形成的序列。

连续合约是研究工具，不是真实存在、可以直接买卖的一只合约。

### 3. 国债收益率和期货价格通常方向相反

一般情况下，国债收益率下降时，国债价格和国债期货价格往往上升；收益率上升时，期货价格往往承压。

因此不能把“中国国债收益率上涨”直接复制成“国债期货价格上涨”。系统必须做方向转换。

### 4. 保证金不等于最大可能亏损

期货交易只需要缴纳一部分保证金，但实际盈亏按照更大的合约价值变化计算。

保证金只是交易所或账户要求占用的资金，不是期货资产市值，也不是投资者最多只能亏这么多。

### 5. 套保只能降低匹配的风险

国债期货可以用来降低债券组合的部分利率风险，但它不能自动消除信用债的违约风险、信用利差风险和流动性风险。

### 6. 正式回测需要完整模拟真实交易过程

正式回测不仅需要价格，还要考虑具体合约、成交时间、手续费、滑点、保证金、每日结算、资金不足、到期和换月。

只用连续曲线计算一段涨跌，不能直接称为真实可交易策略收益。

## 四、用一个例子理解国债期货研究流程

假设央行释放资金，市场资金面明显宽松。

系统希望完成以下工作：

1. 保存政策和资金面证据；
2. 判断资金宽松可能推动国债收益率下降；
3. 按金融关系转换成“国债期货价格可能受到支持”；
4. 查看会员多空排名是否出现明显变化；
5. 如果多头过度集中，同时提示拥挤和回撤风险；
6. 如果没有可靠价格，只进行定性解释，不生成价格收益；
7. 把事件、证据、持仓变化和限制保存为研究案例；
8. 生成正式报告；
9. 等具体合约价格、成本和结算规则具备后，再做预测或策略回测。

这就是当前可实现的基础研究闭环。

## 五、第1部分：目标是什么意思

国债期货模块的目标是把以下环节连接起来：

- 发现合约或会员持仓异常；
- 找到相关政策、宏观和市场证据；
- 分析对期货价格、隐含利率或基差的影响；
- 形成定性判断或条件允许的定量结果；
- 保存为研究案例；
- 生成正式报告。

连续合约、期现研究、价格预测和正式策略回测属于条件开放能力，不是第一阶段完成定性研究闭环的必要条件。

国债期货按推荐路线排在美债之后，但合约数据接入、页面设计和独立模块可以并行建设。

## 六、第2部分：范围是什么意思

### 2.1 当前已经具备什么

系统已经能够读取TS、TF、T、TL的会员成交和持仓排名，查看合约筛选、多空比例和变化趋势。

当前仍然缺少：

- 完整开盘、最高、最低、收盘和结算价；
- 全市场成交量和持仓量；
- 主力和连续合约；
- 换月规则；
- 国债现货与期货价格差异；
- 最便宜可交割国债等期现数据。

外部策略服务只对少量标的存在有限证据，不能认为四个品种已经全部支持。

### 2.2 第一阶段必须完成什么

第一阶段重点完成：

- 保留现有会员持仓页面和数据；
- 增加异常增减仓、集中度和拥挤解释；
- 建立国债期货专属事件分析；
- 正确处理国债收益率与期货价格的方向关系；
- 以TS、TF、T、TL及当前能够识别的合约进行研究；
- 将持仓证据和定性判断加入案例并生成报告；
- 模拟持仓时明确具体合约、手数和多空方向；
- 数据不足时明确显示缺口，不生成价格、基差或策略收益。

### 2.3 哪些能力等条件满足后开放

取得完整合约和价格数据后，再开放：

- 主力和连续合约研究；
- 价格统计和预测；
- 国债现货与期货价格关系；
- 基差、最便宜可交割券和隐含融资收益研究；
- 有真实成本和成交约束的策略回测。

### 2.4 后续可以继续扩展什么

未来可能扩展分钟级行情、盘中事件研究、不同到期合约之间的价差、现货与期货套利、多合约组合和真实交易接口。

真实交易不属于当前阶段。

## 七、第3部分：标的模型是什么意思

国债期货研究对象分为五类。

### 1. 具体合约

真实存在并有明确到期月份的合约，例如某年某月到期的10年期国债期货。这是模拟持仓和正式回测必须使用的对象。

### 2. 主力合约

某个时期最活跃的具体合约。主力合约会随着时间变化。

### 3. 连续合约

为了长期看图和研究，把不同时期的主力或指定合约连接成一条序列。它不是可以直接成交的真实标的。

### 4. 期限组合

比较不同期限品种，例如10年期和5年期国债期货之间的相对变化。

### 5. 期现关系

研究国债期货与可交割国债现货之间的价格关系。

每个具体合约还要记录到期日、最后交易日、合约乘数、最小价格变动和保证金比例等信息。

## 八、第4部分：数据需求是什么意思

### 4.1 合约价格和交易数据

需要取得：

- 开盘、最高、最低、收盘和结算价；
- 成交量和持仓量；
- 涨跌停规则；
- 合约什么时候上市和到期；
- 怎样判断主力合约；
- 怎样把不同合约连接成连续序列。

### 4.2 会员和市场持仓数据

需要研究：

- 会员多头、空头和净持仓；
- 前几名会员的集中程度；
- 持仓是否突然增加或减少；
- 成交和持仓之间的关系；
- 资金是否从一个到期合约迁移到另一个合约。

### 4.3 国债现货与期货关系数据

需要取得：

- 哪些国债可以用于交割；
- 不同国债怎样换算成交割标准；
- 哪只国债交割成本最低；
- 期货和现货之间的价格差；
- 持有现货并卖出期货可能隐含的融资收益；
- 利率敏感度和现货收益率曲线。

### 4.4 需要关注哪些事件

包括货币政策、市场资金、国债发行、财政政策、通胀、经济增长、交易规则变化、持仓异常和海外利率变化。

### 4.5 数据来源和开放关卡

当前公开来源只确认会员排名。价格、结算、合约资料和期现数据要优先盘点公司已有专业数据，不足时再考虑其他来源或采购。

每类能力单独检查。会员排名能够展示，不代表价格预测、期现分析和策略回测也已经可用。

## 九、第5部分：方向模型是什么意思

国债期货需要分别表达多种方向。

### 期货价格方向

价格上涨通常对期货多头有利，价格下跌通常对期货多头不利。

### 隐含收益率方向

期货价格和隐含收益率通常方向相反，系统优先使用明确规则转换。

### 基差方向

基差是国债现货与期货之间的价格关系。基差扩大或缩小本身没有统一的利好或利空，要看具体策略和持仓方向。

### 持有收益方向

只有明确持有哪一边、怎样计算时，才能解释为有利或不利。

系统不能把期货价格、收益率和基差都塞进一个“上涨或下跌”字段。

### 当前能展示的市场表现

第一阶段主要展示会员多空结构和持仓变化。这些是市场观察，不是合约收益。

以后取得价格后，收盘价、结算价和连续合约研究序列也要分别计算，不能混用。

## 十、第6部分：连续合约和换月是什么意思

期货合约会到期，长期研究时需要从旧合约切换到新合约，这叫换月。

“连续合约”是把多个到期合约按某种规则连接起来，方便查看长期趋势。

不同连接方法可能产生不同历史曲线，因此必须说明：

- 怎样选主力合约；
- 使用成交量还是持仓量判断；
- 什么时候切换；
- 切换价格差怎样处理；
- 连续曲线使用什么调整方式；
- 策略实际成交的是哪个具体合约。

最重要的规则是：不能用事后才知道的主力合约做历史回测，也不能把连续合约当成真实可成交对象。

## 十一、第7部分：国债期货因子体系

“因子”可以理解为可能影响国债期货的原因。

### 7.1 公共因素怎样用于期货

货币政策、经济数据、市场资金、风险偏好和情绪继续复用公共因子。

但要明确这些因素影响的是期货价格、隐含收益率、基差还是持仓结构。

### 7.2 期货专属因素

重点包括：

- 会员和全市场持仓结构；
- 主力合约迁移、到期和换月压力；
- 期货与国债现货之间的定价关系；
- 可交割国债和交割规则；
- 不同期限和不同到期合约之间的价差；
- 流动性、涨跌停和异常成交；
- 套保比例、保证金和利率风险。

### 7.3 风险事件

需要特别关注交易规则调整、涨跌停、异常成交、临近交割、数据断档以及无法取得可交割券资料等情况。

### 7.4 冲突和影响路径

不同信号可以同时成立。例如：

- 国债收益率下降，支持期货价格上涨；
- 多头持仓过度集中，增加价格回撤风险。

两者是不同机制，不必强行合成一个方向。

基差、跨期和套保也没有统一利好利空，必须说明研究视角。

## 十二、第8部分：国债期货页面准备展示什么

国债期货内容会加入现有网站板块，原会员持仓页面和数据继续保留。

### 页面共同原则

- 明确当前查看的是品种、具体合约、主力研究序列还是连续序列；
- 模拟持仓、套保和回测必须重新确认具体合约；
- 会员排名、行情、结算、合约规则和期现证据分别展示；
- 日频会员排名不能宣传为实时持仓预警；
- 提醒只产生研究待办，不自动生成订单；
- 报告固定使用的合约、结算和换月版本。

### 8.1 市场页面

未来展示TS、TF、T、TL价格、主力合约、不同期限表现、成交量、持仓量和数据更新时间。

### 8.2 信息页面

展示会员排名、多空集中度、持仓变化以及条件开放的基差、最便宜可交割券和隐含融资收益。

### 8.3 因子页面

分别展示事件重要性、某类信号近期是否活跃、历史上是否有效，以及是否存在相反证据。

### 8.4 收益页面

当前只展示会员持仓变化，并明确它不是收益。

取得数据后，再分别展示具体合约收益、连续合约研究变化、换月影响、基差变化和正式策略损益。

### 8.5 预测页面

先开放具体合约价格方向和波动状态，再根据历史表现开放变化幅度。基差预测单独检查。

会员持仓只能作为证据，不能替代未来价格和预测评价。

### 8.6 组合和套保页面

期货模拟持仓必须填写具体合约、手数和多空方向。

系统分别展示：

- 合约代表的名义金额；
- 需要占用的保证金；
- 利率变化可能带来的价值变化；
- 基差、到期、交割和换月风险；
- 净风险和不考虑抵销的总风险。

保证金不等于市值或最大亏损。

套保分为文字方案、静态合约数估算和完整历史套保回测。数据不足时只做文字方案，AI不能猜测正式手数。

## 十三、第9部分：事件时间怎样与市场对齐

事件可能发生在：

- 开盘前；
- 交易时间内；
- 收盘后；
- 非交易日。

如果只有日频价格，收盘后或非交易日事件要从下一个有效交易时点开始观察，不能说成当天盘中已经发生反应。

正式统计还要处理重复报道、事件后续、多个事件重叠和样本不足。

无法确定信息何时真正被市场看到时，可以保留定性研究，但不进入正式验证或回测。

## 十四、第10部分：什么时候可以正式策略回测

正式回测需要同时具备：

- 具体合约能力登记；
- 历史价格和结算价；
- 当时真实合约映射；
- 换月规则；
- 交易成本和成交模型；
- 每日结算；
- 资金和保证金约束；
- 可复现的外部策略服务。

### 10.1 可以研究哪些策略

例如新闻和因子方向过滤、持仓趋势或反转、期限动量、基差回归、跨期价差、宏观状态切换以及国债现货与期货联动。

这些只是候选类型，不代表当前全部已经开放。

### 10.2 回测要考虑哪些成本

- 手续费；
- 买卖价格偏差；
- 大额交易对市场的影响；
- 换月时的交易成本和新旧合约价差；
- 保证金占用成本；
- 涨跌停和无法成交；
- 临近交割时强制换月。

### 10.3 回测输出什么

除了总收益，还要展示风险、最大亏损区间、交易次数、换手、保证金口径、多空表现、换月影响和基准比较。

任何收益率都要说明分母。保证金收益率不能直接和完整组合收益率比较。

### 10.4 哪些情况必须阻断

- 基础成交测试本应有交易但实际零成交；
- 使用事后才知道的主力合约；
- 没有说明换月规则；
- 忽略交易成本；
- 直接交易连续合约；
- 试图用异常指标美化结果。

普通策略零成交不一定是程序失败，可能只是没有信号，但不能拿来证明策略表现优秀。

## 十五、第11部分：什么时候可以预测

只有取得具体合约资料、可靠价格历史和明确评价方法后，才能开放正式预测。

开放顺序通常是：

1. 价格大致方向；
2. 市场波动状态；
3. 价格可能变化多少；
4. 基差变化；
5. 不同期限品种之间的相对强弱。

预测会参考行情、会员持仓、市场资金、国债曲线、宏观事件、新闻因子以及交割和换月状态。

当持仓信号与价格信号冲突时，系统保留冲突。数据不足时降级为文字分析或拒绝预测，不输出没有历史依据的概率和精确点数。

## 十六、第12部分：策略生成需要哪些期货信息

公共策略模块负责通用流程，国债期货模块额外提供：

- 当前具体合约和主力判断；
- 价格、成交量和持仓量；
- 会员多空排名；
- 基差和可交割券信息；
- 中国国债收益率曲线；
- 事件和主要影响因素；
- 历史研究结果；
- 换月和成本规则。

每个策略版本还要明确：

- 交易哪个具体合约；
- 多久产生一次信号；
- 什么时候作出决定、最早什么时候成交；
- 怎样确定主力和换月；
- 仓位、保证金和资金限制；
- 止损和止盈规则；
- 交易成本和涨跌停处理；
- 回测时间范围。

连续序列可以产生研究信号，但最终订单必须映射到当时真实存在的具体合约。

## 十七、第13部分：国债期货怎样接入公共平台

公共平台已经统一定义页面接口、模拟持仓、风险状态、覆盖率和情景分析方式。

国债期货接入时，需要额外告诉平台：

- 品种和具体合约；
- 多头还是空头；
- 合约手数；
- 合约乘数、到期日和最后交易日；
- 名义金额和保证金；
- 利率风险参数及其来源；
- 可交割券、换算规则和基差；
- 主力判断和换月规则版本；
- 当前数据是会员排名还是全市场行情。

缺失能力要返回清楚状态，假设参数必须明确标记，不能冒充真实市场参数。

## 十八、第14部分：怎样验收国债期货模块

原规格列出了32项详细验收要求，可以归纳为以下九组。

### 1. 现有会员排名正确保留

能够按真实交易日和合约查询TS、TF、T、TL会员排名，并说明来源和覆盖边界。

### 2. 不夸大会员排名能力

会员排名不会被解释成全市场持仓、用户持仓、正式流动性或策略收益。

### 3. 不混淆方向和结果

期货价格、收益率、基差、持仓变化、连续序列和策略损益分别展示。

### 4. 具体合约和换月可复现

主力、连续和换月规则带版本，不使用事后信息，模拟持仓和实际成交都落实到具体合约。

### 5. 组合和风险口径正确

合约手数、名义金额、保证金、市值和配置权重互不混用，风险参数缺失时不强行计算。

### 6. 套保边界清楚

静态套保说明理论值、整数候选、剩余风险和限制；完整历史套保只在全部条件满足后开放。

### 7. 正式回测真实考虑交易过程

手续费、滑点、保证金、每日结算、资金不足、到期和换月都能够追查。

### 8. 案例、监测和报告可复现

案例保留原具体合约和换月版本；日频监测不说成实时；正式报告不会因新主力合约出现而改写。

### 9. 基础研究闭环可以独立完成

即使价格预测和策略回测尚未开放，也可以使用可靠会员持仓和事件证据形成研究案例和正式报告。

## 十九、第15部分：还有哪些内容等开发阶段确认

当前剩余问题主要是数据、模型和实施参数。

### 数据和授权

- 公司供应商是否提供价格、结算、合约资料和全市场成交持仓；
- 是否具备可交割券、转换因子和隐含融资收益数据；
- 数据多久更新、保存多久、允许怎样展示和导出。

### 合约和换月规则

- 怎样判断主力合约；
- 连续序列使用哪种连接方法；
- 什么时候换月；
- 换月价差和交易成本怎样拆分。

### 预测和监测参数

- 哪些合约先开放预测；
- 价格和波动怎样定义；
- 监测阈值、检查频率和提醒渠道。

### 风险和套保规则

- 保证金、名义金额和利率风险使用哪些参数；
- 每手期货能够降低多少利率风险；
- 套保整数合约怎样在风险、资金和保证金之间选择。

### 外部策略服务

- DreamStrategy具体支持哪些合约；
- 是否真正处理成本、成交、每日结算、换月和多合约策略；
- 现有白名单和别名是否有独立可复查证据。

这些内容应在真实数据和外部服务验证后确定，不提前虚构参数。

## 二十、管理层可以怎样理解国债期货模块的交付

### 第一阶段能够看到什么

- 原有TS、TF、T、TL会员排名和趋势；
- 异常增减仓、集中度和拥挤解释；
- 国债期货专属事件分析；
- 国债收益率与期货价格的正确方向转换；
- 可靠证据、风险和数据限制；
- 研究案例和正式报告；
- 对价格、基差和回测缺口的明确说明。

### 数据逐步具备后增加什么

- 具体合约价格和结算价；
- 主力与连续合约；
- 基差、可交割券和期现研究；
- 价格预测；
- 模拟持仓风险和静态套保手数；
- 完整历史套保回测；
- 有真实成本、成交和结算约束的策略回测。

### 最终业务价值

国债期货模块不是简单展示会员多空排名，而是逐步把持仓结构、具体合约行情、国债现货、期现关系、套保风险和策略研究连接起来。

它帮助研究人员区分“市场参与者在做什么”“期货价格发生了什么”和“如果真实交易可能赚亏多少”，也让管理层清楚知道哪些是已经验证的能力、哪些仍然依赖数据和外部服务。

## 二十一、常用词语的简单解释

| 词语 | 简单解释 |
|---|---|
| 国债期货 | 围绕国债价值变化交易的标准化合约。 |
| TS/TF/T/TL | 分别代表2年、5年、10年和30年期国债期货品种。 |
| 具体合约 | 有明确到期月份、真实可以交易的期货合约。 |
| 主力合约 | 某个时期成交或持仓最活跃的具体合约。 |
| 连续合约 | 把不同时期合约连接成长期研究序列，本身不能直接成交。 |
| 换月 | 旧合约临近到期时，将研究或持仓切换到新合约。 |
| 多头 | 期望价格上涨的一方。 |
| 空头 | 期望价格下跌的一方。 |
| 会员排名 | 交易所公布的部分会员成交或持仓排名，不代表全部市场或客户持仓。 |
| 结算价 | 交易所用于每日盈亏结算的价格，不一定等于收盘价。 |
| 合约乘数 | 把期货报价换算成合约实际价值规模的规则。 |
| 保证金 | 开立和维持期货持仓需要占用的部分资金，不是最大亏损。 |
| 名义敞口 | 合约代表的市场风险规模，不等于实际缴纳保证金。 |
| 逐日盯市 | 交易所每天按照结算价计算并划转持仓盈亏。 |
| 基差 | 国债现货与期货之间按规定口径计算的价格差异。 |
| 可交割券 | 符合交易所规则、可以用于期货交割的国债。 |
| 转换因子 | 将不同可交割国债换算到统一交割标准的规则。 |
| CTD | 按规则计算后，交割成本通常最低的可交割国债。 |
| IRR | 期货和现货组合隐含的融资收益指标。 |
| DV01 | 利率变化一个很小单位时，合约或组合价值大约变化多少。 |
| 套保 | 使用期货降低组合的某类利率风险。 |
| 滑点 | 理论交易价格与实际可能成交价格之间的差异。 |
| PnL | 一项具体持仓或策略的损益。 |
