## 3. 舆情因子走势（因子"随时间怎么变"）

系统里"舆情"落了两套数据

- **`analysis`（新闻级情绪）**：每条新闻的 AI 方向 → **`direction`** 是 `positive / negative / neutral`（对国债：positive = 利好、收益率下行，negative = 利空、收益率上行），还带 `horizon`（短期/中期/长期）、`reason`。
- **`factor` + `news_factor`（因子级）**：AI 从新闻里抽取的"因子"，分 6 大类：`POLICY 政策 / MACRO 宏观 / LIQUIDITY 流动性 / RISK 风险 / SENTIMENT 情绪 / INDUSTRY 行业`。`news_factor` 记录**每条新闻挂了哪些因子 + 该因子的方向 + 时间**。

**拿"因子信号序列"最省事的接口（现成的，直接可画走势）：**

```
GET /sapi/macro/signal
  ?factor_code=MONETARY_POLICY_CYCLE   # 因子 code，多个用英文逗号
  &start_time=2025-05-01T00:00:00      # ISO 时间格式
  &end_time=2025-05-31T23:59:59
  &signal_type=directional            # presence=事件是否发生(0/1)；directional=方向(-1/0/1)
  &decay_lambda=0.1                   # 可选，时间衰减，默认0.1，仅 directional 生效
```

- `presence`：时间范围内该因子对应新闻**是否出现** → `0/1`
- `directional`：把范围内所有命中新闻的方向做**时间衰减加权**，离 `end_time` 越近权重越大 → `-1/0/1`，`decay_lambda` 调大更侧重近期
- 返回：`signal_value` + `confidence`（置信度）+ `news_count`（命中新闻数）

> 官方预置的几个因子 code：`OPEN_MARKET_OPERATIONS`、`MAJOR_MACRO_DATA_RELEASE`、`POLICY_GUIDANCE`、`MONETARY_POLICY_CYCLE`、`BLACK_SWAN_SHOCK`、`MACRO_REGIME_BREAK`、`POLICY_SHIFT_EVENT`。**但库里还有大量自动发现的因子**，实际以接口返回为准。

**怎么知道到底有哪些因子 code：**

```
GET /sapi/factors                     # 全部因子（code/name/category/factor_type）
GET /sapi/factors/by-category/SENTIMENT   # 只看"情绪"类
GET /sapi/macro/signal/logs?factor_code=XXX   # 谁查过、结果长啥样（范例）
GET /sapi/factor/{factor_code}/news   # 某个因子的关联新闻（方向、期限、理由）
GET /sapi/news?start_date=&end_date=  # 新闻列表；单条详情 /sapi/news/{news_id}
```

## 4. 市场走势形态（收益率曲线怎么拿）

数据在 **`yield_data`** 表：`（日期, 期限, 收益率值）`。**注意期限两种写法**：接口传中文（`10年`），数据库里存英文码（`10Y` / `5Y` / `2Y` / `1Y` / `1年→1Y` …）。

**接口方式：**

```
GET /sapi/news/yields?start=2025-01-01&end=2025-01-31&type=10年
  # 单个期限的时间序列；type 可选：3月/6月/1年/2年/3年/5年/7年/10年/30年
GET /sapi/news/latest-trading-day        # 最新交易日（先查这个再定 end）
GET /sapi/news/{news_id}/yield?period=10年  # 某条新闻前后 N 天的收益率窗口 → 事件前后的市场反应
GET /sapi/forecast                       # 最新 AI 预测报告；GET /sapi/forecast/history 历史日期
GET /sapi/macro_data/indicators          # 宏观指标清单；/sapi/macro_data/data 取数据
GET /sapi/strategy/snapshot              # 当下策略推荐（后验对照用）
```

**"形态"建议拆成三个角度看（对应三种 SQL，§5.2）：**

1. **单期限时间序列**（如 10Y 收益率逐日）→ 看趋势、波动形态
2. **同期整条期限结构**（同一日期 3M→30Y 各点）→ 看曲线**形态**：陡峭/平坦、蝶形
3. **期限利差**（`10Y 收益率 − 2Y 收益率`，bp）→ 市场对长端/短端定价的**形态指标**，跨日对比看形状变化

### 5.2 关键表结构与现成 SQL

核心五张表：`news`（新闻+时间）、`analysis`（新闻情绪方向，按 news_id+model）、`factor`（因子）、`news_factor`（新闻-因子关联+时间，冗余了 `pub_time`）、`yield_data`（收益率，`date + period` 主键）。

**Q1｜舆情因子每日命中数（因子活跃度走势 —— 因子走势本体）**

```sql
SELECT f.code, f.name, f.category,
       DATE(nf.pub_time) AS day,
       COUNT(*) AS hit_count
FROM Sentiment_analysis.news_factor nf
JOIN Sentiment_analysis.factor f ON nf.factor_id = f.id
WHERE nf.pub_time >= '2025-05-01' AND nf.pub_time < '2025-06-01'
GROUP BY f.code, f.name, f.category, DATE(nf.pub_time)
ORDER BY day, hit_count DESC;
```

**Q2｜每日新闻情绪方向统计（舆情整体情绪走势）**

```sql
SELECT DATE(n.pub_time) AS day,
       a.direction,                       -- positive 看涨 / negative 看跌 / neutral 中性
       COUNT(*) AS cnt
FROM Sentiment_analysis.news n
JOIN Sentiment_analysis.analysis a ON n.id = a.news_id
WHERE n.pub_time >= '2025-05-01' AND n.pub_time < '2025-06-01'
  AND a.model = 'glm'                     -- 关键：固守一个模型，避免一条新闻被多模型重复计数
GROUP BY DATE(n.pub_time), a.direction
ORDER BY day, a.direction;
```

> 一条新闻可能被多个模型分析（analysis 主键是 `news_id + model`）。做总量统计时**务必固定 `a.model = 'glm'`**（当前默认分析模型），否则会重复计数。`direction = positive` 表示"利多国债 / 收益率下行"。

**Q3｜单期限收益率时间序列（市场走势）**

```sql
SELECT date, value        -- value 单位是 %，如 1.71 表示 1.71%
FROM Sentiment_analysis.yield_data
WHERE period = '10Y'      -- 注意是英文码，不是"10年"
  AND date BETWEEN '2025-05-01' AND '2025-05-31'
ORDER BY date;
```

**Q4｜同期整条期限结构（曲线形态）+ 期限利差**

```sql
-- 同一交易日，9 个期限各一个点 = 当前曲线形状
SELECT period, date, value
FROM Sentiment_analysis.yield_data
WHERE date IN (
    SELECT MAX(date) FROM Sentiment_analysis.yield_data
    WHERE period = '10Y' AND date BETWEEN '2025-05-01' AND '2025-05-31'
)
ORDER BY FIELD(period,'3M','6M','1Y','2Y','3Y','5Y','7Y','10Y','30Y');

-- 期限利差（10Y-2Y，bp）跨日走势 —— 形态变化
SELECT y10.date,
       ROUND((y10.value - y2.value) * 100, 2) AS spread_bp
FROM Sentiment_analysis.yield_data y10
JOIN Sentiment_analysis.yield_data y2
  ON y10.date = y2.date AND y2.period = '2Y'
WHERE y10.period = '10Y'
  AND y10.date BETWEEN '2025-05-01' AND '2025-05-31'
ORDER BY y10.date;
```

## 6. 把两者"放一起看"（核心分析动作）

同一时间轴上对齐两组序列：

- **X 轴**：交易日（yield_data 有的，就在它上面做日期主表）
- **因子侧**：Q1 的每日因子命中数，或 `macro/signal` 的 `directional` 日频序列（-1/0/1）
- **市场侧**：每日收益率变动（`value(t) − value(t−1)`，乘 100 得 bp）、Q4 的期限利差

一个可直接套用的"因子信号 → 收益率反应"查询（涨跌 bp 与 factor 是否命中对比）：

```sql
SELECT y.date,
       ROUND((y.value - y_prev.value) * 100, 2) AS y10_change_bp,
       (SELECT COUNT(*) FROM Sentiment_analysis.news_factor nf
        WHERE nf.pub_time >= y.date AND nf.pub_time < DATE_ADD(y.date, INTERVAL 1 DAY)
          AND nf.factor_id = (SELECT id FROM Sentiment_analysis.factor
                              WHERE code = 'MONETARY_POLICY_CYCLE')
       ) AS factor_hit_count
FROM Sentiment_analysis.yield_data y
JOIN Sentiment_analysis.yield_data y_prev
  ON y_prev.period = '10Y'
 AND y_prev.date = (SELECT MAX(date) FROM Sentiment_analysis.yield_data
                    WHERE period='10Y' AND date < y.date)
WHERE y.period = '10Y' AND y.date BETWEEN '2025-05-01' AND '2025-05-31'
ORDER BY y.date;
```

> 更省事的路径：**网页版 `/change` 变动对比页**就是"选时间段 → 新闻情绪 vs 收益率变动"的现成实现，先用它验证直觉，再回 SQL 做深度计算。
> 想要"某条新闻发布后市场的反应"，用 `GET /sapi/news/{news_id}/yield?period=10年` 拿它前后 N 天的收益率窗口。
