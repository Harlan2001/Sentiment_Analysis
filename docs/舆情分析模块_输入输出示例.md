# 舆情分析模块 — 输入 / 输出示例

> 面向使用方同事的快速说明：只讲「给它什么、它还你什么、别的系统怎么接」，不讲实现细节。

---

## 1. 它能做什么

给一条中文财经新闻，AI 自动判断它对中国国债的影响：

| 结果 | 含义 |
|---|---|
| **影响方向** `direction` | `利多`（收益率下行）· `利空`（收益率上行）· `中性` |
| **时间跨度** `horizon` | `短期`（1周–1月）· `中期`（1–6月）· `长期`（6月以上） |
| **关键因子** `factors` | 新闻中影响债市的要素，附作用机制「事件 → 传导 → 利率」 |

每条新闻还会配一句 **结论理由 `reason`**。信息不足判断不了的，统一给「中性」，不影响其它新闻。

---

## 2. 输入：给它什么

只要一条新闻的 **标题 + 正文 + 发布时间**，其余什么都不要。

触发方式（按需）：
- **自动**：系统每天对新增新闻批量分析，日常不用管；
- **手动**：界面上可对单条新闻点「重新分析」，也可调接口触发（见第 4 节）。
  手动支持两种模式：只分析**还没分析过**的、或**强制全部重跑**。

---

## 3. 输出：一条新闻的分析结果

以「央行全面降准」为例：

**输入新闻**
> 标题：央行宣布全面降准0.5个百分点 释放长期资金约1万亿元
> 正文：中国人民银行决定自2026年6月5日起，下调金融机构存款准备金率0.5个百分点……
> 发布时间：2026-06-04

**输出结果（JSON）**
```json
{
  "direction": "positive",
  "horizon": "中期",
  "reason": "央行全面降准 → 释放长期资金约1万亿，流动性格局宽松 → 资金利率下行,债市利多。",
  "factors": [
    {
      "code": "RRR_CUT",
      "name": "存款准备金率下调",
      "category": "流动性",
      "direction": "positive",
      "logic_impact": "降准释放长期资金 → 流动性格局宽松 → 利率债收益率下行"
    }
  ]
}
```

**结果会自动存档、汇入因子库**：每条新闻一份结论；出现因子库里没有的新要素时，会自动纳入因子库，方便后续持续跟踪同类事件。因子本身分大类：政策 / 宏观 / 流动性 / 风险 / 情绪 / 行业。

**这些结果不只是页面上看**，还是宏观信号计算、交易策略推送的底层数据。

> 小提示：库里方向存的是英文 `positive / negative / neutral`，界面展示会自动转成中文「利多 / 利空 / 中性」。

---

## 4. 外部系统对接

**现在能用的**：

| 场景 | 调用方式 |
|---|---|
| 查分析结果 | `GET /sapi/news`、`GET /sapi/news/{id}`（按新闻查方向 / 期限 / 理由 / 因子） |
| 触发单条分析 | `POST /sapi/news/{id}/analyze`（对已入库的新闻） |

**暂时没有的**：目前没有「把新新闻提交进来」的接口——新闻由采集程序直接入库。如果外部系统要自己送新闻、再由本系统分析，需要**新增一个入库接口**，属于新需求，要单独排期。

> 接口字段细节以系统自带文档 `/docs` 为准。
