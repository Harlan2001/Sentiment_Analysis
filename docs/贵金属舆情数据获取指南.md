# 从现有数据获取「贵金属舆情」数据 · 使用指南

> 做法：**贵金属新闻 = 对我们已有新闻语料做关键词检索；衍生 AI 分析 = 走已有的分析链路。**

---

## 1. 你们最终要拿到的数据（目标）

一套贵金属舆情数据集，由三块关联数据组成：

| 数据块 | 内容 | 来源 |
|---|---|---|
| 新闻数据 | 贵金属主题相关的新闻语料 | 我们已有新闻语料，按贵金属词表筛选 |
| AI 舆情分析 | 每条新闻的方向、影响时限、逻辑推导 | 我们已有的逐条 AI 分析链路 |
| 因子归因 | 每条新闻事件对应的因素及作用方向 | 我们已有的新闻—因子关联 |

三块通过**新闻唯一标识**关联；因子通过**因子代码**被持续引用。

---

## 2. 我们这里有什么（数据底板）

你们在我们这可以直接取到的东西：

| 资源 | 内容 | 贵金属相关的使用方式 |
|---|---|---|
| 新闻语料 | 全部财经新闻：标题、全文、发布时间、来源、原文链接，每条有稳定唯一标识（跨来源去重） | 按贵金属词表过滤 → 得到贵金属新闻清单 |
| 逐条 AI 分析 | 每条新闻的方向（positive/negative/neutral）、影响时限、逻辑推导、使用的模型 | 贵金属新闻直接带出分析结果，无需自行建模 |
| 因子库 | 标准因子（含美元指数、美债收益率、实际利率、地缘风险、央行购金等贵金属相关因子） | 用因子代码检索贵金属相关事件 |
| 新闻—因子关联 | 新闻与因子的关联：因子、作用方向、判断依据、事件时间 | 事件归因与跨新闻主题追踪 |

## 3. 第一步：圈定贵金属新闻（关键词检索）

### 3.1 推荐词表

**主词**（标题或正文命中即可纳入）：

```
贵金属、黄金、白银、铂金、钯金、
金价、银价、现货黄金、现货白银、伦敦金、纽约金、
沪金、沪银、上金所、黄金 ETF、纸黄金、黄金期货、白银期货、
黄金储备、央行购金、金饰、金条
```

### 3.2 检索口径建议

- **优先标题命中**，正文兜底：标题含词 → 高相关；仅正文含词 → 低相关，可单独打标复核。
- **时间范围**：按发布时间拉取（支持起止日期）。
- 取数可按日期/来源先拉区间，再按词表过滤；如需我们直接在新闻接口上加"关键词参数"，告诉我们即可。

### 3.3 拉回来后能拿到哪些字段

| 字段 | 说明 |
|---|---|
| 新闻唯一标识 | 稳定、跨来源去重的 ID，三块数据的关联键 |
| 来源 | 新闻来源 |
| 标题 / 发布时间 | 筛选与排序依据（发布时间统一北京时间） |
| 正文 | 新闻原文；对外共享时建议以短摘录形式（版权考虑） |
| 原文链接 | 可回溯出处 |

## 4. 第二步：把 AI 分析结果接上（根据已有分析链路调整）

贵金属新闻圈定后，这批新闻的 AI 分析结果有两条路可选，二选一即可。

### 方案 A：胡老师写分析脚本，自己产出结果

- 流程：拿到第 3 步的贵金属新闻清单后，自写脚本调用大模型，对每条新闻产出分析结果（方向、时限、理由、因子），自行汇总成舆情数据。
- 我们侧需要做的：只保证新闻数据可拉取，其余不需要我们开发。
- 你们侧需要准备的：大模型调用（接口/密钥）、提示词、结果解析与落库，均由你们自行完成。

### 方案 B：由我单独提供「贵金属分析接口」

- 流程：我们新增一个贵金属语境的分析接口，你们把贵金属新闻（或新闻时间范围）传给接口，它返回每条新闻的分析结果。
- 接口语义：`direction` 为贵金属语境 —— `positive=利多贵金属/金价上行`、`negative=利空/下行`、`neutral=中性`；连同时限、理由、因子一起返回。
- 我们侧需要做的：单独开发并上线该接口（复用现有分析链路，改造为贵金属语境）。
- 你们侧需要做的：等接口上线后按文档调用。

> ⚠️ 方向语义（选哪种都要先对齐，避免误读）：
> 我们现有已生成的逐条分析是**“对国债收益率的利好/利空”语境**（如：降息 → 国债利多），**不是“对黄金”**。同一条新闻对国债和黄金的方向常常相反（例：美元走高利多美元但利空黄金）。
> - 选 **方案 A**：方向口径由你们自己定义，请按贵金属语境（利多/利空金价）设定，不要沿用我们债券语境的判断；
> - 选 **方案 B**：接口返回的就是贵金属语境，可直接使用，但建议先核对我们的方向定义。

## 5. 第三步：组装成贵金属舆情数据

| 输出 | 构成 |
