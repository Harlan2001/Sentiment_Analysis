# 协作共享数据资源 · 接口交互文档

---

## 1. 文档说明
### 1.1 范围
- **覆盖模块**：新闻语料、因子库、新闻—因子知识关联、国债收益率、研报库、宏观指标。
- **覆盖层面**：数据表 → 对外获取接口（REST API）→ 数据来源/去向（外部系统交互）。

---

## 2. 通用约定

| 约定项 | 说明 |
|---|---|
| 基础路径 | 所有接口统一前缀 `/sapi`（环境变量 `API_PREFIX` 可覆盖，默认 `/sapi`） |
| 协议 | HTTP/HTTPS，REST 风格，JSON 响应 |
| 认证 | 由 `AUTH_ENABLED` 控制；启用时需携带 JWT（`Authorization: Bearer <token>`），未启用时免登录 |
| 时间格式 | 日期 `YYYY-MM-DD`，时间戳 `YYYY-MM-DD HH:MM:SS`，宏观月份 `YYYYMM` |
| 响应结构 | 列表类返回 `{ items/total/page/page_size }` 或 `{ data }`；错误返回 `{ error/detail }` + HTTP 状态码 |
| 对外关联键 | 新闻用 `global_uid`，因子用 `code`，宏观指标用 `zbcode`；**不使用内部自增 ID** 作为跨系统关联键 |

---

### 3.1 数据获取方式与更新频率

| 模块 | 数据获取方式 | 更新频率 |
|---|---|---|
| 新闻语料 `news` | 爬虫项目定时爬取新闻入库 | 每小时 |
| 因子库 `factor` | 基于新闻的衍生数据：新闻入库后触发大模型分析，复用旧因子或产生新因子 | 随新闻分析触发 |
| 新闻—因子关联 `news_factor` | 大模型分析新闻时生成新闻与因子的关联 | 随新闻分析触发 |
| 国债收益率 `yield_data` | 每晚 20:00 从财政部获取当日国债收益率（经中国债券信息网下载） | 每日（20:00） |
| 研报库 `research_report` | 一次性导入一批研报用于基础功能开发，无自动获取 | 一次性（无定期） |
| 宏观指标 `macro_indicator_data` | 从国家统计局一次性导入建表（多为月度/年度数据），无自动获取 | 一次性（无定期） |

---

## 4. 各模块接口清单

### 4.1 新闻语料（表 `news`）

- **对外关联键**：`global_uid`
- **获取方式**：爬虫项目每小时定时爬取（华尔街见闻、第一财经，本仓库不含爬虫代码）
- **更新频率**：每小时

| 方法 | 路径 | 关键参数 | 说明 |
|---|---|---|---|
| GET | `/sapi/news` | `date` / `start_date` / `end_date` / `source`(逗号分隔) / `model` / `view`(best/single/all) | 新闻列表，含方向/理由/模型 |
| GET | `/sapi/news/{news_id}` | `model` / `include_all_models` | 新闻详情（正文、分块、因子、多模型分析） |
| GET | `/sapi/news/sources` | — | 新闻源列表（key + 脱敏 name） |
| GET | `/sapi/news/latest-trading-day` | — | 最新交易日 |
| GET | `/sapi/news/similar` | `news_id` / `top_k` | 相似新闻（向量检索） |
| GET | `/sapi/discover/news` | `page` / `page_size` / `direction` / `source` | 发现页新闻列表（分页无限滚动） |
| POST | `/sapi/news/{news_id}/analyze` | `model_name` | 触发单条新闻 AI 分析 |

---

### 4.2 因子库（表 `factor`）

- **对外关联键**：`code`
- **获取方式**：基于新闻的衍生数据——新闻入库后触发大模型分析，复用旧因子或产生新因子（当前 401 个）
- **更新频率**：随新闻分析触发（无独立定时任务）

| 方法 | 路径 | 关键参数 | 说明 |
|---|---|---|---|
| GET | `/sapi/factors` | — | 全部因子列表 |
| GET | `/sapi/factors/paged` | `page` / `page_size` | 分页因子（首屏快速加载） |
| GET | `/sapi/factors/by-category/{category}` | `category`(POLICY/MACRO/LIQUIDITY/RISK/SENTIMENT/INDUSTRY) | 按大类筛选因子 |
| GET | `/sapi/discover/factor-detail` | `factor_id` | 因子详情（活跃度、关联新闻、同类别因子） |

---

### 4.3 新闻—因子关联（表 `news_factor`）

- **对外关联键**：`news.global_uid` + `factor.code`（内部表为自增 ID）
- **获取方式**：大模型分析新闻时生成（方向 `positive/negative/neutral` + 判断依据 `driver`）
- **更新频率**：随新闻分析触发（与因子库联动）

| 方法 | 路径 | 关键参数 | 说明 |
|---|---|---|---|
| GET | `/sapi/factor/{factor_code}/news` | `factor_code` / `model` | 某因子关联的方向性新闻列表 |
| GET | `/sapi/news/{news_id}` | — | 新闻详情内含 `factors` 字段 |
| GET | `/sapi/discover/factor-detail` | `factor_id` | 因子详情内含 `related_news` |
| GET | `/sapi/returns/calendar` | `start` / `end` / `selected` | 收益日历内含每日活跃因子 top5 |

---

### 4.4 国债收益率（表 `yield_data`）

- **对外关联键**：`date` + `period` 组合
- **获取方式**：每晚 20:00 从财政部获取当日国债收益率（经中国债券信息网 ChinaBond 下载 Excel 导入）
- **更新频率**：每日（20:00）
- **口径**：`value` 为百分数（`1.7000` 表示 1.7000%）

| 方法 | 路径 | 关键参数 | 说明 |
|---|---|---|---|
| GET | `/sapi/yields` | `start` / `end` / `type`(期限，如「10年」) | 收益率时间序列 |
| GET | `/sapi/news/{news_id}/yield` | `period` / `window_before` / `window_after` | 新闻事件窗口收益率 |
| GET | `/sapi/discover/yield-detail` | `period` | 收益率详情（sparkline、关键指标、显著变动） |
| GET | `/sapi/discover/market-panel` | — | 市场面板（各期限收益率 + sparkline + 利差） |
| GET | `/sapi/returns/calendar` | `start` / `end` | 收益日历（各期限逐日 bp 变化） |

---

### 4.5 研报库（表 `research_report`）

- **对外关联键**：内部自增 `id`（去重用 `file_hash`）
- **获取方式**：一次性导入一批研报用于基础功能开发，无自动获取；后续支持手工上传 PDF（来源标记 `eastmoney` / `seed`）
- **更新频率**：一次性（无定期自动更新）

| 方法 | 路径 | 关键参数 | 说明 |
|---|---|---|---|
| GET | `/sapi/research/summary` | — | 概览统计（总数、观点分布、机构数、时间范围） |
| GET | `/sapi/research/list` | `institution` / `industry` / `market_view` / `page` / `page_size` | 研报列表（筛选 + 分页） |
| GET | `/sapi/research/{report_id}` | — | 研报详情（正文 + AI 分析 + 图表） |
| POST | `/sapi/research/upload` | multipart `file`(PDF) / `uploaded_by` | 上传 PDF 自动解析入库 |
| POST | `/sapi/research/{report_id}/analyze` | `model`(doubao/glm/deepseek/qwen) | 触发单份研报 AI 分析 |
| GET | `/sapi/research/figure/{file_hash}/{filename}` | — | 研报图表文件（PNG） |

---

### 4.6 宏观指标（表 `macro_indicator_data`）

- **对外关联键**：`zbcode` + `datestr`
- **获取方式**：从国家统计局一次性导入建表（绝大多数为月度/年度数据），无自动获取
- **更新频率**：一次性（无定期自动更新）

| 方法 | 路径 | 关键参数 | 说明 |
|---|---|---|---|
| GET | `/sapi/macro-data/indicators` | — | 指标元数据（代码/名称/分类/域） |
| GET | `/sapi/macro-data/data` | `zbcode`(逗号分隔) / `start` / `end`(YYYYMM) | 指标时序数据 |
| GET | `/sapi/macro/signal` | `factor_code` / `start_time` / `end_time` / `signal_type`(presence/directional) / `decay_lambda` | 宏观信号（新闻驱动） |
| GET | `/sapi/macro/signal/logs` | `page` / `page_size` / 过滤条件 | 信号请求日志 |
| GET | `/sapi/returns/calendar` | `start` / `end` | 收益日历内含各月宏观数据 |

---

### 4.7 聚合接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/sapi/dashboard/core` | 看板核心指标（聚合新闻/因子/收益率/研报/分析/向量） |
| GET | `/sapi/returns/calendar` | 收益日历（聚合新闻方向、收益率变动、活跃因子、宏观数据） |
| POST | `/sapi/internal/pipeline/trigger` | 内部定时流水线（批量分析 + 向量化 + 策略推送） |
