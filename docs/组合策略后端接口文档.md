# 组合策略后端接口文档

## 2. 接口概览
- 接口名称：组合策略AI分析
- 请求方式：POST
- 接口路径：/api/strategy/portfolio-analysis
- 完整地址：http://10.253.50.112:8000/api/strategy/portfolio-analysis
- 返回方式：同步返回 JSON
- 鉴权：当前版本无额外鉴权

## 3. 业务说明
- 服务端基于目标新闻日的 news + analysis.reason 数据做聚合分析。
- 首次请求会触发分析并缓存；后续相同缓存键请求直接返回缓存结果。
- 输出是结构化字段值

## 4. 请求定义
### 4.1 Request Body
请求体可为空，支持一个可选参数：

```json
{
  "force_refresh": false
}
```

字段说明：
- force_refresh：boolean，可选，默认 false。
- true：强制忽略缓存，重新执行分析并覆盖缓存记录。
- false：优先命中缓存。

### 4.2 调用示例
```bash 
curl -X POST "http://10.253.50.112:8000/api/strategy/portfolio-analysis" \
  -H "Content-Type: application/json" \
  -d "{}"
```

强制刷新示例：
```bash
curl -X POST "http://10.253.50.112:8000/api/strategy/portfolio-analysis" \
  -H "Content-Type: application/json" \
  -d "{\"force_refresh\": true}"
```

- meta.latest_news_pub_time：目标新闻日中最新新闻发布时间。
- meta.latency_ms：本次处理耗时（毫秒）。

## 6. 输出校验规则
服务端对模型输出做强校验，校验失败将触发失败流程。

### 6.1 通用数值规则
- 所有区间字段满足：0 <= min/max <= 100。
- 所有区间字段满足：min <= max。
- 组合资金 portfolio_fund_wan >= 0。
- 数值统一保留两位小数。

### 6.2 最低评级枚举
min_rating 仅允许：
- 不限
- AAA
- AA+
- AA
- AA-
- A+
- A
- A-
- BBB+

### 6.3 分布可行性规则
分别对 distribution_by_category、distribution_by_type 执行：
- sum(min) <= 100
- sum(max) >= 100

## 7. 缓存与重算规则
- 缓存落表：portfolio_strategy_analysis_cache。
- 缓存状态：running / success / fail。
- 命中条件：同一 cache_key 且 status=success。
- force_refresh=true 时跳过缓存读取，直接重算。
- cache_key 由目标新闻日、模型名、schema 版本、数据版本组合后哈希得到。

## 8. 错误响应
当前接口失败时返回 HTTP 500，响应示例：

```json
{
  "detail": "组合策略分析失败: 目标新闻日没有可分析的新闻或 reason 数据为空"
}
```

常见失败原因：
- 目标日期无有效新闻数据。
- analysis.reason 为空或不可用。
- 模型输出非 JSON 或不满足字段约束。
- 大模型网关不可达或超时。

## 9. 数据库存储说明
接口使用如下表保存缓存与链路信息：

```sql
CREATE TABLE `portfolio_strategy_analysis_cache` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键ID，自增',
  `cache_key` varchar(255) NOT NULL COMMENT '缓存唯一键，唯一标识一条缓存记录',
  `target_news_date` date DEFAULT NULL COMMENT '目标新闻日期',
  `model_name` varchar(128) DEFAULT NULL COMMENT '模型名称',
  `status` varchar(32) DEFAULT NULL COMMENT '执行状态：success-成功，fail-失败，running-执行中',
  `output_json` json DEFAULT NULL COMMENT '分析结果JSON数据',
  `news_count` int DEFAULT NULL COMMENT '新闻数量',
  `news_ids_json` json DEFAULT NULL COMMENT '新闻ID列表JSON',
  `window_start` datetime DEFAULT NULL COMMENT '时间窗口开始时间',
  `window_end` datetime DEFAULT NULL COMMENT '时间窗口结束时间',
  `latest_news_pub_time` datetime DEFAULT NULL COMMENT '最新新闻发布时间',
  `request_id` varchar(128) DEFAULT NULL COMMENT '请求唯一ID，链路追踪',
  `error_message` text DEFAULT NULL COMMENT '错误信息（失败时记录）',
  `started_at` datetime DEFAULT NULL COMMENT '任务开始执行时间',
  `finished_at` datetime DEFAULT NULL COMMENT '任务执行完成时间',
  `latency_ms` bigint DEFAULT NULL COMMENT '执行耗时，单位：毫秒',
  `created_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_cache_key` (`cache_key`),
  KEY `idx_target_news_date` (`target_news_date`),
  KEY `idx_status_created` (`status`,`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='组合策略分析结果缓存表';
```

## 10. 联调建议
- 先调用一次空请求，确认返回 success=true 且 meta.cache_hit=false。
- 再次调用相同请求，确认 meta.cache_hit=true。
- 如需验证重算链路，传 force_refresh=true。
