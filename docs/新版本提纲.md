# 产品提纲
## 1. 产品定位
在7月底的讨论里，我提出在9月份的大会上，我们希望发布的是一个更现代化、更AI化的产品

商业化的ToB层面，我觉得产品的主线不应该是预测金融市场的走向，也就是说AI去预测明天某一个品种的具体价格，评估应该购买多少头寸，无论从模型原理还是目前主流的金融实践中，我觉得都不具备很强的可行性。

改造后的产品主线更接近于辅助交易员做出判断，我们可以提供AI总结的市场走向，政策大纲以及可溯源且具备解释性的内容，提供完整信息流以及多样化的图表

从实务的角度可能更像一个投资助理或者助理研究员的身份，对于9月份的会议，我觉得更符合我们目前产品定位的主题更接近于“面向金融从业者的 AI 固守研究助手”

我们花了一周的时间去看了国内外的金融AI产品，以海外的Bloomberg和perplexity为主要的参考对象

我提出了两个方面的改造：

1. 要加强AI交互以及相关功能配套

2. 要调整目前信息展示的前端，更用户友好、更商业化的信息展示


## 2. 核心产品模块
### 2.1 左侧工具 也就是AI部分
1. 自然语言的交互，也就是聊天框会放在首页，用户看到某一篇新闻或者研报，或者有什么想法，可以直接进行交互

2. Computer模块：我们希望把很多内置的AI功能整合到这个模块里，目前已经整合进了”研报分析””策略开发”等

3. 自定义部分：这一块我们是留空的，主要是参考了比如workbuddy等主流AI产品，这一块我们会考虑做连接器，Skills，记忆等等，也就是定制化的个人使用会放到这个模块

4. “项目”模块：这个是类似于小组使用的功能，也是我们觉得在ToB层面，比较有价值的方向，比如机构的某部门，对于领导来说，部门的工作人员可以共享一个信息空间，和办公软件的交互，内部我们也会开发记忆管理等功能，这一块没有之前开发过，所以暂时也是留空

5. 更现代化的用户管理，包含用户设置，账户信息等


### 2.2 右侧的主要信息展示部分
我们把之前10来个板块整合，计划分成六个部分：”市场”、”收益”、”预测”、”关注列表”、”投资组合”、”工作流”

市场部分：我们打算整合大多数之前的内容放到这个部分，包括新闻信息的展示，国债行情、AI市场摘要、以及最新的策略信号

收益：我目前的想法是做一个类似于收益日历的板块，分日期展示某一天的对国债收益率产生重大影响的信息，比如政策变动、国际局势等

预测：这一块我希望展示的是AI生成内容，包括之前的每日报告，策略生成等

---
下面的内容我们暂时只提出了想法，很具体的实现还需要谈论

关注列表：这一块我们想要实现的是，用户可以关注某一个板块，或者标的

投资组合：这一块我们计划的是资产配置、AI 组合建议

工作流：此处将展示数据流水线、最近任务，能够联动到左侧工具栏中的Computer部分以及项目
