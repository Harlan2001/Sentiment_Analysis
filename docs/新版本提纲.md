# 债券市场舆情分析 产品提纲
## 1. 产品定位
AI驱动的债券市场舆情分析平台，融合实时网页检索与大模型生成，解决用户信息查询、专题研究、资讯分析需求。区别于通用大模型，核心价值：信息时效性强，兼顾主动问答与被动资讯浏览，面向机构、普通用户。

## 2. 核心产品模块
### 2.1 主站对话模块（待检查）
1）对话问答：自然语言提问，输出结构化回答，支持多轮追问、多模态输入?。
2）附属功能：“工件”展示因子库、宏观信号等数据库，“自定义”支持研报分析、AI策略生成等智能分析内容。
3）项目协作：“项目”功能，支持用户创建、加入、管理项目，实现多人协同研究。
4）会话管理：对话自动保存，支持会话重命名和历史问答查询。

### 2.2 资讯发现板块
1）新闻信息：新闻资讯按时序展示，无限滚动加载。点击新闻卡片右侧滑出详情面板，展示标题、来源信息、AI方向置信度+分析理由、关联因子标签、全文内容、相关新闻推荐。
2）市场数据：右侧面板展示所有期限国债收益率曲线、当日活跃因子（7日新闻数归一化排序）、AI市场摘要（每日LLM生成的多空逻辑+关键风险点）、最新策略信号（AI推荐标的+置信度+简要理由）。
3）市场数据和新闻联动：收益率详情页展示关键指标、显著变动日期时间轴和对应日期的方向性新闻；因子详情页展示7日活跃趋势图、关联新闻、相关因子；市场概要和策略信号详情页展示对应分析报告，包括情景分析、策略建议、风险提示等。
