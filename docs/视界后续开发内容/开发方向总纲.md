## 一、原则

1. **数据源先行**。拿不到真实数据、或数据源不合规的，一律不做。
2. **优先新板块，不碰现有逻辑**。分析链路（新闻→因子→信号→预测）、Dream、MCP、Agent、项目权限、Skills 一律不改。
3. **新模块用新表、新路由、新页面**，照抄项目现成模板，零存量回归风险。
4. **新页面必须接真实后端**，不新增硬编码或演示数据。
5. **代码算指标，LLM 只解释**。统计口径一律由 SQL / pandas 产出。
6. **不引重依赖**。不引入 APScheduler / scipy / cvxpy / QuantLib / qlib / vectorbt / AKShare。
7. **只做简单版**。每个模块明确写"不做"什么，避免范围蔓延。
8. **存量修复只记待办，不排进开发**。见 §五。

## 三、各模块要做什么

### 1. 预测诊断（已完成，待迁移）

**问题**：预测报告生成完就归档，从不回看准不准。

**实测结论**：模型存在**系统性看涨偏置** ——

| 周期 | 样本 | 方向命中率 | 多数类基准 | 差值 | 预测"看涨"占比 |
|---|---|---|---|---|---|
| 日 | 77 | 61.0% | 80.5% | −19.5pt | 37.7% |
| 周 | 73 | 38.4% | 68.5% | −30.1pt | **90.4%** |
| 月 | 63 | 28.6% | 82.5% | −54.0pt | **88.9%** |

周、月预测约 90% 看涨，命中率**显著跑输**"无脑猜下行"的基准。

**定位**：**内部评估工具**。结论属平台质量信息，不是给客户看的产品内容。

**待办**：**迁移至 admin 监控看板**（已有 `isAdmin` 门禁），从 `/forecast` 页撤下该标签。

**展示保留**：样本数、方向命中率、多数类基准、基点误差、置信区间。
**展示收紧**：置信度分档仅在样本充足时显示（代码已实现样本 <20 自动隐藏）。

### 2. 信用利差

**数据**：中债 `historyDown` 接口，`nameType=2` = 中短期票据收益率曲线，`gjqx=0` 取全期限。与现有 `bond_downloader.py` **同一接口**，只改一个参数。

**做什么**
- 新增中债信用债曲线下载
- 新建独立表 `credit_curve`（**不改 `yield_data` 主键** —— 改维度会牵动 db_yield / discover / returns / dashboard_service 四处下游）
- 利差 = 同日期同期限的信用债 − 国债
- 展示利差曲线 + **历史分位**

**不做**：评级分档（`nameType≥3` 返回错误页）、自动定时（先手工跑通）、信用-利率轮动信号。

---

### 3. 期货基差（IRR）

**问题**：现有期货持仓页只有"前 20 会员多空持仓"，**对业务判断帮助有限** —— 多空比低是套保盘的正常结构，不是看空信号，容易被误读成交易信号。

**数据（已验证）**：
- 行情：中金所 `sj/hqsj/rtj/YYYYMM/DD/index.xml` —— 含开高低收、结算价、持仓量、成交量（实测 T2612 收盘 109.87、持仓 418,593）
- 现券收益率：库内 `yield_data` 已有

**做什么**
- 存期货日行情
- 计算**期现基差** = 现券净价 − 期货价格 × 转换因子（简化口径：基差 / IRR）
- 展示：基差走势（判断期货相对现券**贵还是便宜**）+ 与持仓多空比并列

**定位**：**研究参考**，不标注为多空交易信号。

**不做**：完整 CTD 券识别与转换因子精算（需券池，拿不到）、自动交易。

---

### 4. 中美利差

**数据（已验证）**：美国财政部官方 CSV，免密钥、可长期获取（FRED 作备用源）。实测返回 1Mo–30Y 全曲线，含 2Y/10Y/30Y。

**做什么**
- 解析 CSV → 存美债 2Y/10Y/30Y
- 中美利差 = 中债 10Y − 美债 10Y
- 展示中美利差走势 + 历史分位

**不做**：海外央行议息日历（需人工维护）、多国曲线、资本流动建模。
**注意**：中美交易日不同 → **利差只在双方都有数据的日期计算，不插值**。

---

### 5. 回测仿真（因子事件研究）

**数据**：库内 `news_factor` 6.4 万行、跨 2021–2026、覆盖 381 个因子。

**关键口径**：**不测 directional 信号**（实测仅 47 行 / 8 个重叠窗口 / 9 个因子各 1 样本），**改测"因子事件"** —— 某因子出现后 T+1 / T+5 / T+20 的 10Y 收益率变动，样本大三个数量级。

**做什么**
- 每因子输出：**样本数、方向命中率、平均变动、中位数**
- 因子详情页展示；**样本 < 20 显式标注"样本不足"**
- 分年度命中率（看稳定性）

**两条纪律**：① 严格防未来函数（信号日 t 只用 t 及之前数据，收益从 t+1 起）；② **按交易日对齐**（`SELECT DISTINCT date FROM yield_data` 即中债估值发布日历，**不需要节假日依赖**）。

**不做**：收益/回撤指标、概率校准、**多因子横向排名**（利率债因子同源于同一批新闻，横向比易得伪结论）。

---

### 6. 政策文件分析（改造为工作流内）

**问题**：原方案从新闻抓政策事件，但**政策文件原文拿不到**（8 次尝试全失败）。现有 7,071 条政策新闻**全是媒体解读**，而平台本来就能看政策新闻 —— 增量价值有限。

**改造方向（用户提出）**：**改为用户上传政策文件 → 平台解析分析**。

**为什么合理**
- 数据源问题**彻底消失**（用户自己提供原文）
- 归属合理：属"用户提交任务、系统处理"场景，应放**工作流**
- 有现成模式可复用：研报上传解析（`research_report/`：PDF 解析 + LLM 提取 + 导出）

**做什么**
- 工作流内新增"政策文件分析"：上传 PDF/Word → 解析 → LLM 提取政策要点与影响方向 → 输出分析
- 复用研报解析的解析与导出能力

**不做**：从公网采集政策原文、人工维护政策日历。

**处置现有 `/policy` 页**：撤下，其"媒体解读聚合"能力与新方向重复。

## 五、存量问题（仅记录，本期不修）

### 1. 中文向量模型用错 ⚠️ 建议优先修

向量化用 `all-MiniLM-L6-v2`（**英文模型**），而 `models/text2vec-base-chinese`（中文模型）**已备好却从未使用**。实测：

- 无关中文对"降息预期" ↔ "钢铁产量" 相似度 **1.000**（相关对仅 0.59）
- **因子去重闸门失效**：拿"通胀预期"比库里已有的"通胀预期"只得 **0.664**，低于阈值 0.7 → **被当新因子入库**
- 这解释了因子库膨胀到 381 个（其中 320 个概念型），分析 prompt 里因子清单占约 1.5 万字符

**修法**：换 `text2vec-base-chinese`（本地已有，零下载）+ 重建索引 + 阈值按现有因子留一交叉验证标定。**约半天，不改任何业务逻辑**。

### 2. 预测的看涨偏置

见 §三.1。修法：调整报告生成 prompt 的置信度与方向指引。**先有诊断基线，改完可复测验证。**

### 3. 收益率异常阈值失效

"单日变动超 50bp 告警" —— 实测全 9 期限、7 年 **触发 0 次**（最大 35bp）。改按分布标定。

## 六、实现约定

**四层模板**（照抄，不发明新模式）：
```
sql/NNN_<模块>.sql                        -- 建表
backend/repositories/<模块>_repository.py  -- 继承 BaseRepository，手写 SQL
backend/routers/<模块>.py                  -- APIRouter(prefix=f"{API_PREFIX}/...")
backend/app.py                            -- 注册路由
frontend/src/api/<模块>.ts                 -- 用 client.ts 的 request<T>()
frontend/src/features/... 页面组件
tests/unit/test_<模块>.py                  -- 仓储读写与幂等
```

**约束**
- 无 ORM、无 alembic → DDL 手写 `sql/`，SQL 手写 repository
- 多租户 = 每表挂 `owner_username`；认证默认关闭，路由用 `getattr(request.state, "username")`
- 所有任务**必须幂等**
- 外部取数失败**必须明确报错并记录日志**，不能静默失败
- **Agent / MCP 的工具清单来自打包文件 `backend/agent/data/openapi.json`，新增接口后必须重新导出**
