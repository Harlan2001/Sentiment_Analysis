# PRD：预测诊断

> 本文档面向产品、开发与业务方，说明这个模块为什么做、怎么做、前端如何设计。
> 所属方向：可信度主线（让分析结论可被核查）

---

## 1. 背景与问题

平台每天生成债券市场预测报告，给出"日/周/月"三个周期的上涨概率、预期基点和置信度。但报告生成完就归档，**从来没有人回看它准不准**。

这带来两个后果：

- **对业务**：投研人员拿到"上涨概率 0.55"这样的数字，无法判断该不该采信。它是一个不可证伪的判断。
- **对产品**：平台无法自证价值。客户试用时问"预测准不准"，没有任何答案。

## 2. 我们实测发现了什么

用现有数据把历史预测复盘了一遍（`forecast_report` + `yield_data` 两张表，无需新数据）。结果如下：

| 周期 | 样本 | 方向命中率 | **无脑基准** | 差值 | 平均基点误差 | 预测"看涨"占比 |
|---|---|---|---|---|---|---|
| 日 | 76 | 61.8% | **80.3%** | **−18.5pt** | 2.06bp | 36.8% |
| 周 | 72 | 38.9% | **68.1%** | **−29.2pt** | 4.78bp | **90.3%** |
| 月 | 63 | 28.6% | **82.5%** | **−53.9pt** | 11.65bp | **88.9%** |

**"无脑基准"是什么**：这段时间债市整体走牛，大多数交易日收益率下行。所以"什么都不想、一律猜下行"的命中率就是 80%+。这是方向预测的正确对照线——**方向命中率的基准不是 50%，而是多数类基准**。

**结论**：模型的周、月预测**显著跑输无脑基准**（置信区间整段落在基准之下）。原因看最后一列——**周、月有约 90% 都在看涨**。模型不是在预测，而是在重复债市长期方向。

> 这个"看涨偏置"已单独记录在《开发方向总纲》的存量问题清单里。**本期不修**，但本模块会把它量化并持续跟踪。

## 3. 这个模块解决什么

**定位：诊断工具，不是成绩单。**

1. 让"预测准不准"第一次可被核查。
2. 把上述偏置**量化并持续跟踪**——这是后续决定要不要修、以及修完有没有效果的**唯一依据**。

> 先建好量问题的尺子，再决定要不要动手。**先修后测，反而没法证明修对了。**

## 4. 本期范围

### 做
- 按周期（日/周/月）计算：方向命中率、**多数类基准**、两者差值、平均基点误差、样本数
- **校准度**：预测"看涨"占比 vs 实际上涨占比 —— 本模块的**主指标**
- 按置信度分档统计实际表现（验证高置信度是否真的更准）
- 三档结论标签，直接回答"能不能用"

### 不做
- 概率校准曲线（Brier score 等）
- 按模型横向对比（样本会碎）
- **任何对现有预测逻辑的修改**（见第 9 节）

### 不建表
本模块**全部是查询与计算**，不需要新建任何表。这是它排在第一位的理由之一。

## 5. 核心设计：为什么不能只显示命中率

**直接展示"命中率 61.8%"是危险的**，有两个原因：

1. **无参照的数字会被误读**。读者会拿它跟 50% 比，得出"接近随机"的结论。**但真正的问题不是随机，是系统性看涨偏置**——这两者的性质完全不同，后者是可以修的。
2. **它无法自证**。没有基准，无法判断这个数字算好还是算坏。

所以本模块的三条展示原则：

**原则一：永远同时显示无脑基准**

读者看到的应该是"模型 vs 无脑策略"的对照，而不是一个孤零零的数字：

```
日度预测   模型 61.8%   ←→   无脑基准 80.3%     ✗ 未跑赢
```

**原则二：用三档标签替代裸数字**

| 标签 | 判据 | 含义 |
|---|---|---|
| `有效` | 显著跑赢基准 | 可以采信 |
| `噪音` | 与基准无显著差异 | 无额外信息量 |
| `风险` | 显著跑输基准 | **不建议采信**（当前周、月即此档） |

标签直接回答了业务方的真实问题——"这个预测能不能用"，把讨论从"数字好不好看"引向"要不要修偏置"。

**原则三：校准度是主指标，命中率是辅指标**

最有价值的发现是那个 **90.3%**。所以页面主角应该是**校准度**（预测看涨占比 vs 实际上涨占比），它直接暴露模型的系统性倾向。命中率降为次要参考。

## 6. 页面设计

### 6.1 融合位置

在现有 `/forecast`（预测）页**新增一个"历史战绩"标签页**，不动现有报告展示。

现有预测页结构是：左侧报告正文（摘要/市场概览/技术分析/情景分析），右侧日历 + 风险提示。新增的标签页与现有内容**并列**，用标签切换，**不覆盖、不重构现有任何组件**。

```
/forecast
├── [预测报告]   ← 现有内容，完全不动
└── [历史战绩]   ← 本模块新增
```

参考范式：`/factors` 页已有"因子信号 / 宏观数据"两个标签切换，直接照抄这套交互。

> 详细归位依据见《前端信息架构.md》。

### 6.2 页面结构

**顶部：三张周期卡片**（日 / 周 / 月），每张卡显示

```
┌─────────────────────────────┐
│ 日度预测            [有效/噪音/风险] │
│                             │
│   命中率  61.8%              │
│   无脑基准 80.3%   ▼ -18.5pt  │
│   平均误差 2.06bp            │
│   样本 76                    │
│   ▁▂▃▅▂▁  （命中率滚动趋势）    │
└─────────────────────────────┘
```

- 标签用色区分：`有效`绿、`噪音`灰、`风险`红
- 命中率与基准**并排显示**，差值用箭头 + 颜色
- 样本数**必须常驻**（业务方需要知道这个数字有多可信）

**中部：校准度图**（主指标）

双折线对比图，横轴是时间：

- 折线 A：预测"看涨"占比
- 折线 B：实际上涨占比

两条线**长期背离**即说明存在系统性方向偏置。这张图是整个页面的核心，能一眼看出问题。

**下部：置信度分档表**

| 置信度区间 | 样本 | 命中率 | 与基准差 |
|---|---|---|---|
| ≥ 0.65 | 55 | 72.7% | … |
| 0.50–0.65 | … | … | … |

用来回答"模型说自己有把握的时候，是不是真的更准"。

### 6.3 边界与诚实性

- **样本 < 20 的分档不展示**（周/月的高置信度分档样本只有 10 和 3，直接隐藏）
- 页面顶部固定一行说明：**"方向预测的对照基准是多数类基准，不是 50%"**，避免读者误判
- 所有数字旁标注口径与时间范围

## 7. 怎么融合到现有产品

| 集成点 | 做法 | 是否动现有代码 |
|---|---|---|
| 前端入口 | `/forecast` 页新增标签页 | 是（仅加一个标签，不改现有内容） |

| 数据来源 | `forecast_report` + `yield_data` | 否（只读，不改表） |
| 预测报告逻辑 | **完全不碰** | 否 |

## 8. 数据与接口

**数据来源**：`forecast_report`（117 份报告，2026-03 ~ 2026-10，2 个 prompt 版本）+ `yield_data`（国债 9 期限，2020-01 起）。

**交易日对齐**：不引入节假日依赖，`SELECT DISTINCT date FROM yield_data` 就是权威的中债估值发布日历（实测其中 50 个"周末日期"恰好是中国的调休补班日，成对吻合）。**按交易日序号回填，不按自然日。**

**两个必须遵守的口径**
1. 预测同时给出"上涨基点"和"下跌基点"，必须**先判断实际方向，再取对应值**算误差，不能直接拿上涨基点比。
2. 三个周期**分别计算**，不要汇总成单一数字（周、月问题远大于日）。

**周期与持有期对应**：日 → T+1，周 → T+5，月 → T+20。

## 9. 明确不做的存量修改

实测确认的"看涨偏置"**本期不修**，只记录、只跟踪。理由：

- 本模块上线后，问题会被量化并可持续跟踪，**那时改才有依据、也能验证效果**
- 现在改，既没有对照口径，又要动存量逻辑

偏置的修改方式已记录在《开发方向总纲》：**只需调整报告生成 prompt 里的置信度与方向指引文本**，不涉及调用链。

## 10. 集成注意

**Agent 与 MCP 不会自动看到新接口。** Agent 与 MCP 的工具清单来自打包文件 `backend/agent/data/openapi.json`（当前是 2026-09-03 导出的），新增接口后**必须重新导出该文件**，否则 AI 对话和 MCP 客户端都无法调用新接口。这是所有新模块的共同注意点。

## 11. 验收标准

- [ ] 三个周期分开展示，各自有命中率、**无脑基准**、差值、平均误差、样本数
- [ ] 三档标签（有效/噪音/风险）判定正确
- [ ] 校准度图能看出预测看涨占比与实际上涨占比的背离
- [ ] 置信度分档正确，样本 < 20 的分档自动隐藏
- [ ] 页面固定说明"基准是多数类基准，不是 50%"
- [ ] 现有预测报告展示**行为无回归**
- [ ] 未新建任何表；未修改预测生成逻辑
- [ ] 重新导出 openapi.json，Agent/MCP 能调用新接口
