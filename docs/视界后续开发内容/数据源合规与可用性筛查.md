# 数据源合规与可用性筛查

> 本文档记录各候选数据源的**实测结论**，作为后续规划的硬约束依据。
> 凡未通过筛查的数据源，不得进入开发排期。
> 筛查日期：2026-10-22

---

## 一、筛查标准（五项全过才可用）

| # | 标准 | 说明 |
|---|---|---|
| 1 | **合规** | 商业使用有授权；非公开爬取的第三方商业数据一律排除 |
| 2 | **可持续** | 官方或长期稳定，非"今天能取、明天可能挂" |
| 3 | **字段够用** | 能支撑目标分析，不缺关键字段 |
| 4 | **数据质量** | 无大量垃圾/过期数据 |
| 5 | **可量化展示** | 能落成对业务判断有帮助的指标 |

**用户明确原则：合规不通过的，直接排除，不做技术可行性讨论。**

---

## 二、通过筛查（✅ 可用）

### 1. 中债（中国债券信息网）—— 收益率曲线

| 项 | 结论 |
|---|---|
| 合规 | ✅ 官方公开下载接口 |
| 可持续 | ✅ 实测连续 3 次请求稳定返回 200 |
| 字段 | ✅ 国债曲线（`nameType=1`）、中短期票据曲线（`nameType=2`），1/2/3/5/7/10/15/20/30 年完整 |
| 质量 | ✅ 数据连续，可回溯多年 |
| 限制 | ⚠️ **仅曲线，无个券**；`nameType≥3` 返回错误页 → **无法按评级分档** |

**用途**：信用利差（信用债曲线 − 国债曲线）

### 2. 中金所（中国金融期货交易所）—— 持仓 + 行情

| 项 | 结论 |
|---|---|
| 合规 | ✅ 官方公开 CSV / XML |
| 可持续 | ✅ 实测连续 3 次返回 200；历史可回溯至 2020 年 |
| 字段 | ✅ **持仓排名**：前 20 会员多空持仓 + 增减<br>✅ **行情**：开高低收、结算价、持仓量、成交量 |
| 质量 | ✅ 每日更新，无过期数据 |
| 覆盖 | T(10年) / TF(5年) / TS(2年) / TL(30年)，每品种 3 个合约 |

**接口**：
- 持仓排名 `http://www.cffex.com.cn/sj/ccpm/YYYYMM/DD/{品种}_1.csv`（GBK 编码）
- 日行情 `http://www.cffex.com.cn/sj/hqsj/rtj/YYYYMM/DD/index.xml`（XML，482KB，含全部品种）

**用途**：期货持仓排名（已做）、**期现基差（待做，需结合现券收益率）**

### 3. 美国财政部 —— 国债收益率曲线

| 项 | 结论 |
|---|---|
| 合规 | ✅ **美国政府官方公开数据**，无授权风险 |
| 可持续 | ✅ 官方长期发布（实测偶有网络波动，有 FRED 备用源） |
| 字段 | ✅ 1Mo–30Y 全曲线，含 2Y / 10Y / 30Y |
| 质量 | ✅ 数据到 2026-10-20，格式规整 |

**用途**：中美利差（中债 10Y − 美债 10Y）

### 4. 库内既有数据（零新数据源）

## 三、未通过筛查（❌ 排除）

| 数据源 | 排除原因 |
|---|---|
| **新浪财经**（商品 `nf_*`、汇率 `fx_susdcnh`） | ❌ **合规不通过**（非授权商业数据源） |
| **东方财富**（可转债列表） | ❌ **合规不通过**；且仅覆盖可转债 |
| **中国货币网**（银行间债券） | ❌ 403 / 需登录，拿不到 |
| **中国政府网**（政策文件原文） | ❌ 8 次尝试全失败：搜索接口只返回统计分面不返回列表、页面 JS 渲染、TRS 接口路径未逆向出 |
| **深交所 / 上交所**（个券列表） | ❌ 接口活着但**未找到债券列表**（扫描 30+ catalogId 无果），页面 JS 渲染 |

### 连带结论

- **商品**：唯一数据源不合规 → **排除**
- **汇率**：唯一数据源不合规 → **排除**
- **海外债**：数据源合规 ✅，保留（仅中美利差）
- **政策原文**：拿不到 → 原方案作废，改为**用户上传**
- **银行间个券 / 评级分档**：拿不到 → **排除**
