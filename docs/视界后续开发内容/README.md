## 共同约定

**开发原则**：数据源先行；优先新板块、不碰现有逻辑；新页面必须接真实后端；代码算指标、LLM 只解释；不引重依赖；只做简单版。

**四层模板**：
```
sql/NNN_<模块>.sql → repositories/ → routers/ → app.py
                  → frontend/src/api/*.ts → features/ 页面 → tests/unit/
```

**所有新模块的共同注意点**：Agent 与 MCP 的工具清单来自**打包文件** `backend/agent/data/openapi.json`。**新增接口后必须重新导出**，否则 AI 对话与 MCP 客户端无法调用。

**三个共用基础件**：交易日历（用 `SELECT DISTINCT date FROM yield_data`）、收益率变动计算、官方数据取数骨架。
