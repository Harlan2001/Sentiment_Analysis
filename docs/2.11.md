# 合规的问题

技术上合规主要的问题是不是可能在于我们要做数据留存，[perplexity金融板块](https://www.perplexity.ai/finance)也没有为任何数据付费，是不是因为它不会把数据放到内部数据库里。

像是百度、谷歌一样，数据的展示方式类似于搜索引擎，你要看具体的就跳转原网页。

但是原则上perplexity金融板块上的所有AI内容都访问使用了这些数据，这个不用付费也合规吗？
