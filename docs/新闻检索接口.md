# 新闻检索接口

Base: `http://10.253.50.112:8000`

## 1. 列表接口加关键词过滤

```
GET /sapi/news
```

| 参数 | 说明 |
|---|---|
| `keyword` | 关键词，逗号分隔多个，**命中标题或正文任一个即可**（新增） |
| `date` / `start_date` / `end_date` | 日期过滤（原参数） |
| `source` | 新闻源，逗号分隔（原参数） |
| `view` | best / single / all（原参数） |

```
例: 近一周贵金属相关新闻
GET /sapi/news?keyword=贵金属,黄金,白银,金价&start_date=2026-08-12&end_date=2026-08-19
```

## 2. 专项检索接口（精确 + 语义）

```
GET /sapi/news/search?q=<关键词>
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `q` | 是 | 关键词，逗号分隔多个，命中一个即可 |
| `start_date` / `end_date` | 否 | 日期范围 YYYY-MM-DD |
| `top_k` | 否 | 返回条数，默认 30，最大 200 |
| `model` | 否 | 指定分析模型，不传取优先级最高 |

`q` 超长直接一条带上：

```
GET /sapi/news/search?q=贵金属,黄金,白银,铂金,钯金,金价,银价,现货黄金,现货白银,伦敦金,纽约金,沪金,沪银,上金所,黄金ETF,纸黄金,黄金期货,白银期货,黄金储备,央行购金,金饰,金条&top_k=100
```

返回结构：

```json
{
  "query": { "q": "贵金属,黄金", "keywords": ["贵金属", "黄金"] },
  "total": 2,
  "items": [
    {
      "id": 10096,
      "title": "……",
      "publish_time": "2026-08-19 10:00:00",
      "source": "数据源",
      "direction": "negative",
      "horizon": "短期",
      "reason": "……",
      "model": "glm",
      "matched_keywords": ["贵金属", "黄金"],
      "matched_count": 2,
      "semantic_score": null
    }
  ]
}
```

字段说明：

- `matched_keywords` / `matched_count` — 字面命中了哪些词（可高亮）
- `semantic_score` — FAISS 语义相似度，仅语义兜底召回的非字面命中项有值，其余为 `null`
- 排序：字面命中数多的在前 → 语义相似的在前 → 时间新的在前
