# 产品发布会互动方案
---

### 核心机制：互动 = 集体表态的"出场仪式"

产品主线的完整链路是 **新闻 → 宏观 → 研报 → 因子 → 策略 → 辅助决策**。但演示环节我们不依赖现场输出来推进——**所有新闻、宏观、研报、因子、策略内容均提前准备、写死在脚本中，流程完全可控。**

因此互动的定位是：

- **一个"集体参与"的瞬间**：让全场观众通过一次问卷表态，产生"我们一起参与了"的参与感和仪式感；
- **一个"亮点时刻"**：大屏实时票数动画，是全场唯一、集体参与感最强的视觉引爆点；
- **一个"话头/引子"**：票选结果作为主持人衔接讲演的过渡语，自然引出后续演示。

**关键约定：无论互动结果如何，后续演示均按既定的单一流程执行，不做条件分叉。** 互动结果仅用于承接话术，不改变演示内容，确保流程完全可控、不出现意外。

---

## 二、四种互动方案（展开设计）

以下四种方案均采用**问卷（有限选项、单选）**形式，每种都包含"问卷题 → 完整后续流程 → 方案亮点"。四个方案可任选其一，也可组合使用。

---

### 方案一｜市场主线，您更认同哪个？

#### 问卷题（全场单选）
> 下半年债市，您更认同哪条主线？
> □ A 资产荒持续　　□ B 供给放量　　□ C 政策驱动为主

#### 现场流程

**① 互动瞬间（约 1 分钟）**
- 大屏投放问卷，全场勾选（电子问卷或纸质均可）。
- 结果实时上屏，柱状图三条票数同步增长，形成"集体表态"的视觉亮点。
- 主持人承接："我们看到，大家更认同『资产荒持续』这条主线。"——**仅作话术承接，无论结果如何，都进入统一的演示流程。**

**② 既定流程讲演（约 6–8 分钟，内容写死）**
以「资产荒」为主线主轴，沿产品链路逐层展开：

| 环节 | 模块 | 台上内容 |
|---|---|---|
| 1 | 开篇 | 抛出问题："研究员每天看的新闻、宏观、研报、因子，是怎么变成投资建议的？" |
| 2 | 新闻 | 一条真实"理财规模扩张/债基申购"新闻落进系统，AI 打上「资产荒/需求旺盛」标签 |
| 3 | AI 分析 | 多模型摘要 + 观点 + 情绪判断，数秒出结果 |
| 4 | 宏观 + 研报 | AI 自动关联同期社融、资金面数据与相关研报，佐证或补充 |
| 5 | 因子 | 命中因子池：「利率下有支撑」「资金面宽松」，因子动画点亮 |
| 6 | 策略 | 因子组合 → 策略信号："资产荒格局下，久期策略具备支撑" |
| 7 | 辅助决策 | AI 给出完整研究建议 + **反方观点**（供给放量风险）+ 风险提示 + 每条结论的来源引用 |

## 三、贯穿四个方案的统一演示主线

不论选择哪个方案，后续演示都沿同一条主线推进，四个方案只是**切入话题不同**，链路骨架完全一致：

```
新闻采集 → AI 多模型分析 → 宏观/研报关联 → 因子命中 → 策略生成 → 辅助决策（含反方观点与风险提示）
```

| 模块 | 演示要点 |
|---|---|
| 新闻报道 | 真实新闻进入系统，AI 自动打标签 |
| AI 分析 | 多模型摘要、观点、情绪判断 |
| 宏观 + 研报 | AI 自动关联数据与研报佐证 |
| 因子 | 因子命中可视化，观众外行也能看懂 |
| 策略 | 因子组合 → 策略信号 |
| 辅助决策 | 建议 + 反方观点 + 风险提示 + 来源引用，把判断交给研究院 |
