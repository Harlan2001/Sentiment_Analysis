# BondSense 新版工作台：左侧栏 PRD

> 状态：需求已确认，等待后端实施批准。  
> 功能基线：[`02-前端功能与后端对照.md`](./02-前端功能与后端对照.md)。  
> 约束：本文只细化第一批左侧栏真实闭环，不扩张功能基线；如有冲突，以功能基线和用户后续明确确认的决定为准。

## 1. 目标

登录用户打开或刷新新版工作台后，左侧栏能够一次取得当前用户、项目、各项目下的最近会话，以及不属于任何项目的最近会话。点击已有会话只打开该会话；所有新建入口都创建独立会话。

## 2. 首批范围

- 显示当前用户及登录状态。
- 显示当前用户可访问的项目。
- 每个项目可展开其项目内最近会话。
- “最近会话”显示普通会话，默认 5 条。
- 项目区块加号创建项目。
- 项目行加号创建该项目下的新会话。
- 最近会话区块加号创建普通新会话。
- 展开更多历史时调用独立的分页列表接口。
- 默认不显示已归档会话。

## 3. 已确认规则

### 3.1 会话分区

- 普通会话的 `project_id = null`，只出现在“最近会话”中。
- 项目会话的 `project_id` 必须指向有效项目，只出现在对应项目下。
- 项目会话不得同时出现在“最近会话”中。
- 后端必须按 `project_id` 做明确分区，不能依靠前端收到数据后再排除。

### 3.2 最近数量与排序

- “最近会话”默认返回 5 条普通会话。
- 每个项目默认返回 5 条项目会话。
- 会话按 `last_message_at DESC` 排序；没有消息时使用 `created_at`。
- 同一时间值使用 `id DESC` 作为稳定排序的第二关键字。
- 展开更多使用不透明游标分页，不增加 `/sidebar` 的聚合数量。

### 3.3 项目更新时间

以下动作更新项目 `updated_at`：

- 修改项目名称或描述。
- 在项目中创建会话。
- 项目会话新增消息。

归档或取消归档项目会话不更新项目 `updated_at`。

### 3.4 新建入口

- 首页聊天框、侧栏普通会话加号、项目行加号每次都创建新的会话 ID。
- 不允许复用另一个入口创建的空会话。
- 点击已有会话只导航，不创建会话。

## 4. 数据要求

左侧栏聚合响应至少包含：

- `current_user`
- `projects[]`
- `projects[].recent_conversations[]`
- `recent_conversations[]`
- 本次聚合使用的数量限制

项目和会话字段以 [`06-第一批最小接口契约.md`](./06-第一批最小接口契约.md) 为准。

## 5. 空态与错误

- 没有项目时返回空数组，不返回示例项目。
- 没有普通会话时返回空数组，不返回 Mock 会话。
- 未认证返回 `401`，前端进入未登录状态。
- 单个项目数据异常不得静默混入其他项目；聚合接口整体失败时使用统一错误格式。

## 6. 验收标准

1. 登录后刷新页面，左侧栏内容仍然存在。
2. 普通会话只出现在“最近会话”中。
3. 项目会话只出现在所属项目中。
4. 两类区域默认各显示最近 5 条，并可继续加载。
5. 点击已有会话不会创建新会话。
6. 从任意新建入口连续创建两次，得到两个不同的会话 ID。
7. 已归档会话不出现在默认左侧栏。

## 7. 不在本 PRD 范围

- 项目成员邀请和成员管理。
- 项目记忆。
- 未读状态的完整业务闭环；首批 `unread_count` 返回 `0`。
- 全局搜索和当前会话内搜索。
- 会话删除和批量操作。
