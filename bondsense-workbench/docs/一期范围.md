# BondSense 新版工作台：一期实施范围

## 目标

在不改动既有 `frontend/` 与后端的前提下，交付可独立运行的新版 BondSense 前端骨架，并用 Mock 数据验证首页、导航和基础会话入口。

## 本期包含

- 全局工作台壳、左侧栏、页面路由和响应式基础样式。
- 新版债券首页、最近五条会话与基础 Mock 会话入口。
- Computer、自定义、项目、设置的可进入页面骨架。
- Mock 与 HTTP 服务可切换的访问层。

## 本期不包含

- 工件模块：不显示入口、不提供路由。
- 真实任务执行、策略回测、定时新闻、真实团队权限和文件管理。
- 对原有前端、后端、构建配置或接口行为的修改。

## 验收原则

每个模块独立完成后再继续下一模块；页面需能启动、可路由访问，并具有明确的加载或空态。
