# BondSense 新版工作台：项目 PRD

> 状态：需求已确认，等待后端实施批准。  
> 功能基线：[`02-前端功能与后端对照.md`](./02-前端功能与后端对照.md)。  
> 约束：本文只细化第一批项目及项目会话闭环；成员管理和项目记忆已明确退出本批。

## 1. 目标

用户可以创建私有项目、打开项目主页、修改项目基本资料，并在项目中创建和读取持久化会话。项目边界必须由后端鉴权保证。

## 2. 首批范围

- 创建项目。
- 获取当前用户可访问的项目列表。
- 获取单个项目基本资料。
- 修改项目名称和描述。
- 获取项目内会话列表。
- 创建项目内会话。
- 为后续成员权限保留 `owner | editor | viewer` 角色字段和鉴权边界。

## 3. 可见性与角色

- 新项目固定以 `visibility=private` 创建。
- 数据模型保留 `shared` 枚举，但第一批不提供把项目切换为共享的产品能力。
- 创建者自动成为项目 `owner`。
- 第一批不提供成员邀请、移除和角色修改接口。
- 后端不得只依靠前端隐藏入口，所有项目和项目会话操作都必须校验访问权限。

预留权限语义：

| 角色 | 读取项目 | 修改项目资料 | 创建项目会话 | 管理成员 |
| --- | --- | --- | --- | --- |
| owner | 是 | 是 | 是 | 后续批次 |
| editor | 是 | 是 | 是 | 否 |
| viewer | 是 | 否 | 否 | 否 |

## 4. 项目资料

首批项目字段至少包含：

```text
id, name, description, visibility, role,
unread_count, created_at, updated_at
```

- `name` 必填，去除首尾空白后长度为 1 至 80 个 Unicode 字符。
- `description` 可空，最大 1000 个 Unicode 字符。
- 第一批未实现未读状态，`unread_count` 固定返回 `0`。

## 5. 项目更新时间

以下动作更新项目 `updated_at`：

- 修改项目名称或描述。
- 创建项目会话。
- 项目会话新增消息。

以下动作不更新项目 `updated_at`：

- 打开或读取项目。
- 打开或读取项目会话。
- 归档或取消归档项目会话。

## 6. 项目会话边界

- 创建项目会话前必须验证项目存在且当前用户拥有写权限。
- 读取项目会话前必须验证当前用户拥有项目读取权限。
- 项目会话只出现在所属项目下，不出现在普通“最近会话”。
- 不允许通过更新会话把会话移动到另一个项目或移出项目；跨项目移动不属于第一批。

## 7. 验收标准

1. 创建项目后刷新页面，项目仍存在并出现在左侧栏。
2. 项目创建者获得 `owner` 角色。
3. 项目内创建的会话刷新后仍属于原项目。
4. 项目会话只在对应项目下出现。
5. 无权用户无法读取或修改项目及其会话。
6. 新增项目会话或消息会更新项目时间，归档项目会话不会更新。
7. 第一批没有成员管理和项目记忆的写入入口。

## 8. 不在本 PRD 范围

- 邀请成员、移除成员、修改角色。
- 将项目切换为共享状态。
- 项目记忆的候选、确认、共享和忽略。
- 项目删除、转让、外链分享和审计日志。
- 跨项目移动会话。
